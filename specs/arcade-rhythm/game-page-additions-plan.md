# 月巴节拍 · 游戏页可增内容计划

> 状态：待确认
> 范围：`月巴节拍/rhythm.html` 游戏页（演奏中）+ 暂停页
> 硬约束：不改判定窗口（`JUDGE`）、权重（1 / 0.75 / 0.4）、谱面数据、存档结构、解锁逻辑；不新增图片/音频文件；演奏中新增绘制全部走 Canvas，不加逐帧 DOM；不使用 `filter` / `shadowBlur` / 热循环渐变；`lowPower || QUAL.low` 下全部退化为静态。

## 一、现状盘点（已有，不重复做）

- 顶栏：LV / ACC / COMBO / 退出 / 静音 / 低功耗 / 暂停。
- 进度条按「试听 · 演奏」小段推进。
- 谱面角标：`BPM 80 · 4/4`、短句标签 `A · 3/6`。
- 月巴待机：呼吸、眨眼、看最后敲击、漏拍受惊、久等 Zzz。
- 判定：分级形变 + 徽记（腮红/星/汗/泪）+ 判词；perfect 爱心、miss 墨蓝阴影。
- 历史带：小节框、16 格网格、BARS 整关结果条。
- 氛围：连击观众席（10/25/50/100）、demo→play 交棒、轮到你箭头、键帽高亮、悬停圈、倒数探头、里程碑音。
- 结算：月巴立绘 + S/A/B/C/D 动作 + 点击可撸。
- 暂停 / 校准 / 说明页。

**结论**：可爱度和氛围已经够，真正的短板是「演奏中的节奏读数与结构信息」。下一步先补可读性，再补结构性反馈，最后才加氛围，避免画面越加越吵。

## 二、可增的六个方向

1. **节奏读数**：偏移尺、±ms、平均偏差——最值钱，直接提升手感与练习价值。
2. **判定后瞬时反馈**：断连提示、PERFECT 链、双押提示——不改变判定，只补信息。
3. **小节/段落结构**：拍点灯、小节号、小节结算小票、记忆段准备倒数、最后一段标记。
4. **月巴休息与观众反应**：空拍小动作、观众遮眼/撒纸屑——把节奏的空隙填得可爱。
5. **暂停页读数**：ACC/COMBO/进度/本关最佳，给中途一个判断依据。
6. **舒适度/可选**：HUD 精简、四轨颜色辅助、音量条、节奏画像——P3 按需。

## 三、实施计划

### P0 · 读数层（低风险、直接提升手感）

**P0-1 偏移尺（中缝）**
- 位置：画布中部空白带 `y ≈ H*0.56`，宽 `min(320, 0.46W)`，中心 0 ms，量程 ±180 ms。
- 数据：`judgeTap` 已有 `bestD`（`tNow - n.t`，负 = 早，正 = 晚）与 `G.lastDelta`（ms，目前只给 debug 用）。新增 `TR.offMarks`（`{d,t0}`，最多 6 条）与 `TR.offAvg`。
- 画法：一条墨线 + 每 50 ms 短刻度；命中落一个 3 px 方块，2.4 s 内淡出；最后一击画朱红指针；右侧小字 `±12ms` 与 `AVG +6`；两端小字 `早 / 晚`。
- 只在「本段已有命中」时出现；本段首击前隐藏。教学关教练气泡期间下移到 `0.60H`，避免叠字。
- 降级：`lean` 时只画最后一击指针，不画拖尾、不做缓动。
- 落点：`judgeTap` 记录 → `draw()` 新增 `drawTimingRuler(now,lean)`；`startSegment` 清空。

**P0-2 小节计数 + 四拍灯**
- 位置：BPM 角标下方（约 `18, 34`），四个 4 px 圆点；右侧 `BAR 3/8`。
- 数据：`TR.beatIdx` / `TR.beatAt`（`loop` 已维护）、`G.chart.beat`、`G.L.bars`、当前 `now`。
- 画法：当前小节的第 n 拍点亮（朱红实心，其余墨线空心）；小节号 `floor(now/(beat*4)) + 1`，截到 `L.bars`。
- 降级：只画静态四个点与文字，不点亮。
- 落点：`drawScoreTags()` 扩展。

**P0-3 断连提示**
- 触发：`judgeMiss` 或 whiff 时，若断前连击 ≥ 10，记 `TR.breakN`、`TR.breakAt`。
- 画法：历史带下方居中一行小字 `COMBO 24 ✕`，0.9 s 淡出；低于 10 连不提示，避免噪音。
- 降级：`lean` 时不出提示（信息已由判定文字承担）。
- 落点：`judgeMiss`、`judgeTap` 的 whiff 分支 → `drawBreak(now,lean)`。

### P1 · 结构与即时反馈

**P1-1 双押连线**
- 数据：`startLevel` 时给同一时刻的第二个及以上 note 标 `pair:true`；或绘制时按 lane 取「最近一个环」，比较时间是否相等。
- 画法：同一时刻两轨环之间一条虚线墨桥 + 中间 `×2`；只在环收缩到 60% 前显示。
- 降级：仅画 `×2` 标签，不画线。
- 落点：`drawRings` 内部。

**P1-2 PERFECT 连击**
- 数据：`TR.perfStreak`（perfect 时 ++，其它判定/miss 归零）、`TR.perfBest`。
- 表现：≥10 演奏行月巴头顶三瓣小皇冠；≥20 皇冠加一圈纸屑（复用 `addBurst`）；10/25/50 可各来一次轻量 `milestone` 变体。
- 降级：只在 HUD 附近显示 `P×12`，不画皇冠。
- 落点：`judgeTap` / `judgeMiss`；`drawBunnies`。

**P1-3 小节结算小票**
- 触发：`commitHistory(ph)` 时统计本段 perfect / great / good / miss。
- 画法：历史带左下一张约 `120×26` 纸票，内容 `A · P 12 · M 0`（全完美印薄荷星，含 miss 印朱红），1.8 s 后淡出。
- 降级：静态显示 1.8 s，无淡入淡出。
- 落点：`commitHistory` 写 `TR.sumAt / sumText / sumKind` → `drawHistory` 末尾。

**P1-4 记忆段准备倒数**
- 数据：`isRecallPhrase()`；`startSegment` 传入的 lead（记忆段 ≥1.2 s）。
- 画法：演奏行上方 `准备 · 记谱段` + 两个拍点逐个点亮，结束时消失；不改 `t0`、不碰判定。
- 降级：只显示文字。
- 落点：`startSegment` 记 `TR.recallAt / TR.recallLead` → `drawCountdown` 扩展。

### P2 · 月巴与氛围

**P2-1 空拍小动作**
- 条件：本段下一个 note 距 `now` > 1.2 s，且当前无待敲 note；每段只挑一次。
- 动作（按 `trait`）：伸懒腰（scaleY）、左右看、打哈欠（Zzz）、晃小旗。纯时间函数。
- 降级：静止。
- 落点：`drawBunnies`。

**P2-2 观众反应**
- miss：底部观众月巴用爪子遮眼 0.7 s（两条短线 + 头微低）。
- 全完美小节：观众撒纸屑（复用 `burst`，8 颗），现有 star 保留。
- 降级：无。
- 落点：`drawComboCrowd`；`commitHistory` 触发。

**P2-3 最后小节标记**
- 右上短句标签下加 `最后一段` 小印；进度条尾部加一个朱红小旗（一次绘制即可）。
- 降级：保留文字。
- 落点：`drawScoreTags`。

**P2-4 暂停页读数**
- 暂停面板加一行：`ACC 92.3% · COMBO 24 · 小节 3/8 · 本关最佳 95.1%`。
- 只在暂停页新增 DOM（不在演奏循环里）；移动端换行。
- 落点：`pauseGame` + `#pauseScr` 增加一个 `<div>`。

### P3 · 可选

- **P3-1 纸面音量条**：`AnalyserNode` 取 RMS，画在谱线空白处；`try/catch`，失败静默；`lean` 关闭。
- **P3-2 HUD 精简开关**：只保留 ACC/COMBO，偏移尺/拍点/小票可关；存 `mainSave`（不碰 rhythm 存档）。
- **P3-3 四轨颜色辅助**：每个洞口的纸环用 `COLORS[lane]` 极淡描边，提升 D/F/J/K 映射。
- **P3-4 结算页「节奏画像」**：early/late 比例、最长完美链；数据已在手，结算页展示。

## 四、性能与降级

- 每帧新增：≤ 30 次 stroke/fill、≤ 2 次 `fillText`；无 shadow / filter / 渐变。
- 新层全部叠加在 `draw()` 末尾、静态 base 贴图之上，不重绘静态层。
- `lean = lowPower || QUAL.low`：位移、淡出、皇冠、拍点动画全关，只留信息文字。
- 移动端：中缝尺宽 ≤ 0.46W，4 轨时缩到 0.36W；不与键帽（`yBot + r*0.72`）和轮到你箭头（`yBot + r*1.10`）重叠。
