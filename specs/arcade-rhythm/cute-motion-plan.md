# 月巴节拍 · 月巴可爱动效与互动计划

> 状态：方向与实施计划，待确认后按阶段落地。
> 范围：只改 `月巴节拍/rhythm.html` 的视觉与交互表现；**不改判定窗口、谱面、计分、存档结构、关卡解锁**。
> 基线：纸面乐谱风 + 4 张外链月巴立绘 + Canvas 2D 逐帧绘制 + `lowPower / QUAL.low` 降级。

## 一、现状盘点（可复用的底子）

| 已有 | 位置 | 可延展点 |
|---|---|---|
| 待机呼吸、轻微起伏、左右摆 | `drawBunnies` 待打分支 | 加眨眼、耳朵抽动、看向敲击轨 |
| 冒头回弹 `popEase` | 同上 | 分档位改回弹幅度 |
| 命中先压扁再回正的 Q 弹 | `drawBunnies` 已命中分支 | perfect/great/good 三档差异化 |
| miss 阴影 + 头顶郁闷圈 | `drawSadMood` | 加眼泪、背身、耳朵下垂 |
| perfect 冒爱心 | 已命中分支 + `drawHistory` | 加星星、腮红、音符 |
| 连击礼花 | `addBurst`（每 10 连） | 连击档位氛围升级 |
| 历史带 | `drawHistory` | 可摸、挥手、眨眼 |
| 判定文字弹跳 | `draw` 的 `G.pops` | 保持，不抢戏 |
| 结算/暂停/选关 CSS 动效 | 各 `.scr` | 加月巴吉祥物与评级动作 |
| 音效池 | `boing / whiff / click / squish` | 可加触摸软音、里程碑铃 |

关键约束：

- 月巴是**真实立绘**（`BUNNY_IMGS` 四张，居中缩放为 256×256），不是程序绘制，**不要重画五官**；表情用「符号贴纸 + 身体语言」，必要时按立绘做一张脸部锚点表。
- 所有逐帧画面走 Canvas；DOM 只用于结算/菜单这类一次性界面。
- `lowPower || QUAL.low` 时必须能一键退化成静态（只留腮红/眼泪/结果色这类零动画信息）。
- 暂停、切段、重开时要清空瞬时特效（沿用 `G.fx / G.pops / G.burst` 的处理方式）。

## 二、动效方向（7 组，按「性价比」排序）

### 方向 1：判定即时反应（最优先）

同样是「被戳」，四档要有四种表情，玩家不看 HUD 也能读出成绩。

| 判定 | 身体动作 | 符号贴纸 | 时长 |
|---|---|---|---|
| Perfect | 更深的压扁 + 回弹过冲 + 轻轻上浮 | 腮红 ×2、星星 ×2、爱心 ×1、头顶小音符 | 0.55s |
| Great | 中等压扁，一次干净回正 | 单颗小星 | 0.40s |
| Good | 小幅左右抖一下（±0.03rad） | 一滴小汗珠 | 0.30s |
| Miss | 下沉 + 侧倾 + 耳朵/身体下垂（沿用墨蓝阴影与圈圈） | 眼泪一滴、问号/省略号 | 0.90s |
| 空拍 whiff | 不打断当前月巴，只让**该洞待打的那只受惊**：先弹一下再缩回 | 洞口哑光波纹 | 0.25s |

补充：

- 连续 Perfect 第 3 只起，星星从 2 颗加到 3 颗（只做视觉，不加分）。
- Good 与 Miss 的符号用「小、偏、短」，不要盖住立绘主体。
- 所有符号用纯色小图元，不加 `shadowBlur`、不加渐变。

### 方向 2：待机性格（让月巴「活着」）

利用 4 张立绘固定 4 种性格，行为稳定、玩家能记住：

| 立绘 | 性格 | 待机 | 被戳反应 |
|---|---|---|---|
| 春 | 活泼 | 呼吸幅度大、每拍轻轻颠一下 | 跳得高、星星多 |
| 夏 | 害羞 | 安静、偶尔缩一下 | 腮红更久、侧过身去 |
| 秋 | 困倦 | 眨眼慢、偶尔打哈欠 | 慢半拍才回弹（0.15s 延迟） |
| 小 | 好奇 | 头会朝最近敲击的洞偏 | 会「看」向敲击轨 |

微动作清单：

- **眨眼**：按每只的固定 seed 算周期（2.5~6s），每次 0.08~0.12s；用立绘上方一条半透明弧线，不重画眼睛。
- **耳朵抽动**：每 2 拍一次，幅度很小，只作用于立绘整体轻微旋转。
- **看向敲击**：记录 `TR.lastLane`，当前月巴整体朝该方向平移 1~2px 并轻转 0.02rad。
- **打哈欠**：连续 12s 无敲击时，随机一只打一次哈欠（头顶 Zzz 符号，不发声）。
- **每小节开场**：全体一起「抖一下耳朵」作为段落起拍提示，与现有拍点一致。

### 方向 3：连击与氛围升级

把现有「每 10 连一次礼花」做成一条递进的情绪曲线：

| 连击 | 表现 |
|---|---|
| 10 | 当前排月巴齐齐跳一下 + 小纸花 |
| 25 | 上方历史带边缘探出 2 只「观众月巴」 |
| 50 | 观众月巴增加到 4 只，纸面角落出现小彩旗 |
| 100 | 观众全体起立蹦跳 1 次 + 一次性彩带（0.8s 后消失） |
| 断连（≥10 连） | 最靠近 miss 洞的那只低头 0.6s；符号「…」；不弹窗、不出文字 |
| 全 Perfect 小节 | 该排月巴在段落结束时齐齐鞠躬；BARS 色块加一颗小星 |

注意：观众月巴只用小尺寸立绘（历史带左侧留白），不进入演奏区，避免遮挡。

### 方向 4：段落转场与流程提示

现有的「试听 → 演奏 → 下一小节」是天然的三幕剧，可以做得更有仪式感：

- **交棒**：`startSegment` 的 lead 期间，一只月巴从试听行跳到演奏行，落在洞位；lead 越短跳得越快。
- **收尾挥手**：`commitHistory` 时，飞上历史带的月巴在落位后挥手 0.4s。
- **整排出场**：新小节第一拍，所有洞位月巴**同时**冒头（现在已接近，强化为同一 easing 起点）。
- **轮到你了**：`yourTurn` 时，洞口出现向下小箭头/手指，随拍脉动 2 次后淡出（不新增 DOM）。
- **记忆段**：试听时月巴「闭眼/捂耳朵」，轮到玩家时睁开；只换符号，不改谱面。
- **倒数 4/3/2/1**：现有大数字不变，洞口月巴按拍点轻跳，不抢数字视觉。

### 方向 5：可触摸互动（非玩法）

原则：**演奏行的点击永远是判定**，绝不与「摸」冲突；可摸区域只放在不参与判定的地方。

开放范围：

1. **上方历史带**：点/摸已固定的月巴 → 挤压 + 爱心 + 软音效，0.12s 节流。
2. **试听行（demo）**：点洞口或月巴 → 探头/歪头，不断连击（demo 本来没有连击）。
3. **结算页**：点评级证书上的月巴 → 再盖一次章/眨眼。
4. **选关卡片**：按下卡片 → 月巴图做一次压扁回弹。

桌面增强：

- `pointermove` 节流 100ms：悬停的洞位亮边，该洞月巴朝指针偏头；`lowPower` 关闭。
- 键盘按下：对应洞位的键帽在 Canvas 里压下 2px 并亮朱红；松开回位（`keydown/keyup` 维护一个 Set，不走 DOM）。
- 长按 400ms 摸历史带月巴：连续爱心（上限 3 颗，不叠加音效）。

### 方向 6：开场 / 结算 / 菜单

- **进入关卡**：4 只洞口月巴从纸面外弹入（0.35s，一次性）。
- **结算**：面板顶部加一只「捧证书月巴」（复用 `BUNNY_IMGS`，CSS 定位，不新增资源）。
  - S：双手举高 + 星星；A：点头；B/C：挥手；D：摊手、低头。
  - 结算面板已有 `resPanelIn / stampIn / rowIn`，月巴动效放在 `.panel` 内，不新增全屏层。
- **选关页**：装饰月巴已有 `float`，补交替眨眼与悬停小跳；压扁回弹只在按下时发生。
- **解锁提示**：`toast` 出现时，选关卡片上的月巴探头（纯 CSS `transform`）。

### 方向 7：声音与动效对位（可选）

- Perfect 加一声很轻的「叮」；Good 用短 click；Miss 保留 `whiff`，不加重。
- 触摸历史带月巴：低频软「咕噜」（`squish` 变体，音量 0.04~0.06）。
- 连击 10/25/50/100：四档不同的短铃，音量递减，不叠加长尾。
- 全部复用现有 `AC / master / muted`，单音 < 0.2，并发上限沿用现有实现。

## 三、实施计划

### P0 · 表现基础层

1. 新增「性格」分配：`startLevel` 里按 `dimg` 映射 `trait`（lively/shy/sleepy/curious），存入 `note.trait`；不写存档。
2. 新增立绘锚点表 `BUNNY_FACE = {0:{...},1:{...},...}`，标出四张立绘的脸颊/眼睛大致位置；图片加载失败回退手绘时用默认值。
3. 拆 `drawBunnies`：
   - 先算 pose（x/y/scaleX/scaleY/rot/alpha），再画立绘，再画符号层；
   - 符号层统一入口 `drawMarks(x,y,r,marks,alpha)`，所有符号走纯色图元，不加滤镜。
4. 新增辅助：`drawBlush / drawStar / drawTear / drawSweat / drawNote / drawZzz / drawDots`，放在 `drawSadMood` 附近。
5. 统一时间驱动：所有周期动作（眨眼、呼吸、抽耳）都用 `now + seed` 直接算，不建定时器、不存逐帧状态。

### P1 · 判定分档 + 待机性格 + 空拍受惊

1. `judgeTap` 记录 `TR.lastLane / TR.tapAt`；不同档位写入不同强度的动作参数（或直接由 `result` 推导）。
2. `drawBunnies` 已命中分支按方向 1 的表分档；新增符号层；保留原压扁公式作为 Perfect 基底。
3. `drawBunnies` 待打分支加：眨眼、看 `TR.lastLane`、按 `trait` 的待机幅度。
4. `judgeMiss` 写 `TR.lastMissLane`；`whiff` 写 `TR.whiffAt/Lane`，待打月巴在 `drawBunnies` 里做 0.25s 受惊回缩。
5. `drawHistory` 加眨眼与轻摆；perfect 爱心保留，miss 眼泪补上；只对最近 8 个历史条目加符号，控制绘制量。

### P2 · 连击氛围 + 段落转场 + 可摸

1. `loop` 里按 `G.chart.beat` 算拍点，维护 `TR.beatAt`；全体月巴在拍点后 0.18s 内做一次很小的抽耳/侧摆。
2. 连击档位：沿用 `TR.comboLv`（0/10/25/50/100），在 `draw` 里按档位画观众月巴/彩旗/彩带；礼花仍由 `addBurst` 负责。
3. 断连：`judgeMiss` 里若断掉 ≥10 连，设 `TR.consoleAt`，最近月巴低头 0.6s。
4. `startSegment` 设 `TR.segFrom / segTo / segAt / segLead`；`draw` 画一只交棒月巴（只在 lead 期间）。
5. `commitHistory` 给条目写 `waveAt`；历史带落位后挥手 0.4s。
6. 新增画布命中测试 `bunnyAtPoint(x,y)`：
   - 只认历史带与 demo 行；
   - 命中后 `G.pets.push(...)`（上限 12），播放挤压 + 爱心 + 软音效，0.12s 节流。
7. 输入层：`pointermove` 维护 `TR.hoverLane`；`keydown/keyup` 维护 `TR.pressed`；只影响绘制。
8. `draw` 增加顶层：键帽按下态、悬停亮边、`yourTurn` 箭头脉动、倒数月巴小跳。

### P3 · 结算/菜单 + 可选音效

1. `finishLevel` 填充结算月巴容器：按 `g` 加 `win-S/A/B/C/D` 类；点击月巴播一次性盖章。
2. 选关卡片按下压扁（CSS `:active` 类，或 `pointerdown` 加类 120ms 后移除）；装饰月巴交替眨眼。
3. 可选音效：`purr()`、`milestone()`、`sparkle()`，全部走 `master`，音量 0.04~0.12。
4. 色板与现有纸面语言一致：腮红 `rgba(226,114,91,.35)`、星星 `#E9C46A`、眼泪 `#5C7FA3`、汗 `#8FA8BF`；Perfect 薄荷只用于判定文字与星星，不新增大面积薄荷。

## 四、性能与降级规则

- 单只月巴的符号层 ≤ 6 个绘制调用；历史带符号只给最近 8 条。
- 新粒子总量 ≤ 40，复用/新建数组都要有上限与 `splice` 清理。
- 逐帧禁止：`ctx.shadowBlur`、`ctx.filter`、新建渐变、`measureText`、DOM 读写。
- `lowPower || QUAL.low`：
  - 不眨眼、不抽耳、不悬停、不彩带、不交棒飞行；
  - 只保留静态腮红/眼泪/miss 阴影/结果色下划线；
  - 触摸仍可用，但只做一次瞬时挤压（无粒子）。
- 暂停 / 退出 / 结算时清空 `G.fx / G.pops / G.burst / G.pets` 与 `TR` 瞬时字段（延续现有习惯）。
- 不新增外链图片、字体、音频文件。

## 五、验收清单

- 判定窗口、谱面、分数、评级、解锁、存档字段**零改动**。
- 演奏行点击始终只走 `judgeTap`；摸月巴不会触发判定、不会断连。
- 四档判定在截图上可一眼区分（Perfect/Great/Good/Miss）。
- 4 种性格行为稳定、不随机跳变；重开一致。
- 连击 10/25/50/100 有递进但不遮挡洞位与谱面；断连安慰不弹窗。
- 试听→演奏、演奏→试听有交棒/挥手；轮到你时提示清晰。
- 结算 S/A/B/C/D 五种月巴反应正确；选关页按下有回弹。
- 低功耗：动效全停，信息仍可读；`prefers-reduced-motion` 自动进入低功耗。
- 手机 390×844 与桌面 1280×720 截图无溢出、无遮挡；帧率不低于改动前。
- 四语言界面不出现新硬编码文案（新反馈优先用符号，必须写字时才进 i18n 表）。

## 六、需要确认的取舍

1. **观众席**：连击越高，历史带边缘探头月巴越多。视觉更热闹，但会占用上方留白；是否保留？
2. **可摸范围**：建议只开放「历史带 + 试听行 + 结算/选关」，演奏行保持纯判定。是否同意？
3. **固定性格**：建议 4 张立绘固定 4 种性格（好记、稳定）；或每局随机（更惊喜但不易记）。
4. **是否加软音效**：抚摸咕噜、里程碑铃、Perfect 细叮，默认建议加，音量压低。
5. **结算月巴**：复用现有立绘做「捧证书月巴」，还是只用 CSS 线条小月巴（更轻）？

## 七、不做清单

- 不做全屏模糊/滤镜/混合模式。
- 不做每帧 DOM 动画或频繁 `classList` 切换。
- 不做影响判定、连击、音符时刻的「互动」。
- 不做无限粒子、拖尾、屏幕震动。
- 不重画立绘五官，不改四张外链资源。
