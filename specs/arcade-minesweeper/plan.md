## 三、叙事与主题映射

### 3.1 一句话故事

> 周末，双休月巴把家里的杂物间翻了个底朝天。鼓起的纸箱、旧报纸、干草堆下面，可能藏着蛀虫。蛀虫会咬坏番茄，所以每一格都要小心。翻开安全的垃圾、贴上封条，把番茄完整地留到最后。

### 3.2 元素映射

| 扫雷概念 | 本作表现 |
|---|---|
| 未翻开格 | 鼓起的垃圾袋 / 纸箱 / 旧报纸堆 |
| 雷 | 藏在垃圾下的**蛀虫** |
| 数字 | 相邻 8 格里的蛀虫数量，用深色小数字刻在翻开的干净地板上 |
| 旗子 | 红蜡**封条**，贴在怀疑有虫的垃圾堆上 |
| 空格（0） | 一整片干净地板，翻开时自动扩散 |
| 生命 | 3 颗**番茄**；踩虫会损失 1 颗 |
| 胜利 | 所有安全垃圾翻开，剩余虫窝自动贴封条，番茄一颗没少 |
| 失败 | 3 颗番茄被啃完，蛀虫全部现身 |
| 每日挑战 | 「今日大扫除」，同一天固定棋盘 |
| 入口角色 | **双休月巴**，周末大扫除的主持人 |

### 3.3 文案基调

- 温和、生活化，有轻微紧张感，但不恐怖、不血腥。
- 踩虫反馈是「蛀虫窜出来，啃了一口番茄」，不是爆炸。
- 失败文案避免责备玩家，例如「番茄被啃了…下次把封条贴早一点」。
- 胜利文案强调「番茄都保住了」，而不是「你赢了」。

示例：

- 开场：「杂物间里又堆满了。双休月巴握紧扫帚：这次一定要把蛀虫挡在番茄外面。」
- 踩虫：「纸箱底下窜出一条蛀虫，番茄被啃了一口！」
- 胜利：「大扫除完成。番茄一颗都没少，月巴终于能坐下休息了。」
- 失败：「蛀虫从角落里钻了出来…番茄被啃完了，明天再来一次吧。」

## 四、形态与接入

### 4.1 独立页 + 百巴箱 iframe

对齐 `goldminer.html` / `nonogram.html` 的接入方式，而不是把棋盘塞进 `index.html`：

| 对比项 | 贪吃蛇 / 幸存者 | 扫月巴（本方案） |
|---|---|---|
| 游戏本体 | 独立页 / 页内浮层 | 独立 `minesweeper.html` |
| 打开 | 百巴箱或图鉴入口 | 百巴箱卡片；M5 后增加双休月巴图鉴入口 |
| 关闭 | 卸载 iframe | `fr.src='about:blank'`，回百巴箱或回图鉴 |
| 首页计时 | 继续运行 | 继续运行 |
| 存档 | 独立键 | 独立键 `yueba-minesweeper-v1` |
| 语言 | 页内字典 + 主存档 | 页内字典 + 主存档 |

「不脱离原本游戏、其他功能照常」的落点：

- iframe 盖在首页之上，主游戏番茄钟、月巴生长、自动收获、5 秒自动存档全部继续；
- 页面只负责自己的棋盘、计时、音效；关闭即销毁；
- 首页只加 `gb-lock`（`overflow:hidden`），不碰任何计时器与存档逻辑。

### 4.2 两条入口

| 入口 | 出现位置 | 行为 | 实装前 |
|---|---|---|---|
| 百巴箱卡片 | 首页底部 dock「百巴箱」→ 卡片网格 | `gbFrameOpen` 打开，关闭回百巴箱 | **不显示**（`hidden:true`） |
| 双休月巴图鉴入口 | 图鉴 → 双休月巴详情 / 卡片 | `dexMineEntry()` → `gbFrameOpen(g,'dex')`，关闭回图鉴 | **不接入**（M5 再加） |
| 直接打开 | 双击 `minesweeper.html` | 完整游玩，使用默认语言/设置 | 开发期可用 |

### 4.3 实装前隐藏策略

1. **M1 起**就把卡片配置写进 `GB_GAMES`，但带 `hidden:true`；`gbRender()` 已原生跳过，箱内看不到，也不会影响现有 7 张卡。
2. **M1–M4 不改 `DEX_GAME`**，避免双休月巴详情页出现一个打不开的按钮。
3. **M5 验收通过后**：删除卡片上的 `hidden:true`，同时接入 `DEX_GAME` 与 `dexMineEntry`。
4. 开发期直接双击 `minesweeper.html` 或用 `?selftest=1` 自检，不依赖百巴箱入口。

## 五、玩法设计

### 5.1 核心循环

```
百巴箱点「扫月巴」
  → 标题页（难度 / 今日大扫除 / 最佳记录 / 成就 / 静音）
  → 选难度或今日局
  → 棋盘：翻开垃圾堆 → 数字提示相邻蛀虫 → 贴封条 → 推理
      → 踩虫：损失 1 颗番茄，虫窝自动封住，棋盘继续
      → 卡住：用「敲一敲」翻开一个安全格（每局 3 次）
      → 3 颗番茄耗尽：失败，蛀虫全部现身
  → 所有安全格翻开：胜利，剩余虫窝自动封条
      → 用时 / 失误 / 提示 / 星数 / 首次通关金币
      → 再来一局 / 换难度 / 返回
```

### 5.2 难度与棋盘

| 难度 | 棋盘 | 蛀虫数 | 密度 | 标准时间（3 星） | 定位 |
|---|---|---|---|---|---|
| 小扫除 | 9×9 | 10 | 12.3% | 90 秒 | 入门，1–3 分钟 |
| 中扫除 | 12×12 | 24 | 16.7% | 210 秒 | 主力，4–7 分钟 |
| 大扫除 | 16×16 | 45 | 17.6% | 420 秒 | 挑战，8–15 分钟 |

- 16×16 是竖屏上限：360px 宽下每格约 17–18px，仍可准确点按；不做 30×16。
- 三档全部开放，不设解锁门槛。
- 难度选择显示各自的「最佳时间 / 最佳星数 / 通关次数」。

### 5.3 布雷与首开保护

- **普通局**：第一次翻格后才布雷。以首次翻开的格为中心，排除 3×3 区域（越界自动裁剪），剩余格洗牌后放满固定数量的蛀虫。
- **每日局**：打开棋盘时按日期种子直接布雷，并固定一个「叶标记」起点；起点及其 3×3 区域预先翻开，保证开局安全且全服同日同盘。
- 数字在布雷后一次算好；翻开任意格只查表，不重复计算。
- 蛀虫数始终固定，不因首开保护减少；保护只是把虫挪到 3×3 之外。
- 随机数使用页面内 `mulberry32`，每日种子来自本地日期 `YYYY-MM-DD`，同一天多次进入结果一致。

### 5.4 操作

| 操作 | 桌面 | 手机 |
|---|---|---|
| 翻开 | 左键点格 | 点格（当前模式为「翻」） |
| 贴封条 / 取消 | 右键点格 | 长按 350ms；或切到「封」模式后点格 |
| 快速翻开（chord） | 双击已翻开的数字格 | 点已翻开的数字格（相邻封条数 = 数字时） |
| 切换翻/封模式 | 工具栏按钮 | 工具栏按钮 |
| 暂停 | `Esc` / 暂停按钮 | 暂停按钮 |
| 重开 | `R` / 重开按钮 | 重开按钮 |
| 移动光标 | 方向键 | — |
| 翻开当前格 | `Space` | — |
| 贴/取消封条 | `F` | — |
| 返回百巴箱 | 外层「✕ 返回百巴箱」 | 同左 |

- 棋盘 `touch-action:none`，阻止 iframe 内滚动与双击缩放。
- 长按阈值 350ms；长按触发后松手不再执行翻开，避免「想贴封条却翻格」。
- 数字格的 chord 只有在「相邻封条数 = 数字」时才生效，并在数字外圈加一圈很淡的琥珀提示环；封错时 chord 仍可能踩虫，这是扫雷的正常风险。
- 拖动棋盘不执行连续涂抹；扫雷是离散点按，避免误触。
- 键盘只在 iframe 聚焦时生效，关闭后随文档销毁。

### 5.5 判定与生命

| 项 | 规则 |
|---|---|
| 胜利 | 所有非蛀虫格都已翻开（贴在安全格上的封条不算翻开，需取消后翻开） |
| 失败 | 3 颗番茄全部损失 |
| 踩虫 | 损失 1 颗番茄；该虫窝自动封住并标记为「已发现」；输入锁定 350ms |
| 虫窝 | 已发现的虫窝不可再翻、不可取消封条 |
| 错封 | 贴在安全格上的封条不扣血、不提示对错；取消后即可翻开 |
| 0 格 | 翻开后自动扩散相邻安全格，直到碰到数字格 |
| chord | 相邻封条数等于数字时，一次性翻开周围未封格；若其中有多条蛀虫，逐条结算，番茄归零立即停止 |
| 重开 | 清空本局，番茄回到 3 颗，提示次数不返还 |
| 无撤销 | 扫雷不提供撤销；3 颗番茄就是容错空间 |

> 默认采用「3 颗番茄」而不是「一踩即死」，是为了贴合「怕蛀虫伤害番茄」的主题，也让手机误触不至于直接废掉一局。经典一命模式作为待确认项保留。

### 5.6 计时、星级与结算

- 计时从第一次有效操作（翻格/贴封条）开始；暂停、切后台、结算时停止。
- 顶部 HUD 显示：剩余蛀虫、用时、番茄生命、提示剩余。
- 星级：

| 星 | 条件 |
|---|---|
| ★★★ | 0 次踩虫、0 次提示、用时 ≤ 标准时间 |
| ★★ | 三项中满足任意两项 |
| ★ | 通关即可 |

- 结算面板显示：难度、用时、踩虫次数、提示次数、星数、本次金币、最佳时间/最佳星数。
- 只记录最佳用时与最佳星数；重复通关可刷新，但不重复发金币。
- 失败面板显示：用时、踩虫次数、剩余安全格、蛀虫分布；按钮「再来一局 / 换难度 / 返回」。
- 每日局单独记录最佳时间与星数，不覆盖普通模式。

### 5.7 提示「敲一敲」

- 每局 3 次。
- 从「尚未翻开的安全格」中随机选一格（包括被错封的安全格，会先取消封条），立即翻开；如果是 0 格，正常扩散。
- **永远不会选到蛀虫**，所以提示不会直接把玩家送进失败。
- 若所有安全格都已翻开（只剩虫窝），提示不消耗，弹出「已经没有可敲的安全角落了」。
- 使用提示会让本局无法拿到「0 提示」条件，影响星数。
- 不做「直接标出虫窝」的提示，避免破坏推理乐趣。

### 5.8 每日大扫除

- 固定 12×12 / 24 蛀虫；按本地日期做种子。
- 同一天所有玩家、多次进入都是同一棋盘；起点固定并预先翻开。
- 当天首次通关额外 +50 金币（一次性）。
- 连续 7 天完成每日局 → 本地成就「七日扫除」。
- 当天已完成后仍可重玩刷时间，但不再发金币。
- 跨天时检查日期键；若页面一直开着跨天，回到标题页时重新生成。

### 5.9 本地成就（8 条）

| id | 名称 | 条件 |
|---|---|---|
| `ms_first` | 第一扫 | 通关 1 局 |
| `ms_ten` | 十次扫除 | 通关 10 局 |
| `ms_hard` | 大扫除 | 通关 16×16 |
| `ms_perfect` | 毫发无伤 | 0 踩虫、0 提示通关 |
| `ms_speed` | 快手 | 9×9 在 60 秒内通关 |
| `ms_noseal` | 不贴封条 | 全程不贴任何封条通关 |
| `ms_daily7` | 七日扫除 | 连续 7 天完成每日局 |
| `ms_all` | 三档全清 | 三个难度各通关至少 1 次 |

- 只属于本页面，不写入主游戏 `ACHS`。
- 解锁横幅 1.4 秒，不拦输入。
- 存档 `ach` 记录；成就面板在标题页右上角。

### 5.10 金币奖励

| 来源 | 金币 | 次数 |
|---|---|---|
| 小扫除首次通关 | 60 | 每档一次 |
| 中扫除首次通关 | 120 | 每档一次 |
| 大扫除首次通关 | 200 | 每档一次 |
| 每日大扫除首次通关 | +50 | 每天一次 |

- 全清一次性合计 430 金币，相对主游戏道具价位属于小额纪念奖励。
- 重复通关、失败、重开、每日重复完成都不发。
- 独立打开（没有父页）时只在结算面板显示奖励数值，不写任何主存档。
- 若不想影响主经济，把四个数值全部设为 0 即可，代码只发 0 或直接不监听。

## 六、视觉与音效

### 6.1 视觉方向

### 6.4 动效与低功耗

- 翻格：90ms 纸片掀起（`transform` + `opacity`）。
- 0 格扩散：12ms 错峰，最多 30 格；超过 30 格剩余直接显示。
- 贴封条：120ms 向下盖章（`scale` 1.15 → 1）。
- 踩虫：220ms 左右轻抖 + 番茄汁粒子 ≤12 颗。
- 胜利：800ms 番茄逐个落位 + 一次柔光扫过；不闪屏。
- 失败：300ms 暗场 + 蛀虫现身，不做全屏晃动。
- 低功耗 / `prefers-reduced-motion`：关闭粒子、扫光、手电呼吸、震动，过渡时长减半或归零。
- 无常驻循环动画；闲置时零 rAF。

### 6.5 音效

页内自带极简 Web Audio 合成器，不引入音频文件，不依赖首页 `sfx`：

const SFX = {

  seal(){ /* 蜡封落下：180Hz 闷响 + 短噪声 */ },
  unseal(){ /* 胶带撕开：320Hz 短音 */ },

- 低功耗、无音频设备、`prefers-reduced-motion` 时只保留必要点击音或全部静默。
- 震动：翻开 6ms、踩虫 30ms、胜利 20ms；低功耗关闭。

| 模块 | 方案 |

| 游戏循环 | **无常驻 rAF**；计时用 250ms `setInterval`；只有翻格扩散/踩虫/胜利动画时临时用 CSS 动画，结束即停 |
| 事件 | 棋盘容器 `pointerdown` 事件委托；按下时用坐标换算格；长按 350ms；`pointercancel` 收尾；`contextmenu` 阻止默认 |

### 8.2 自检 `?selftest=1`

页面加载后（不影响正常流程）跑以下断言，结果输出到 console 与页内角落：

1. 三档难度各 100 个随机种子：蛀虫数量精确等于配置。
2. 首次翻格后，3×3 保护区内蛀虫数为 0。
3. 每个非虫格的数字 = 相邻 8 格蛀虫数。
4. 翻开 0 格会扩散，且不会翻开虫格。
5. 所有安全格翻开后 `win` 判定为真；少一格为假。
6. 连续踩中 3 条蛀虫后状态为 `over`；踩 1 条后番茄为 2。
7. 每日同一日期种子生成同一棋盘；跨日期不同。
8. 存档写入/读取/损坏重建均不抛错。

## 十、验收标准

1. **实装前隐藏**：M1–M4 期间，百巴箱卡片数量与当前一致，箱内看不到「扫月巴」；控制台无相关报错。

6. **布雷正确**：三档蛀虫数量精确；首次翻格 3×3 无虫；数字与相邻虫数一致。

## 十二、风险与对策

| 风险 | 对策 |
|---|---|
| 16×16 在 320px 屏上格太小 | `--cell` 下限 16px，压缩 HUD 与间距；实测 320×568；不做 30×16 |
| 手机误触点开虫格 | 默认 3 颗番茄；长按贴封条；模式切换；踩虫后 350ms 输入锁 |
| 3 条命让扫雷太简单 | 星级与最佳时间仍是目标；经典一命模式作为待确认选项 |
| 首开 3×3 保护改变密度 | 蛀虫总数不变，只把虫移出保护区；布雷在首开之后 |
| 每日种子与首开保护冲突 | 每日局固定起点并预先翻开，开局即安全；棋盘完全由日期种子决定 |
| chord 一次踩到多条虫 | 逐条结算，番茄归零立即停止，不额外惩罚 |
| 错封没有反馈，玩家困惑 | 这是扫雷的正常信息隐藏；提示可翻安全格；不提供「封错」提示 |
| 自动更新在游玩中刷新 | `gbBusy()` 加入 `minesweeper`，读 `__msState()`，`play/pause` 时跳过刷新 |
| 主存档并发覆盖 | 本作只读主存档；金币由父页写入；绝不写 `idle-yueba-save-v2` |
| iframe 关闭后仍在跑 | 依赖 `gbFrameClose()` 的 `src='about:blank'`；页内 `pagehide` 清计时器、暂停音频 |
| 音效叠加过大 | 总输出限幅 0.7、单音 0.03–0.2、并发 ≤8、节点释放 |
| 深色暖色面板文字对比不足 | 所有文字用 `--text` / `--dim`；数字在奶油底上用深棕；不用浅底浅字 |
| 实装前误显示入口 | `hidden:true` 由 `gbRender()` 原生跳过；M5 前不接 `DEX_GAME`；验收第 1 条专门检查 |
| 新增入口影响现有 7 张卡 | 只在 `GB_GAMES` 末尾追加一条；不改渲染逻辑；隐藏项不占位 |
