另两张原图留白更多，必须配合各自的 `crop` 使用，否则看起来比战斗番茄小一圈。

## 各游戏称呼不统一（刻意如此，不要跨游戏统一）

**立绘是三张图，名字随游戏走。** 每个游戏对同一只番茄的叫法可以不同，这是有意的设定，
不要为了「统一」去改别的游戏里的名字；本表只保证「想画番茄时找得到图」。

| 游戏 / 文件 | 本地叫法 | 用到哪张 |
|---|---|---|
| 巴巴博弈 `fight.html` | 代码里目前仍显示**厉害番茄 / 入学番茄 / 大统领番茄**（即上表的战斗 / 常服 / 006） | 三张各自独立，可三选一出战 |
| 幸存者 `幸存者游戏-番茄幸存者/survivor.html` | 普通番茄 / 入学番茄 / 昏睡番茄 / 队长番茄 | 四只角色共用战斗番茄一张图（其余靠色相/亮度变化） |
| 吃豆人 `pacman.html`、`pacman-intro.html` | 键名 `tomato` / `tomatoGreen` / `tomatoRipe`，界面上不显示名字 | 三张都在（`tomato`=战斗番茄、`tomatoGreen`=常服番茄、`tomatoRipe`=006番茄） |
| 掘金 `goldminer.html` | 石像（`STATUE_SRC`），不叫番茄 | 战斗番茄 |
| 月亮摆锤 `moon-swing.html` | 只取剪影轮廓 | 战斗番茄（用的是不带 `.th` 的原图 URL） |

> 幸存者里的「入学番茄」和常服番茄**不是同一只**：它对应 `char_cherry`，英/日/韩名是
> Cherry / チェリー / 체리（樱桃番茄），中文写成「入学」本身是个历史笔误，但按上面的原则不去动它。
