# 「月巴大战丧尸月巴」百巴箱小游戏 · 计划书

> 状态：**已实现**（`pvz.html` + 百巴箱入口；战场为左屋右尸，M1–M4 完成，浏览器实测开局/种植/通关/结算正常）
> 目标：在「百巴箱」新增一款植物大战僵尸式塔防小游戏。植物全部使用**现有带外链立绘的月巴**；僵尸是同一批月巴的**丧尸化形态**（深色遮罩 + 紫色粘液 + 少量血迹），不新增立绘资源。
> 文件名：`pvz.html`；独立存档键：`yueba-pvz-v1`；暂定名「月巴大战丧尸月巴」，百巴箱卡片简称「月巴大战」。

## 二、已核实的事实

这些数字直接决定素材与玩法取舍：

| 项 | 实测/已核实 |
|---|---|
| 带外链立绘的月巴 | **89 只**（`TYPES` + `TYPES2` + `TYPES3`） |
| `img` 字段 / 唯一 URL | 95 处 / **91 个唯一 URL**（小月巴与微笑月巴共图等重复） |
| 图片规格 | 抽样为 **160×160** 缩略图，PNG / GIF / WebP 混合，带透明通道 |
| 动图 | `mb_shui`（睡觉）、`mb_gao`（高）、`mb_ku`（背头）为 **GIF** |
| 外链 CORS | 抽样响应**没有** `Access-Control-Allow-Origin`；运行时不能 `getImageData()` |
| 本地素材 | `月巴放置（图）/月巴` 有 98 张序号 PNG、`新增月巴` 有 11 张，但**网页均未引用**；运行时仍走外链 |
| 复用参考 | `goldminer.html` 已内置完整 `POOL_RAW`（id/name/img/color/shape/rarity），可直接拷贝再裁剪 |
| 现有接入 | `GB_GAMES`、iframe 关闭、`postMessage` 金币、LANG 三级回退、`mainSave.lowPower/muted` 均有现成范式 |

由此得到四条硬约束：

1. **不能用 Canvas 读像素**做抠图或生成丧尸皮肤；只能显示、CSS 滤镜与 CSS mask。
2. **不能把 GIF 画进 Canvas**（只会取当前帧/首帧），植物和僵尸必须保留 DOM `<img>` 才能保住动图。
3. **不做运行时图片处理**；丧尸外观全部由「滤镜 + 遮罩层 + CSS 配件」合成。
4. **外链可能失败**（离线/图床挂掉）；必须有本地 SVG 月巴降级，游戏不能白屏。

| 金币 | `yueba-gold-coins` | `yueba-pvz-coins`（新增一个消息分支） |

2. `I18N_UI`（约 4889 行）追加四语言游戏名。

else if(d.type==='yueba-pvz-coins'){

首页不新增任何计时器、DOM 或样式；`gbFrameClose()` 已能正确卸载。

### 3.2 关闭与暂停

- 关闭：页面内**不做**返回按钮，统一用百巴箱顶部返回条，避免再增加首页消息类型。
- 暂停：`visibilitychange` 隐藏时自动暂停；页面失焦也暂停；恢复需点按，不做自动续跑。
- iframe 被关闭时 `src='about:blank'`，页面内所有 `AudioContext` / `rAF` 随之销毁。

## 四、世界观与美术

### 4.1 场景：月巴后院

- 黄昏到夜色的「月巴后院」：深青草地 + 冷蓝月光 + 一层薄雾，和百巴箱的青色 SF HUD 同色系。
- 网格用细线暗纹，不画满格边框；每行一条极淡的草径，方便手机上看清 5 条通道。
- 左侧是月巴小屋（被啃就输），右侧是丧尸月巴的来路（夜色+紫雾）；丧尸从右向左推进。
- 顶部 HUD：番茄光计数、种子槽、波次进度、暂停。
- 配色：
  - 背景 `#08111a` / `#0d1c24`，草地 `#16332f` / `#1b3d36`
  - 青色 UI `#46e6f2`，月光 `#ffd54f`（少量）
  - 丧尸紫 `#7a4fa8`，粘液深紫 `#4a2a6b`，血迹暗红 `#7e1f2d`

### 4.2 植物：原立绘 + 「种在土里」

- 植物就是月巴本人，不另起皮肤；卡面写月巴原名 + 职业后缀（如「金月巴 · 光匠」）。
- 每株植物下方加一个共用的小土堆/叶托 SVG，让它看起来是「种下去的」而不是贴图。
- 待机：轻微上下呼吸（`transform: translateY`，2.8s 循环）。
- 射击：后坐 1 帧（缩放 0.92 + 后移 3px），枪口一小簇番茄籽碎光。
- 受伤：左右抖动 120ms，叶片掉色；被吃掉：先抖再缩小消失。
- 尺寸：普通植物 100×100 设计像素（格子 120×116）；巨月巴 150×150。

### 4.3 丧尸合成配方（本方案的核心）

同一张月巴立绘，经四层叠加变成「丧尸月巴」：

```html
<div class="zb" data-v="cone">
  <span class="zslime"></span>
  <img class="zimg" src="..." decoding="async" alt="">
  <span class="zblob"></span>
  <span class="zblood b1"></span>
  <span class="zblood b2"></span>
  <span class="zgear"></span>
</div>
```

| 层 | 做法 | 效果 |
|---|---|---|
| 底色压暗 | `filter: grayscale(.35) brightness(.66) contrast(1.1) saturate(.85)` | 深色遮罩，保留轮廓与五官 |
| 紫色浸染 | `.zblob` 纯紫色块，`mix-blend-mode:color`，并用**同一张图作 CSS mask**，只覆盖不透明区域 | 稳定的紫色丧尸肤色；低功耗时退化为纯 filter |
| 粘液 | 脚下 2–3 个紫渐变椭圆 + 下滴小条，`blur(.5px)`，2.6s 滴落循环 | 「从墓土里爬出来」的湿滑感 |
| 血迹 | 2 个小radial-gradient 斑点（嘴角/边缘），暗红 `#7e1f2d`，透明度 0.7 | 只要「一点」，不做血腥 |
| 配件 | 纯 CSS 画：盒盖 / 铁盒 / 报纸 / 杆 / 音响 / 气球 / 王冠 | 一眼区分僵尸职业，且不新增图片 |
| 眼睛 | 精英怪加 1–2 个发光小点 | 夜里可读性 |

要点：

- **CSS mask 用原图 URL**，只借 alpha 通道，不触发 CORS 像素读取；不支持 mask 的浏览器直接走 filter 版。
- 每只丧尸按 `id + 类型` 做固定 seed，粘液位置、血迹位置固定，避免同屏克隆感。
- 丧尸动作：走路左右摇（`rotate ±2deg`）、前倾、啃咬时短促前扑、死亡向后倒并淡出。
- 低功耗：关闭粘液下滴、眼睛发光、死亡倒地动画，保留静态紫化与位置移动。

### 4.4 为什么是「DOM 精灵 + Canvas 弹道」

| 方案 | GIF 动图 | 紫化/遮罩 | 同屏 40 单位 | 结论 |
|---|---|---|---|---|
| 纯 Canvas 预渲染 | 只取一帧，动图全废 | 需烘焙，CORS 不能读像素 | 最省 | **否** |
| 纯 Canvas 每帧 `ctx.filter` | 仍只取一帧 | 可行但每帧滤镜开销高 | 中 | **否** |
| DOM `<img>` + CSS filter/mask | **保留** | 简单、稳定 | 足够（40–50 节点） | **采用** |
| WebGL / 第三方引擎 | 需额外资源管线 | 复杂 | 过剩 | **否** |

所以：

- 植物 / 丧尸 / 种子卡 / 番茄掉落 = DOM；
- 番茄籽、冰屑、爆炸、烟尘、飘字 = 一张覆盖战场的 Canvas；
- 两层共用同一套 1280×720 设计坐标与缩放系数。

## 五、核心玩法

### 5.1 核心循环

```
百巴箱点「月巴大战」
  → 关卡地图（12 关，已通关打勾，下一关高亮）
  → 开局：种子槽里是本关可用植物
  → 战斗：种月巴 → 收番茄光 → 挡丧尸 → 撑到最后一波
  → 结算：首次通关发金币 / 重玩只记成绩
  → 下一关 / 重玩 / 回地图
```

### 5.2 棋盘与操作

- 5 行 × 9 列，设计尺寸 1280×720；格子 120×116，左侧留 90px 给月巴小屋，右侧留 70px 给丧尸来路。
- 操作：
  - 点种子卡选中（再点一次取消），点空格种下；键盘 `1–8` 快速选卡。
  - 铲子按钮：点已种植物铲除，返还 0 光（避免经济循环）。
  - 点飘落的番茄光收集，点击热区放大到 56px；8 秒未收自动消失。
  - 点已种植物显示小信息条（名称/血量/冷却），不弹窗。
- 手机：战场 `touch-action:none`，防止拖动页面；所有可点元素 ≥ 44px。
- 横竖屏：横屏为设计基准。竖屏时先显示「横屏体验更佳」提示层，提供「仍要竖屏」按钮；竖屏下按宽度缩放，HUD 压缩为两行，不隐藏任何功能。

### 5.3 番茄光经济

- 战斗内货币，上限 9999，**不写存档**。
- 开局 50（第 1 关 75）。
- 天降番茄：每 8–10 秒一颗，+25；落点在随机列，落地弹两下后静止。
- 生产者：金月巴（25 / 8.5s）、番茄月巴（50 / 11s）；生产时头顶冒光并「叮」一声。
- 所有价格、冷却写进 `PLANTS` 表，便于一处调平衡。

### 5.4 大巴车清道夫

- 每行末端停一辆「大巴车」（`dabus` 立绘，缩成小车头）。
- 丧尸越过最左格触发：大巴车鸣笛、横扫整行、清掉该行全部丧尸，然后驶出画面，本行永久失去保底。
- 触发时全屏轻震 + 黄色警示闪边；每关最多 5 次。
- 这是「最后一道保险」，不参与星级判定以外的经济。

### 5.5 胜负

| 状态 | 条件 |
|---|---|
| 胜利 | 本关所有波次出完，且场上丧尸清空 |
| 失败 | 某行大巴车已用掉，丧尸走到小屋门口 |
| 暂停 | 手动 / 页面隐藏 / iframe 失焦 |
| 重开 | 结算或暂停菜单，重置本关全部状态 |
| 星级 | 1 星通关；2 星未用大巴车；3 星且没有植物被吃（纯展示，不发额外奖励） |

## 九、技术方案

### 9.1 页面结构

```
pvz.html
├─ <style>  HUD / 种子槽 / 战场 / 丧尸合成 / 结算 / 竖屏提示
├─ <body>   #app > #hud + #field(> #domLayer + #fxCanvas) + #seedbar + #overlays
└─ <script>
   ├─ 常量与设计坐标（W=1280, H=720, ROWS=5, COLS=9）
   ├─ POOL_RAW（从 goldminer.html 拷贝，裁剪到本作用到的 22 只）
   ├─ PLANTS / ZOMBIES / LEVELS / TXT(4语言)
   ├─ 存档（yueba-pvz-v1）与主存档只读
   ├─ 资源预加载 + SVG 降级
   ├─ 战斗引擎（种植 / 经济 / 波次 / 移动 / 碰撞 / 胜负）
   ├─ 渲染（DOM 位置更新 + Canvas 弹道）
   └─ UI（地图 / 选卡 / 暂停 / 结算 / 成就）
```

### 9.2 关键数据结构

```js
const battle = {
  phase:'play',            // menu|play|paused|clear|fail
  level:6, sun:50, time:0,
  cards:[...],             // 本关可用植物
  cooldown:{},             // 植物 id -> 剩余秒
  grid:[],                 // [row][col] -> plant|null
  plants:[], zombies:[], bullets:[], particles:[],
  mowers:[true,true,true,true,true],
  waves:[], nextWave:0, spawned:0,
  stats:{kills:0, eaten:0, mowerUsed:0, sunCollected:0}
};
```

- 植物/丧尸对象只保留数值与 DOM 引用，渲染层不参与判定。
- 每帧只更新 `transform: translate3d(x,y,0)`；不改 `left/top`，避免布局抖动。
- 子弹与粒子走 Canvas，坐标同为 1280×720 设计坐标。

### 9.3 循环与碰撞

- 固定步长 `1/60s`，`rAF` 累加器，单帧最多补 4 步，防止切后台后爆炸。
- 丧尸：按行推进，`x` 递减；碰到本行最靠右的可啃植物 → 停下啃咬。
- 子弹：只在本行内检测，按 x 区间与丧尸碰撞盒相交。
- 抛投：按落点格子结算，命中该格及相邻格的丧尸。
- 爆炸：以格子为中心的 3×3 范围，一次结算。
- 死亡：播放倒地 0.35s 后移除；低功耗立即移除。
- 波次：`nextWave` 计时到点生成；最后一波清空后 1.5s 结算。

### 9.4 资源预加载与降级

- 只预加载本作涉及的 22 张外链（13 植物 + 9 丧尸），约 1MB。
- 每张图 `Image()` 预载，6 秒超时视为失败。
- 失败或离线：用与首页 `fatSVG` 同思路的程序化月巴（圆形/高/扁等 shape + 配色 + 简单五官）作为占位；丧尸版直接叠加紫化 CSS。
- 预载期间可进关，占位先上场，图片到位后原位替换，不重置战斗。
- 图片统一 `decoding="async"`，`draggable=false`，禁止长按菜单。

### 9.5 性能与低功耗

| 项 | 常规 | 低功耗 |
|---|---|---|
| 帧率 | 60 | 30 |
| 粒子 | 爆炸/冰屑/飘字全开 | 只留飘字 |
| 粘液动画 | 开 | 关（静态粘液） |
| 紫化方式 | filter + CSS mask | 仅 filter |
| 丧尸倒地 | 有 | 立即移除 |
| 番茄飞向 HUD | 有 | 直接加数字 |
| 背景 | 两层视差雾 | 单层静态 |

- 同屏上限：丧尸 40、子弹 60、粒子 80；超出不再生成特效，不降逻辑。
- 避免动画 `filter` / `box-shadow`；滤镜只做静态合成。
- 页面隐藏时停 `rAF`，恢复时重置累加器。

## 十、存档、奖励与主游戏接入

### 10.1 独立存档 `yueba-pvz-v1`

```js
{
  v:1,
  cleared:{ 1:1, 2:1 },     // 已通关关卡
  best:{ 1:{time:95,stars:3} },
  rewarded:{ 1:1 },         // 已发过首次金币，防重复
  endlessBest:0,
  ach:{ firstClear:1, noMower:1 },
  stats:{ kills:0, plants:0, sun:0 },
  settings:{ sfx:1 }
}
```

- 读写全部 `try/catch`；损坏则回默认值，不清空主存档。
- 关卡解锁 = `max(cleared)+1`，上限 12；`?debug` 全解锁。
- 不写入主存档任何字段。

### 10.2 主存档只读

| 字段 | 用途 |
|---|---|
| `lang` | 无 `?lang=` 时的语言回退 |
| `muted` | 全局静音 |
| `lowPower` | 默认低功耗 |

### 10.3 金币回传

- 仅在 iframe 内（`window.parent !== window`）且该关未 `rewarded` 时发送：

```js
parent.postMessage({type:'yueba-pvz-coins', coins:n}, '*');
```

- 发送前写 `rewarded[id]=1`；独立打开不发送、不标记，之后在百巴箱里通关仍可领取。
- 重复通关、无尽模式一律不发。
- 首页分支做 0–5000 钳制，沿用 `addCoins + save + toast`。

### 10.4 语言

- 页内 `TXT` 四语言，覆盖：卡名/价格、植物/丧尸名、关卡名、提示、结算、成就。
- `LANG` 优先级与 `goldminer.html` 一致：`?lang=` → 主存档 `lang` → `navigator.language` → zh。
- 月巴原名与四语言名：本作只涉及 22 只，直接手写进 `TXT`，不整表拷贝 `I18N_BANNY`。

### 10.5 音效

- 全部 Web Audio 合成，无音频文件；读取主存档 `muted`。
- 音色清单：种植（土声）、收番茄（双音）、射击（短促 pop）、冰籽（玻璃音）、啃咬（低频锯波）、吞噬、爆炸、大巴车鸣笛、旗帜号角、胜利、失败。
- 同类音效 60ms 内合并，避免 20 只丧尸同帧叠音；低功耗下降低复音数。

## 十二、风险与对策

| 图床挂掉 / 离线 | 植物丧尸全变占位 | 程序化 SVG 月巴降级；预载超时 6s；M4 做断网测试 |
