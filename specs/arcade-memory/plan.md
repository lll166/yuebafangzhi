## 三、玩法与规则

### 3.1 一句话流程

选考级 → 考官月巴宣布开考 → 卡盘亮出 N 对打乱的月巴立绘（卡背盖住）→ 翻两张：**配对成功**保持翻开并连击 +1；**配错即答错，必受罚**→ 全部配对完成「合格」，步数/时间耗尽「不合格」。

### 3.2 考级（难度）与基准数值

| 考级   | 盘面  | 对数 | 限步模式步数 | 限时模式时间 |
| ---- | --- | -- | ------ | ------ |
| 随堂小考 | 4×3 | 6  | 15     | 60s    |
| 单元测验 | 4×4 | 8  | 20     | 85s    |
| 期中考试 | 5×4 | 10 | 26     | 110s   |
| 期末大考 | 6×4 | 12 | 32     | 135s   |

> M3 调参落定：限时高档位收紧（60/85/110/135，约 11s/对，仍是宽松通关预算）。限步模式下每翻一对扣 1 步（成败都算）；限时模式倒计时，答错另扣。

### 3.3 判定规则

- 每回合最多同时翻开 2 张：第 1 张翻开，第 2 张翻开 → 立即判定。
- 配对成功：两张牌定格「配对态」（批改红 ✓ 印章 + 轻微下沉），连击 combo +1。
- 配对失败：**先演惩罚**（见第四节），然后两张牌盖回；连击清零。
- 盘面全部配对 → 合格结算；步数归 0 或时间归 0 → 不合格结算。
- 惩罚演出期间锁输入（约 1s；低功耗模式缩短到 0.3s）。

### 3.4 双模式

- **限步模式**（经典记忆玩法，M2 先实装）：主要压力来自步数预算与惩罚扣步。
- **限时模式**（M3 追加）：步数不限，压力来自倒计时与惩罚扣时；同一考级共用最佳成绩榜（按模式分开记录）。

### 3.5 结算

- **合格**：「成绩单」面板——考级、用时/步数、最大连击、**受罚次数**、本局配到的月巴立绘一览；考官嘴硬祝贺台词。刷新最佳成绩时盖「新纪录」红章。
- **不合格**：考官得意嘲讽台词 + 番茄被弹脑门的像素小动画（一颗番茄被指头弹飞，纯 CSS/SVG，零美术）。
- 开场白：每个存档首次进入播 3 句对话框（可跳过，`introSeen` 标记）。

## 四、惩罚系统（核心特色）

> 人设：考官月巴（默认 **wink 月巴** **`mb_xin`**，可换）主持考试；番茄是考生。答错 = 没认出月巴 = 必须受罚。

### 4.1 惩罚触发（答错必罚，确定性、不可跳过）

每次配错立即依次执行：

1. **嘲讽**：考官席气泡弹出随机嘲讽台词（台词池见附录），考官立绘小幅前倾抖动。
2. **批改**：卡盘上盖一枚「批改红 ✗」印章动画（旋转落下 + 音效，跟随 muted）。
3. **代价**：按模式扣——限步 **-1 步**（额外）/ 限时 **-3 秒**（额外）。
4. **随机小惩罚**（权重池，v1 两种）：
   - **墨渍遮罩**：一块墨渍泼在卡盘上 2 秒，遮住局部牌面；
   - **围观干扰**：一排月巴立绘横幅从卡盘前掠过 1.5 秒（掩护牌面，制造记忆干扰）。
5. **连错 ×3 → 大惩罚「当堂重考」**：所有未配对的牌洗牌重新盖回；考官切换「生气」状态（立绘加红字批改滤镜 + 抖动），台词升级。连击清零。

### 4.2 惩罚体验约束（防挫败）

- 惩罚演出总时长 ≤1s（墨渍/干扰可被玩家无操作等待结束），低功耗模式全部缩短；
- 惩罚**只影响本局资源（步/时）与视野，不追溯存档**；失败只丢当局；
- 惩罚不可关闭（这是本游戏的梗），但演出可在设置里选「快速模式」。

### 4.3 连击

- 连续配对无错 = combo，UI 显示 ×N；combo 仅计入结算与「新纪录」，v1 **不发奖励**（M6 预留奖励挂钩）。

## 五、视觉与 UI

### 5.1 风格总则

**浅色像素**：奶油试卷纸底 + 墨色线条/文字 + 批改红为强调色；全部直角/切角，无圆角无渐变投影，`image-rendering:pixelated`；纸面点状纹理用 CSS 生成，零图片。

| Token      | 值                    | 说明                  |
| ---------- | -------------------- | ------------------- |
| `--paper`  | `#F5F0E6`            | 纸面（与 diner 默认奶油纸同族） |
| `--paper2` | `#E8E1D1`            | 面板/卡底               |
| `--ink`    | `#2B2723`            | 主墨色（文字/边框/卡背）       |
| `--ink2`   | `#6E6459`            | 次级文字                |
| `--accent` | `#D25B45`            | 批改红（✗/✓/新纪录章/惩罚高亮）  |
| `--ok`     | `#5D8F78`            | 合格章绿                |
| `--line`   | `rgba(43,39,35,.30)` | 描线                  |

### 5.2 布局（借 snake / survivor 结构，不借配色）

- **顶部 HUD**（照 snake 同构）：左品牌「月巴记忆」；中部 `PAIRS x/y` + `步数|时间` + `COMBO`；右 BEST、暂停。方形窗口、等宽字体栈（SF Mono/Cascadia/Consolas + 中文字体），不做点阵中文字库。
- **考官席**：卡盘上方一条横栏——圆框考官立绘（图鉴外链图）+ 名牌「监考：wink月巴」+ 台词气泡（惩罚/开场白/结算都走这里）。
- **卡盘**：切角面板包住的方格 grid；卡背 = 墨色对角纹 + 中央「？？」（纯 CSS，零美术）；卡面 = 外链立绘 `object-fit:contain`（不裁切、不显示名字——名字会剧透且遮挡）。
- **底部**：考级选择 + 模式切换 + 重开；「返回百巴箱」由父页内嵌栏负责（照既有 iframe 约定）。
- **320px 竖屏可玩**：卡盘自适应缩放，HUD 折行规则照 snake 的 narrow 分支。

### 5.3 动画

翻牌 CSS 3D flip（0.25s）、配对 ✓ 下沉定格、惩罚印章旋转落下、墨渍 fade、失败弹脑门（番茄飞出）。低功耗（父页下发 `lowPower` 或 `prefers-reduced-motion`）时：去抖动、去印章弹跳、缩短演出。

## 六、数据、接入与同步

### 6.1 立绘数据（零美术的关键）

- `memory.html` 内置 `DEX_ART` 表：`{id, name, color, url}`，来源 index.html `TYPES/TYPES2/TYPES3` 中有外链立绘的条目（约 127 只），口径与 `pacman.html` 完全一致。
- **扩展** **`sync-dex-art.js`**：目标从单文件 `pacman.html` 改为多目标（pacman + memory），`--check` 同步支持；沿用防误删护栏（<50 条中止）。
- 每局从池中随机抽 N 只组成 N 对；卡面 `<img loading="lazy">`，`onerror` 兜底：改画 `color` 色块 + 名字首字（游戏照常可玩）。

### 6.2 百巴箱接入（实装前不显示）

1. `GB_GAMES` 末尾追加（`hidden:true` 期间零影响）：
   `{id:'memory', codex:'mb_xin', name:'?? 月巴记忆', sub:true, html:'memory.html', hidden:true},`
2. `GB_FRAME_SEED` 增加 `memory:'mem'`；`index.html` CSS 增加 `#gbGameOverlay.t-mem{…}` 试卷纸浅色主题（照 `.t-diner` 写法）。
3. 子页载入后 postMessage 自报色系 `t-mem`（俄罗斯巴块先例）。
4. **M5 验收通过后删除** **`hidden:true`** **即上线**（与螺旋跳/月巴蛋同一流程）。

### 6.3 名册桥（M4）

- 子页请求 → 父页回（照螺旋跳/食堂写法）：
  `{type:'yueba-memory-roster', list:[{id,name,color,art}], muted, lowPower, lang}`；
- list 只含**已解锁**的月巴（`colCount(id)` 口径）——进阶玩法「考的只是番茄认识的月巴」；离线/独立打开时回退内置 `DEX_ART` 全量池；
- 语言、静音、低功耗随桥下发；多语言文案对齐 tamago 口径（zh/en/ja/ko，M5 补齐）。

### 6.4 存档

- 独立键 `yueba-memory-v1`：`{best:{step:{…},time:{…}}, stats:{clears,fails,penalties,maxCombo}, settings:{mode,diff,quick}, introSeen}`；
- 不写、不改 `idle-yueba-save-v2`；iframe 内 localStorage 异常时静默降级为不存档（既有子页同模式）。

## 九、风险与预案

| 风险                                  | 预案                                                                         |
| ----------------------------------- | -------------------------------------------------------------------------- |
| picgo 外链图床不稳定/失效                    | 卡面 onerror 兜底色块 + 名字首字，游戏规则不受影响；`sync-dex-art.js --check` 每次同步立绘可发现 URL 变更 |
| GIF 立绘较多时性能                         | 单局上限 12 对，gif 占比天然有限；`loading="lazy"`；gif 无法暂停为已知限制，低功耗模式不再追加处理            |
| 127 只立绘风格/尺寸不一                      | 卡面统一纸底 + 墨框衬托，`contain` 不裁切；不显示名字避免遮挡                                      |
| 惩罚过挫败                               | 演出 ≤1s、代价固定且可预期（-1 步/-3s）；失败只丢当局；「快速模式」可选                                  |
