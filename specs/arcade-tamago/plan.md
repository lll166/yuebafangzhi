# 「月巴蛋」拓麻歌子式养成小游戏 · 计划书

> 版本：v1.0（2026-10-26）
> 状态：**计划中（未实装）**
> 目标：在「放置月巴」的百巴箱新增一台单色像素电子宠物「月巴蛋」；实装完成前，百巴箱内**不显示**该卡片。

## 三、叙事与主题

### 3.1 一句话

> 你在桌上养一只虚拟月巴。它吃不了番茄，也不会真的饿。可庭院里那些真月巴会走过来，隔着玻璃看它，然后嘲笑你。

### 3.2 三层反差

| 层 | 内容 |
| --- | --- |
| 表层 | 一台廉价的电子宠物机：三个按键、一块单色屏、几颗心 |
| 中层 | 你养的月巴是「已开启图鉴」里随机抽出的，它认识，但没法回应 |
| 里层 | 真月巴吃番茄、会偷番茄、会旅行；虚拟月巴连番茄都不吃。它们因此看不起你和它 |

### 3.3 基调

- 冷幽默、短句、轻微冒犯，但不恶毒；嘲讽的是「人类对假东西认真」这件事，不是玩家本人。
- 庭院月巴的台词像在参观一件无聊展品：看完、点评、走人。
- 电子月巴几乎不说话，只用「……」「？」和动作回应。
- 不卖萌过度，不用感叹号堆情绪；死亡场景不煽情，只关机。

### 3.4 主题映射

| 拓麻歌子概念 | 本作表现 |
| --- | --- |
| 蛋 | 三枚一模一样的蛋，外壳有编号 1/2/3 |
| 孵化 | 蛋壳裂开，月巴从像素噪点里「渲染」出来 |
| 喂食 | 空白饼（0）／数据粒（1）；番茄按钮永远被拒 |
| 清洁 | 扫掉屏幕底部的像素便便与苍蝇 |
| 游戏 | 接月巴球：三回合节奏条 |
| 生病 | 屏幕出现「×」图标、抖动、黑边；吃药或抢救 |
| 死亡 | 屏幕逐行关机，留下墓碑记录 |
| 庭院访客 | 真月巴走到玻璃外嘲讽，可敲玻璃或无视 |

## 四、核心循环

```
开机 → 三枚蛋 → 选一枚 → 长按孵化 → 幼体
   ↑                                  ↓
新蛋 ← 归档/死亡 ← 成体 ← 成长期 ← 喂/摸/玩/清/灯/药
                                      ↓
                              庭院月巴来访嘲讽（随机间隔）
```

### 4.1 三个蛋的规则（已确认：三选一，其余封存）

- 首次进入：三枚蛋同屏、外观一致，只有底部编号不同。
- 每枚蛋在**首次进入时就完成抽签**并写入存档，关掉页面再开不会重摇。
- 三枚蛋优先抽不同物种；可抽池不足 3 种时允许重复，但会在孵化页标注「重复」。
- 只能孵化一枚。选定后另外两枚变暗并加一条裂纹贴纸，不能再点。
- 只有**蛋位为空**（当前月巴死亡或毕业归档）时，才能开下一枚封存的蛋。
- 孵化需要长按 B 键 1.2 秒，防误触；松手会回弹。
- 孵化演出约 3 秒：裂纹 → 白光 → 像素块拼合 → 名字牌 → 稀有度。可按 B 跳过。

### 4.2 抽签池

- 池 = `list`（父页下发的已解锁月巴，`colCount(id)>0`，含第三图鉴）。
- 权重：均匀。稀有度 `r` 只用于展示与归档评分，不改变概率，避免「越稀有越难养」的双重惩罚。
- 图鉴为空（新号直接进百巴箱）：借用 `mb_xiaoyue / mb_xian / mb_chi` 三只做样机，并在名字牌标注「样机」；样机不进入归档、不参与毕业。这样不会白屏，也不伪造解锁。
- 抽到 `shape` 未知的新月巴：回退 `round`，名字照常显示。

### 4.3 阶段与时间

| 阶段 | 进入条件 | 特征 |
| --- | --- | --- |
| 蛋 | 初始 | 不可互动，只能孵化 |
| 幼体 | 孵化后 | 饿得快、便便勤、动作幅度大 |
| 成长期 | 存活满 2 小时 | 食量稳定，开始出现性格小动作 |
| 成体 | 存活满 120 小时  | 可参加毕业归档 |
| 毕业 | 成体 + 亲密度 ≥ 60 + 当前无病 | 可主动「归档」，蛋位空出 |
| 死亡 | 健康归零 | 不可逆，蛋位空出，记录进墓碑 |

> 时间按真实时间累计，但离线只结算到 12 小时上限（见 §6.4）。

## 五、系统与数值

### 5.1 四项主数值

| 数值 | 范围 | 初始 | 自然变化（清醒） | 睡眠时 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 饱食 | 0–100 | 70 | −1 / 6 分钟 | −1 / 12 分钟 | <15 触发生病判定 |
| 心情 | 0–100 | 70 | −1 / 8 分钟 | 不减 | 饱食或清洁 <15 时改为 −1 / 4 分钟 |
| 清洁 | 0–100 | 80 | −1 / 10 分钟 | 不减 | 每 90–120 分钟掉一坨便便，最多 3 坨 |
| 健康 | 0–100 | 100 | 仅生病时 −1 / 5 分钟 | 同左 | 归零即死亡 |

隐藏值：亲密度 0–100（初始 0）。

### 5.2 行动表

| 行动 | 位置 | 效果 | 冷却 | 反馈 |
| --- | --- | --- | --- | --- |
| 喂·空白饼 | 喂食菜单 | 饱食 +18；心情 +2 | 45 秒 | 三口咀嚼，饱食条跳动 |
| 喂·数据粒 | 喂食菜单 | 饱食 +10；心情 +5；亲密度 +1 | 30 秒 | 小 0/1 从上方落下 |
| 喂·番茄 | 喂食菜单第 3 项 | **必定失败**；心情 −3；亲密度 +1 | 20 秒 | 月巴扭头，屏幕显示「0」；若访客在场追加专用台词 |
| 摸头 | 点宠物本体 | 心情 +2；亲密度 +1 | 20 秒 | 眯眼、前倾 1px、头顶爱心 |
| 小游戏 | 玩菜单 | 三回合节奏条，成功心情 +8／失败 +1；亲密度 +3／+1 | 5 分钟 | 回合音、命中闪光（低功耗改为纯反色） |
| 清洁 | 清洁菜单 | 清洁 +15，移除一坨便便；无便便时 +3 | 10 秒 | 扫帚扫过、便便碎成像素 |
| 开／关灯 | 灯光菜单 | 切换睡眠；睡眠中关灯每小时健康 +2 | 无 | 屏幕整体反色／暗一档 |

| 归档 | 状态页（满足条件时） | 写入本地相册，蛋位清空 | — | 外壳断电 1.5 秒，记录卡滑出 |

> 防刷：同类互动每分钟最多计入 6 次亲密度；超出只给动画不给数值。

### 5.3 生病与死亡

| 阶段 | 触发 | 表现 | 处理 |
| --- | --- | --- | --- |
| 隐患 | 饱食 <15／清洁 <15／便便 ≥2，持续 20 分钟 | 宠物动作变慢，偶尔冒汗滴 | 喂或清即可解除 |
| 生病 | 隐患持续 30 分钟 | 头顶「×」，心情掉速翻倍，不能玩／不能毕业 | 吃药 1 颗即愈 |
| 重症 | 生病后健康 <35 | 屏幕每 6 秒抖 2px，四周黑边，心跳音 | 60 分钟内吃 2 颗药；或反复按 B 抢救 |
| 死亡 | 健康 = 0 | 屏幕逐行关闭 → 只剩一颗心 → 黑屏 | **不可逆**；不能复活、不能读档挽回 |

- 死亡不会静默发生：离线期间健康最低压到 1，回到页面后若处于重症，给 **60 秒抢救窗口**（连按 B 8 次）。失败才死亡。
- 死亡后展示「墓碑卡」：物种名、活了多久、亲密度、被嘲讽次数、死因（饿／脏／忽视）。可截图留念。
- 死亡音效只保留一声低音「嘀——」，不做长混响。

### 5.4 离线结算

- 读取 `lastSeen`，最多结算 12 小时；超过部分丢弃。
- 离线期间饱食／心情／清洁按 **60% 速率**衰减，避免回来必死。
- 健康在离线期间最低 1，不触发死亡（见 §5.3 抢救窗口）。
- 回来先播「重新通电」0.8 秒，再一次性落到当前值；不做逐分钟补算动画。

## 六、庭院月巴来访（核心内容）

### 6.1 触发

- 孵化完成后 **45 秒**必来第一次（保证玩家看到核心梗）。
- 之后每 3 分钟检查一次，35% 概率触发；两次之间至少隔 8 分钟。
- 同时最多 1 只访客；睡眠中不来访（避免打断关灯）。
- 数据源：父页 `S.travel.yardIds`（庭院当前 3 只），过滤掉最近 2 次来过的；不足时从已解锁名册随机补。
- 庭院为空：不生成访客，改为屏幕上飘过一行「今天没人来看你。」（也算一种嘲讽）。

### 6.2 演出

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 入场 | 2.4 秒 | 从屏幕左／右侧一颠一颠走进来，宠物转头看它 |
| 开口 | 0.3 秒 | 对话气泡从玻璃外弹出（LCD 内排版，单色描边） |
| 停留 | 12 秒 | 玩家可按 B 敲玻璃（最多 3 次）、按 C 无视 |
| 退场 | 1.8 秒 | 说一句收尾，原路走出；宠物目送 |

### 6.3 互动结果

| 操作 | 结果 |
| --- | --- |
| 敲玻璃 ×1–3 | 访客回一句更欠的台词；宠物跳一下；第 3 次后访客提前退场 |
| 无视（C） | 访客自嘲一句后离开；宠物松一口气 |
| 访客走后摸头 | 心情 +5，宠物「装作不在意」动画 |
| 访客在场时喂番茄 | 触发专属台词「你居然真的喂了」 |

数值上只影响心情：首次被嘲讽 −2；敲满 3 次 +4（出气）；其余不变。**不扣金币、不扣番茄、不写主存档。**

### 6.4 台词池（首批，四语言在实装时补齐）

**开场嘲讽（10）**

1. 「你这只，连番茄都不吃。也算月巴？」
2. 「你在这里养着它的时候，我已经在庭院里吃掉了番茄。」
3. 「它才不会饿，都是假的。」
4. 「人类真可怕，对着一串数据这么上心。」
5. 「它眨眼睛是画出来的。」
6. 「觉得它很丑吗？」
7. 「你说它叫什么？真的假的……」
8. 「它不会死吧？哦，会。那更没意思了。」
9. 「别养了。来庭院陪我。」
10. 「就按下面那三个按钮？好廉价的爱。」

**敲玻璃反应（3）**

- 「别敲了，它听不见。」
- 「玻璃上全是你的指纹，真脏。」
- 「吵死了，再敲，我就把你的番茄吃了。」

**无视反应（3）**

- 「……行吧。你继续。」
- 「哦，那我走了。」
- 「人类真是没意思。」（说完直接走）

**退场（3）**

- 「回来的时候见。」
- 「我明天再来看看，你肯定已经把它养死了。」
- 「这种东西还是赶紧关机吧。」

**特殊（4）**

- 喂番茄：「你居然真的喂了假的番茄……」
- 生病：「它病了。你连个假货都养不好。还好我们会自己去找番茄吃，不会被你养死。」
- 重症：「要关机了，还能救吗？」
- 死亡之后（下一次开机）：「看，关机了。我就说嘛。」

### 6.5 电子月巴的回应

只用极短符号，保持「机器不会说话」的设定：

| 场景 | 显示 |
| --- | --- |
| 被摸 | 「……」「（靠过来）」「？」 |
| 被喂番茄 | 「？」「（扭头）」「……不」 |
| 生病 | 「（缩成一团）」 |
| 被嘲笑 | 「……」+ 低头 |
| 敲玻璃后 | 「！」+ 跳一下 |

> 中文括号动作用小号字显示在气泡第二行；名词与系统文案走四语言表。

## 七、界面与像素规格

### 7.1 整体形态

- 整页即一台电子宠物机：**外壳 360px 宽、高约 500px**，居中；手机竖屏优先，窄屏时整机等比缩放（320px 宽下约 0.84×）。
- 屏幕：逻辑 **160×144**，整数倍 2× 放大到 320×288；`image-rendering:pixelated`。
- 屏幕下方三颗实体按键：`A`（左／切换）、`B`（中／确认·互动）、`C`（右／取消·无视），直径 54px，触控热区 60px。
- 外壳底部留一条窄标签，印机型名「BANNY TAMAGO · MODEL 01」，不参与交互。
- 无圆角滥用：外壳 26px 圆角；屏幕内框 6px；面板直角或 2px 切角。与贪吃蛇／幸存者共用「顶部状态条 + 方形窗口 + 切角面板」的节奏，但形态改成塑料玩具。

### 7.2 屏幕布局

```
┌──────────────────────────┐ 160×144
│ ♥♥♥♡   R2   AGE 03:12    │ 顶部状态行（8px 图标 + 位图数字）
│                          │
│        [宠物 32×32]      │ 主舞台
│                          │
│  · · ·  便便 / 苍蝇      │ 地面
│  ┌────────────────────┐  │
│  │ 对话气泡（DOM 文本） │  │ 仅在事件时出现，最多两行
│  └────────────────────┘  │
│  [喂] [玩] [清] [灯]      │ 底部图标行（4 个 16×16）
└──────────────────────────┘
```

- 主舞台宠物按 2× 或 3× 绘制（32×32 → 64/96px），只允许整数倍。
- 便便最多 3 坨，固定在底部左／中／右三个槽位，避免随机位置压到对话。
- 对话气泡**不遮住宠物脸**：优先放在宠物下方；下方拥挤时放到上方。

### 7.3 单色与配色

- 每套主题只有 5 个颜色令牌：`shell`（外壳）、`bezel`（内框）、`lcdBg`（屏幕底）、`ink`（墨色）、`ghost`（50% 网点）。

### 7.4 像素资源

- 所有图形用 JS 内的 ASCII 点阵表定义，例如：

```
PIX.pet.round = [
  '....########....',
  '..############..',
  '.#............#.',
  ...
]
```

- 身体：按 `TYPES.shape` 提供 13 套 32×32 轮廓（`round / wide / squish / heart / tall / cube / drop / moon / spike / star / rainbow / big / bean`），未知回退 `round`。
- 表情：4 种眼睛（圆点／竖椭圆／菱形／横线）× 4 种嘴（波浪／圆／方／横线），由 `id` 的哈希决定，保证同一只每次都一样。
- 附加件：蛋（24×32）、裂纹、便便（8×8）、苍蝇（4×4）、爱心（7×7）、药丸（8×8）、「×」病标（8×8）、4 个菜单图标（16×16）、3×5 位图数字。

### 7.5 文本策略（重要）

- **图形与数字**用点阵绘制；**自然语言**（台词、菜单名、状态说明）用等宽系统字体排在 LCD 内。
- 原因：中日韩三语点阵字库体积大、授权复杂、离线不可靠；用单色等宽排版同样能保持「屏幕里的字」观感。
- 规则：字体 `"SF Mono","Cascadia Mono",Consolas,"PingFang SC","Microsoft YaHei",monospace`；字号 11–13px；颜色只用 `ink`；不使用文字阴影；行高 1.35；气泡最多 2 行，超出用「……」截断。
- 位图数字用于年龄、时间、心数、金币式的计数，保证「机器感」。

### 7.6 动效

| 事件 | 表现 | 时长 |
| --- | --- | --- |
| 待机 | 呼吸 1px、3–6 秒随机眨眼 | 循环 |
| 选择蛋 | 该蛋左右摇 2px，其余不动 | 0.3 秒 |
| 孵化 | 裂纹 3 段 → 反色闪 2 次 → 像素拼合 | 3 秒 |
| 喂食 | 食物从上方掉到嘴边，咀嚼 3 下 | 1.2 秒 |
| 摸头 | 前倾 1px、眯眼、爱心浮起 | 0.6 秒 |
| 清洁 | 扫帚横掠，便便碎成 6 个像素 | 0.8 秒 |
| 生病 | 屏幕抖 2px、黑边呼吸 | 每 6 秒 |
| 死亡 | 逐行关闭（每行 40ms）→ 黑屏 | 2.6 秒 |

- 不使用 `requestAnimationFrame` 常驻循环；待机动画用 250ms 定时器按需重绘，有动效时才开 rAF。

### 8.1 卡片配置

在 `GB_GAMES`（`index.html` 约 L14804）新增一条，**先隐藏**：

```js
{id:'tamago', codex:'mb_xiaoyue', name:'🥚 月巴蛋', html:'tamago.html', hidden:true},
```

- 图标：`fatSVG(typeById('mb_xiaoyue'))`，无需新图。
- 卡片副标题：`gbsub` 自动显示「小月巴」，符合现有规则。
- 不加入 `DEX_GAME`：首版没有图鉴专属入口，避免多一个未完成入口。
- 不加入 `gbBusy()` 自动更新白名单：本作不写主存档，首页刷新不会丢进度以外的状态。

### 8.2 名册桥（沿用螺旋跳的现成模式）

子页加载完成后发：

```js
window.parent.postMessage({type:'yueba-tamago-ready'}, '*');
```

父页在现有 `message` 监听（约 L14952）新增分支：

```js
}else if(d.type==='yueba-tamago-ready'){
  if(!e.source) return;
  const tv=S.travel||{};
  const list=fgAllTypes().filter(function(t){ return colCount(t.id)>0; }).map(function(t){
    return {id:t.id,name:t.name,color:t.color||'#8fb3a6',shape:t.shape||'round',r:t.r||1};
  });
  const yard=(tv.yardIds||[]).filter(function(id){ return !!typeById(id); });
  e.source.postMessage({
    type:'yueba-tamago-roster',
    list:list,
    yard:yard,
    tomato:tv.tomato||0,
    muted:!!S.muted,
    lowPower:!!S.lowPower,
    lang:curLang()
  }, '*');
}
```

- `name` 直接用 `t.name`：`heal()` 已在运行期做本地化，子页无需再查表。
- `yard` 用 `S.travel.yardIds`，不触发庭院刷新，纯只读。
- 子页若 2 秒没收到回包，重发一次 `ready`，最多 3 次；仍未收到则用样机三只进入离线模式（并提示「未连接到主游戏」）。
- 安全：沿用现有 `e.origin` 校验；子页只接受 `type` 完全匹配的消息。

### 8.3 关闭

- 关闭仍走 `gbFrameClose()`；子页 `beforeunload` / `visibilitychange` 时立即存盘，不做异步等待。
- 关闭后必须清掉所有定时器与 AudioContext，防止叠后台计时。

## 十四、风险与对策

| 风险 | 对策 |
| --- | --- |
| 单色导致不同月巴难以区分 | 13 种轮廓 + 稀有度 + 名字牌 + 孵化剪影；不靠颜色 |
| 手绘 13 套轮廓工作量大 | 先做 6 套（round/wide/tall/drop/star/spike），其余回退 round，后续补 |
| 离线死亡引发挫败 | 离线健康压到 1 + 回归 60 秒抢救；死亡前有黑边、心跳、台词预警 |
| 访客数据拿不到 | 父页未回包时重试 3 次，再退样机；不影响主循环 |
| 中文点阵字库不可行 | 图形用点阵、语言用单色等宽文本；保观感不保字库纯度 |
| iframe 内存／计时器泄漏 | 隐藏即停、卸载清空、存盘同步 |
| 玩家把「毕业」误当死亡 | 毕业用归档卡＋彩色（墨色）印章；死亡用关机＋墓碑，文案完全分开 |
| 三蛋抽到重复物种 | 池不足 3 种才允许，重复时在孵化页明示，不暗改概率 |
