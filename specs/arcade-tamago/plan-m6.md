> 版本：v1.2（2026-10-30）

## 0. 结论

M1–M5 把「能玩」做完了，但还有四类明显缺口，按优先级排：

1. **P0 收尾**：卡片还没上线；访客池有一个越界回退；存档损坏没有按计划备份；回归脚本不在仓库。
2. **P1 养成深度**：现在只有线性数值 + 固定三段成长，养成质量不影响结局形态；没有命名、没有统计页。
3. **P2 访客叙事**：访客只有「嘲讽→敲玻璃/无视→离开」一条线，没有记忆、礼物、事件，长期会腻。
4. **P3 主游戏联动**：毕业只进本作相册，不回流金币/图鉴/番茄；云存档也不覆盖本作。

建议顺序：**P0 → P1 → P2 → P3 → P4**。P0 一天内可完成；P1 是投入产出比最高的一段。

## 2. P0 · 收尾与缺陷（0.5–1 天）

### 2.1 上线开关（本次暂缓）

- `index.html` 的 `GB_GAMES` 中 `tamago` 仍是 `hidden:true`（约 L15187）。按用户要求**本次不删除**。
- **新发现的阻塞项**：卡片写的是 `html:'tamago.html'`（仓库根目录），真实文件在 `电子宠物游戏-tamago/tamago.html`。上线前必须二选一：把文件放到根目录，或把卡片路径改成子目录路径；否则点开是 404。
- 验收（上线时）：从百巴箱进入/关闭正常，关闭后 iframe 无残留计时器。

### 2.2 访客池越界回退（真实 bug）

`visitorPool()`（约 L1958）在「庭院有 1–2 只，且都在最近 2 次记录里」时会落到全名册：

```js
for (yard) add(...);                 // 全被 recent 过滤掉
if(!out.length && ROSTER.length) ... // ← 越界到全名册
```

后果：庭院只有 1–2 只时，第三次来访会抽到不在庭院里的月巴，违反「访客只来自庭院当前 3 只」。

修法：记录 `yardCount`；yard 非空时，回退只允许在 yard 内重抽（忽略 recent，取最久没来的），**不得**落到 `ROSTER`。`ROSTER` 兜底只在 yard 为空且非样机时保留现状（即返回空，走「今天没人来看你」）。

验收：构造 yard=1/2/3 三组，连续来访 6 次，访客 id 始终属于 yard。

### 2.3 死字段二选一

- `TOMATO`（L928/L956）从父页收到后从未使用。
- `careCount`（L2625）定义后从未累加。

建议：P1 做统计页时装上 `careCount`；`TOMATO` 在访客喂番茄时显示「你的番茄：N」，或直接删除，避免“看起来实现了其实没有”。

### 2.4 存档健壮性

计划书 §9.2 要求「损坏时备份到 `yueba-tamago-v1-broken` 再开新档」，当前 `loadState()`（L558）只 `catch` 后重置，没有备份；`state.v` 也固定写 1。

动作：
- 解析失败时先把原串写入 `yueba-tamago-v1-broken`，再重置。
- 新增 `migrateSave()`：按 `v` 递增迁移，M6 起 `v:2`。
- `ensurePet()` 继续做数值兜底（已有，保留）。

验收：手工写入坏 JSON，刷新后原串仍在 broken 键里，游戏可正常开局。

### 2.5 回归脚本入仓

M3–M5 的测试都在 `%TEMP%`，换机器不可复现。动作：把 `tamago-m3/m4/m5` 与 visitor-art / art-pixel / noflash 脚本收进 `specs/arcade-tamago/tests/`（或根目录 `_tamago_test.js`），补一个 `README` 说明端口与启动方式。

### 2.6 小体验缺口

- 相册只能 A 倒序翻，建议 A 正序、C 上一张，或 A/B 双向。
- 独立打开时无法静音；建议 `M` 键或点击品牌切换静音（父页 `muted` 仍优先）。
- 没有重置存档入口；建议三击品牌 → 确认清档（仅独立打开时显示）。
- 没有新手引导（计划里的 `tutorialDone` 未落地），见 P4。

## 3. P1 · 养成深度（2–3 天，最高优先级）

目标：让「怎么养」影响「养出什么」，而不是只影响数值条。

### 3.1 状态氛围（原「状态驱动表情」已按用户要求替换）

**不加表情**，五官保持 `drawFace()` 原样。改为环境粒子：
- 心情高时按性格偏好随机冒爱心 / 小花 / 星星
- 摸头冒爱心、正常喂食冒小花、小游戏表现好冒星星、抢救成功冒爱心
- 低心情、生病、重症、睡眠、页面态、访客在场、低功耗一律不冒

验收：高心情能看到粒子，低心情/低功耗没有；`drawFace` 不引用 mood/hunger/clean。

### 3.2 养成质量决定成体形态（已完成）

现状 `refreshStage()` 只按时间切 baby→grow→adult，所有成体一样。

动作：记录幼体期（0–2h）的照顾质量：
- `avgHunger / avgMood / avgClean`（`simulateStep` 里按分钟累计）
- `sickCount`（每次进入生病 +1）
- 结局分三型：`plump`（吃得好、少生病）/ `lean`（常饿、常脏）/ `stubborn`（心情长期低、被嘲多）

表现层不改物种，只改：
- `SHAPE_GEOM` 的缩放/偏移（例如 plump 横向 ×1.06，lean 纵向 ×1.06）
- 成体加一个像素小装饰（围巾/呆毛/斑纹），用 `PIX` 点阵叠加
- 状态页显示「成体 · 圆润/精瘦/倔强」

验收：同一物种两种极端养法，成体轮廓/装饰不同；老存档无质量数据时默认 `plump`。

### 3.3 过喂惩罚（已完成）

现状喂食只加数值，没有代价。动作：`confirmFeed` 记录最近 10 分钟喂食次数，超过 3 次时：
- 本次饱食收益减半
- 心情 -3
- `poopAcc` 加速
- 弹一句「它吃撑了」

验收：连续喂 4 次，第 4 次有明确负反馈；正常节奏不受影响。

### 3.4 真实昼夜（可选，本次未做）

动作：22:00–07:00 自动入睡，07:00 自动醒；玩家仍可用「灯」手动覆盖一次。离线跨夜按睡眠速率结算（`simulateStep` 已区分 asleep）。

风险：玩家白天没空时可能错过互动。建议做成「自动作息」开关，默认关，避免打断现有节奏。

### 3.5 命名（已完成，按用户改为好感解锁）

- 好感达到本性格阈值后才解锁：黏人 40 / 慢热 50 / 傲娇 60；性格由物种哈希固定。
- 入口在「详情」页：状态页 A → 详情，详情页 B → 取名；A 换候选名、B 确定、C 再说。
- 存 `pet.nickname`，状态页/主屏/死亡与毕业卡/相册优先显示昵称；物种名保留在 `pet.name`。
- 候选名按语言各 3 个，不接输入法。验收：四语言下不溢出；同一物种阈值固定。

### 3.6 统计/日记页（已完成）

- 导航：状态页 A → 详情页 → 相册；详情页 B 取名/返回，A 相册，C 退出。
- 详情页 5 行数据 + 按键提示：名字/阶段/年龄、亲密/最高/性格、喂/玩/净/摸、药/救/客/病、照顾/被嘲。
- 缺「最长不生病时长」，用生病次数替代；`careCount` 与分类统计已埋点。

验收：数值随操作即时增长，死亡/毕业后写入相册记录。

## 4. P2 · 访客叙事（1.5–2 天）

访客是本作的核心差异点，建议优先于“更多小游戏”。

### 4.1 常客系统（已完成）

- 保留 `visitLog: string[]` 给「最近 2 只不复用」用，兼容 M4 回归；新增 `state.visitorSeen = {id:{count,lastAt}}` 做累计。
- 同一只来访 ≥5 次 → 台词池切换为「常客」语气（更软、少嘲讽），心情 +1、不计被嘲。
- ≥10 次且到 10 的整数倍 → 带礼物，心情 +5、亲密 +1，不计被嘲。
- 记录页显示「名字 ×N + 最后一次时间」。

### 4.2 访客事件（部分完成）

- **带礼物**：已完成，走专属台词 + 心情/亲密奖励。
- **偷番茄**：已完成，连续无视 3 次后下一次来访说「你的番茄我拿走了」，不真扣。
- **节日/季节、雨天**：本次未做，留给后续；需要节日台词表和天气判断。

### 4.3 分层的离线台词（已完成）

按原始离线时长分 1 天 / 3 天 / 7 天三档；`fmtGap` 支持「天 + 小时」。切回标签页超过 1 小时也会补一句。

### 4.4 睡眠梦境（已完成）

睡觉时除了 Z，还会每 2.6 秒轮换一个爱心/小花/星星；低功耗关闭。没有做番茄/访客剪影。

### 4.5 访客记录页（已完成）

相册页按 B 进入第二 tab：来访记录，列出前 4 位访客的名字、次数、最后一次相对时间；数据来自 4.1。

### 5.1 毕业/死亡回写（已完成）

- 子页毕业时发 `yueba-tamago-graduate`，id = `tg-{endedAt}-{species}-{bond}`。

- 死亡不发金币；样机模式不发。

验收：同一记录重复发送只发一次；父页读档后去重表仍在。

### 5.2 番茄真实消费（本次未做）

### 5.3 云存档覆盖本作（本次未做）

当前云存档只存主存档 blob，`yueba-tamago-v1` 仍不在其中。`S.tamago` 已存在（毕业去重），但没有合并本作完整存档；需要额外的 `save-get/put` 与冲突策略，留待后续。

### 5.4 番茄钟联动（已完成）

- 父页 `pomoStart/Pause/Resume/Stop/EnterBreak` 向月巴蛋 iframe 发 `yueba-tamago-focus`。
- 子页专注期间心情不下降、访客不打扰，主屏显示「专注中 · 它陪着你」。
- 结束时按实际分钟数显示「它陪了你 N 分钟」。
- 打开/重开 iframe 时，roster 带 `focus/focusMins`，状态自动恢复。

## 6. P4 · 工程与体验打磨（已完成主要项）

- **存档版本化**：`v:2` + `migrateSave()`，P0 已完成。
- **仓库内自动化测试**：`p0`–`p4` 五个源码守卫 + 运行时套件。
- **无障碍**：`S` 键打开状态页；按键/色板 `:focus-visible` 描边；canvas 的 `aria-label` 跟随名字/阶段/病情/蛋屏摘要。
- **触觉**：敲玻璃 10ms / 抢救 8ms / 死亡 30ms，`navigator.vibrate` 不可用时静默。
- **性能**：`document.hidden` 时 `idleTick` / `visitTick` 不再绘制；`artSpriteCache` 上限未做。
- **独立打开体验**：`M` 键静音/恢复；底部「导出存档 / 导入存档 / 重置」，iframe 内自动隐藏；导入/重置前关闭自动存盘，避免 beforeunload 覆盖。
- **新手引导**：首开在蛋屏显示三行提示（孵化 / 状态 / 访客），孵化开始即收掉并写 `tutorialDone`；没有做强制三屏翻页。
