# 旅行玩法说明（草案 v1）

> 状态：**待确认**。确认后按文末「实现方案」加入游戏，本轮不改代码。

## 一、目标

在旅行页增加一个独立的「旅行说明」入口，用一页弹窗讲清：

- 旅行怎么开始、怎么结束
- 行囊/便当/道具分别有什么用
- 旅途中和回家后能拿到什么
- 图鉴、庭院、访客、惊喜这些内容分别怎么参与

入口建议：旅行页顶栏加一个 `?` 按钮（与斗月巴右上角规则按钮同一套交互），点开 `openModal` 展示说明。

## 二、解锁与入口

- 解锁条件：第一图鉴集齐 **85 只**月巴（`DEX1_MIN=85`）。
- 解锁后主界面底部出现 **🧳 旅行** 按钮。
- 旅行页顶部显示：🍅 番茄余额、月巴状态（在家 / 旅途中）、📔 旅行笔记、✕ 关闭。
- 旅行页底部导航：🏠 庭院、🛋 室内、🛍 商店、💼 行囊、🏷 图鉴、🎲 对赌、🃏 斗月巴、🎰 惊喜（满足条件时出现），以及 📮 信箱、🚪 门口浮标。

## 三、核心循环

> 选月巴 → 装便当 → 出发 → 等它寄信 / 回家 → 收特产与番茄 → 招待访客、补图鉴 → 再出发。

## 四、规则明细（开发核对用）

### 4.1 出行准备

- 行囊最多 **4 件**。
- 便当最多 **1 份**；幸运护身符最多 **1 个**；小号护身符最多 **1 个**；其余道具按格数携带。
- 必须选择 **1 只已拥有的月巴**，否则不能出发。
- 出发前可以写一句留言，会记录在这趟寄回的信上。
- 同一时间只能有 **1 只月巴在旅行**；它回来前不能再次出发。
- 旅途中，护身符 / 小号护身符不能从行囊取出。

### 4.2 便当决定去哪个地区

| 便当 | 价格 🍅 | 主要地区（65%） | 其余地区 |
| --- | --- | --- | --- |
| 🍙 饭团便当 | 50 | 森林 | 小镇 / 大海 / 雪地 |
| 🍱 时蔬便当 | 150 | 小镇 | 森林 / 大海 / 雪地 |
| 🐟 海味便当 | 250 | 大海 | 森林 / 小镇 / 雪地 |
| 🥡 豪华便当 | 400 | 雪地 | 森林 / 小镇 / 大海 |

> 其余地区按「地图时长越短、概率越高」分摊；地区内再抽具体地图。

地区内具体地图权重：

- 默认：图一 50% / 图二 30% / 图三 20%
- 带小号护身符：图一 20% / 图二 48% / 图三 32%
- 图一已集齐且带小号护身符：图一 10%，其余 90% 按原比例分摊
- 图四已解锁且带小号护身符：图四 15%，其余三图各 ×0.85
- 不带小号护身符时，**图四不会被抽到**

### 4.3 道具

| 道具 | 价格 🍅 | 作用 |
| --- | --- | --- |
| 🔔 铃铛 | 200 | 一次性，需配便当，必定前往「小镇」地区任一地图 |
| 🏮 油灯 | 300 | 一次性，需配便当，必定前往「大海」地区任一地图 |
| 🍀 幸运护身符 | 500 | 每趟特产 +1；耐久 3，每趟 -1，用尽消失；最多带 1 个 |
| 🧭 指南针 | 200 | 一次性，仅「豪华便当 + 幸运护身符」去雪地时可用，可指定雪山 / 遗迹 / 冰湖 / 失落王庭 |
| 🎫 小号护身符 | 200 | 永久只买一次；装进行囊才生效；每周（周一 0 点刷新）可指定任意地图一次，只需带最便宜饭团；同时调整地区内地图概率（更偏向靠后的图） |

### 4.5 旅途中

- 每趟 **必得 1 封信**：约出发后 8–14 分钟寄到，最多 1 封；若离线错过，归来结算时补发。
- 信件从该地图的信件池抽取；重复信会累计「重复累计」，满 **10 封**后，下一趟在「仍有新信」的地图必出新信。
- 出发留言会写在这封信上；信还会记录是哪个地区的哪张地图、由哪只月巴寄出。
- 旅途中可以关闭旅行页去做别的事，旅行按真实时间继续。

### 4.6 归来结算

- 每趟带回特产 **1 件**；带幸运护身符则 **2 件**。
- 抽到的特产若已拥有，会按该地图的兑换范围折算成 🍅。
- 幸运护身符每趟耐久 -1，耐久归零后消失。
- 归来后进入「🛋 室内」可领取 **5–20 🍅** 的归家奖励；若不进室内就直接再次出发，奖励会自动补发。
- 每次旅行会写入「📔 旅行笔记」（保留最近 200 次）。

### 4.7 旅行图鉴

- 图鉴分「✉️ 信件」与「🌿 特产」两页，按 森林 / 小镇 / 大海 / 雪地 四个地区分组。
- 每个地区的第 4 张图默认锁定：需该区**前 3 张图各集齐至少 3/4 的信件**才解锁。
- 图四解锁后，只有带小号护身符时才有概率前往（见 4.2）。

### 4.8 庭院 / 室内 / 访客 / 小偷 / 惊喜

- 🏠 庭院：每 10–30 分钟刷新一段月巴小剧场；每次刷新有 **10%** 概率出现「偷番茄的月巴」。
- 小偷事件：三回合滑块小游戏，捉拿成功次数越多奖励越高（0 / 10 / 20 / 30 🍅）。
- 🚪 访客：约每 15–25 分钟可能来一位，门口图标亮起；用特产招待可获得 🍅 回礼：
  - 访客没有特别想要：15–34 🍅
  - 正好是它更想要的特产：20–39 🍅
  - 不是它想要的：6–19 🍅
  - 招待时有 10% 概率获得该访客关联的一封稀有信（未拥有时）。
- 🎰 惊喜：每 10–30 分钟积攒一次，三格老虎机，可得 1–50 🍅。

### 4.9 旅行页小游戏

- 🎲 对赌、🃏 斗月巴 是旅行页内置的独立小游戏，各有自己的规则与次数限制，不参与旅行主流程。
- 说明弹窗只讲旅行主流程，小游戏沿用各自已有规则说明。

## 五、拟加入游戏的玩家文案（中文）

**标题：🧳 旅行说明**

**怎么开始**
1. 在「💼 行囊」里选一只想出门的月巴。
2. 至少装 1 份便当；便当决定它大概率去哪个地区。
3. 想带特产回来，可以再装一个幸运护身符。
4. 点「✈️ 出发」，等它回来。

**旅途中**
- 月巴会在路上寄回 1 封信，可以在 📮 信箱里拆开。
- 同一条路可以反复走；重复的信会累计，攒满一定数量后下一趟必得新信。
- 出门前写下的留言，会跟着这封信一起寄回来。

**回家**
- 每次回来都会带回 1 件特产；带幸运护身符可以带回 2 件。
- 重复的特产会折算成 🍅。
- 到「🛋 室内」看看它，能收到它旅途中攒下的 🍅。

**图鉴**
- 「🏷 图鉴」里可以查看每个地区已收集的信件与特产。
- 每个地区的前 3 张图信件收集到 3/4 后，会解锁该地区的隐藏地图。
- 隐藏地图只有带上「🎫 小号护身符」才有机会前往。

**庭院与访客**
- 🏠 庭院里月巴们会自己玩耍，偶尔会有月巴来偷番茄，可以捉拿它。
- 🚪 门口偶尔会有访客，用特产招待可以换到 🍅，还可能带来稀有的信。
- 🎰 庭院里攒够惊喜时，可以拉一次老虎机。

**小提示**
- 旅行按真实时间推进，关掉页面也会继续。
- 同一时间只能有一只月巴在外旅行。
- 幸运护身符每趟都会消耗 1 点耐久。
