# 「黄金矿工 · 番茄矿脉」百巴箱小游戏 · 计划书

> 状态：**已实现**（`goldminer.html` + 百巴箱入口；M1–M5 完成，Node 沙箱校验 40+ 项通过）
> 目标：在「百巴箱」新增第 6 个游戏「黄金矿工」；矿区是**地下番茄田**，每局开始随机抽 1 只月巴当矿工，戴着安全帽下矿挖番茄。
> 形态：**独立单文件 `goldminer.html` + 百巴箱 iframe 内嵌**，对齐 `snake.html`：不跳页、不卸载首页，游玩时主游戏番茄钟 / 月巴生长 / 自动存档照常运行。

## 二、形态：为什么是「独立页 + iframe」

你要求对齐「贪吃蛇月巴」的做法，这个形态在本项目里已经验证过：

| 对比项 | `snake.html` | 黄金矿工（本方案） |
|---|---|---|
| 游戏本体 | 独立 HTML | 独立 `goldminer.html` |
| 打开 | `#snOverlay` iframe | 百巴箱通用 `#gbGameOverlay` + `#gbGameFrame` |
| 关闭 | 卸载 iframe，回首页 | 卸载 iframe，回百巴箱 |
| 首页计时 | 继续运行 | 继续运行 |
| 存档 | 独立键 | 独立键 `yueba-gold-v1` |
| 语言 | 页内字典 + 主存档 | 页内字典 + 主存档 |

和蛇月巴唯一的差别：蛇月巴同时有「图鉴入口」，所以它单独做了一层 `#snOverlay`；黄金矿工只从百巴箱进，直接用百巴箱现成的 iframe 外壳（`fight.html` 走的就是这条路），**index 不需要新增浮层、CSS、游戏逻辑**。

「不脱离原本游戏、其他功能照常」的落点：

- `#gbGameOverlay` 盖在首页之上，首页的 `setInterval(tick,250)`、主游戏番茄钟、自动收获、5 秒自动存档全部继续；
- iframe 只负责自己的画面与循环，关闭时 `fr.src='about:blank'`，游戏音频与 rAF 立即停止；
- 首页只加 `gb-lock`（`overflow:hidden`），不碰任何计时器与存档逻辑。

## 三、玩法设计

### 3.1 核心循环

```
百巴箱点卡片 → 打开 goldminer.html（iframe）
  → 开始面板（随机抽到的矿工 + 名字 + 台词 + 开始）
  → 第 1 关（60s，本关目标 450）
     摆钩 ⇄ 下钩 → 命中番茄 / 土块 → 收回 → 计分
     达标 → 关间 2s 横幅（剩余秒数 ×3 加分）→ 下一关，重新铺番茄
     未达标 / 时间到 → 结算
  → 结算（总分 / 到达关卡 / 最高分 / 本局矿工 / 本局番茄金像数）
     「再来一局」→ 重新抽矿工、从第 1 关开始
     「返回百巴箱」→ 由外层「✕ 返回百巴箱」关闭（与 fight.html 一致）
```

### 3.2 画面布局

页面铺满 iframe 可用区域；逻辑画布 **480 × 720**（竖屏 2:3），等比缩放居中：

```
┌──────────────────────────────┐  ← 外层百巴箱条：🎁 黄金矿工   ✕ 返回百巴箱
├──────────────────────────────┤
│ 第 1 关 · 本关 0/450      ⏱ 60      🍅 0 │  ← 页内 HUD
├──────────────────────────────┤
│            🐰（月巴矿工，戴安全帽）           │
│              ＼  绳                       │
│               ＼                         │
│     🍅       🍅(大)   ✦🍅      ⏰🍅       │  ← Canvas 地下番茄田
│        🍅        ▮土块       🍅           │
│   🍅       ✦🍅       🍅        🍅          │
│         🍅      ▮       🍅      [番茄金像]  │
│                                          │
├──────────────────────────────┤
│   点击屏幕 / 空格键 下钩                  │  ← 页内底提示
└──────────────────────────────┘
```

- 顶部 HUD（DOM）：关卡与目标、倒计时、总分（外层已有返回按钮，页内不重复做返回）。
- 中部矿区：全部 Canvas 绘制（土层背景、番茄、根须、绳、钩、粒子、飘字）；番茄金像是唯一的 DOM 覆盖物（加载番茄外链图片）。
- 月巴矿工：**DOM 元素**，外链立绘 `<img>` 或页内程序化 SVG，叠在画布上，随摆角轻微晃动。
- 底部提示与安全区留白（`env(safe-area-inset-bottom)`）。

### 3.3 钩爪状态机

```
idle(摆动) --点击/空格--> shoot(下探) --命中--> attach(吸附) --> retract(收回) --> idle
                                   └--到达最大长度--> retract(空钩快速收回) --> idle
```

| 参数 | 值 | 说明 |
|---|---|---|
| 摆动角度 | ±68° | 以竖直向下为 0° |
| 摆动周期 | 2.4s → 1.6s（随关卡递减） | `θ = sin(t·2π/T) · 68°` |
| 下钩速度 | 700 px/s | 钩尖沿当前角度直线前进 |
| 最大绳长 | 596 px | 到顶仍未命中则空钩返回 |
| 空钩收回 | 620 px/s | 快速归位，不拖泥带水 |
| 带物收回 | `max(38, 200 / weight × (标准半径 / 实际半径)^1.2)` px/s | 重量 + 尺寸双重减速；400px 行程约：小番茄 2.0s、中 2.9s、大 4.4s、土块 8.5s、闪光 1.5s |
| 命中判定 | 钩尖圆半径 8px + 目标半径，小番茄 / 闪光番茄额外 +4px 容错 | 手感优先，不做像素级苛刻判定 |
| 一次一钩 | 收回结束前不能再次下钩 | 经典规则 |

- 钩子回顶时才结算该番茄：加分、粒子、音效、目标从场上移除。
- 若同一帧命中多个目标，取钩尖最近的一个。

### 3.4 可挖物表

| 可挖物 | 分值 | 重量 | 半径 | 出现占比 | 备注 |
|---|---|---|---|---|---|
| 小番茄 | 50 | 1.0 | 14 | 36% | 最基础的一筐番茄 |
| 中番茄 | 120 | 1.5 | 19 | 26% | — |
| 大番茄 | 260 | 2.4 | 26 | 14% | 又大又沉，但值钱 |
| 硬土块 | 15 | 4.5 | 24 | 16% | 唯一不是番茄的东西；假动作惩罚；第 3 关起占比逐关 +2% |
| 闪光番茄 | 600 | 0.8 | 17 | 4% | 水晶质感 + 彩虹扫光 + 彩色粒子，又轻又贵 |
| 番茄钟 | +5 秒 | 0.9 | 16 | 3% | 带奶油表盘的番茄，时间奖励，不直接加分 |
| 番茄金像 | 888 | 3.0 | 30 | 1%（每 3 关保底 1 个） | **幸存者游戏那只番茄**（`PLAYER_ART_SRC`）的金色化身，带反光与扫光 |

- 每关铺番茄数量：`18 + 2 × (关卡 - 1)`，上限 32。
- 生成规则：矿区矩形内随机、圆与圆不重叠、距顶部绳枢 ≥110px；重试 60 次仍失败则跳过该颗。
- 全部图形 Canvas 程序化绘制，不加载图片资源（番茄金像用幸存者游戏的番茄外链除外）：
  - 番茄：球体径向渐变 + 顶部五角绿萼 + 小藤 + 高光点，底部一小撮土丘，体现「埋在地里」；
  - 闪光番茄：水晶切面 + 彩虹扫光 + 四角星点，红色半透明；
  - 番茄钟：番茄轮廓 + 奶油色表盘 + 指针；
  - 硬土块：灰褐多边形 + 颗粒；
  - 番茄金像：DOM 层绘制（见 3.7.1 与第六节），不画在 canvas 里。
- 番茄大小只影响半径、分值与重量，不改变命中容错比例。

### 3.5 关卡与计分

- 每关固定 60 秒；「本关得分」只统计本关挖到的番茄，不跨关累计；总分跨关累计。
- 目标：第 1–4 关 400 / 600 / 800 / 1000；第 5 关起 `round(前关目标 × 1.15 / 10) × 10`。
- 达标：本关得分 ≥ 目标 → 进入下一关；剩余秒数 ×3 计入总分。
- 未达标：结算，最高分只与「总分」比较。
- 关卡难度：摆速周期每关 -6%（下限 1.6s）；土块占比从 16% 起每关 +2%（上限 34%）；其它番茄占比按比例压缩。
- 最高分与最高关写入 `yueba-gold-v1`；不设排行榜（避免与飞行 / 格斗的榜单体系混淆）。

### 3.6 操作

| 操作 | 桌面 | 手机 |
|---|---|---|
| 下钩 | 鼠标点击矿区 / 空格 / ↓ | 点击矿区任意位置 |
| 关闭 | 外层「✕ 返回百巴箱」 | 外层「✕ 返回百巴箱」 |
| 开始 / 再来一局 | Enter / 点击按钮 | 点击按钮 |

- 只在 `idle` 状态接受下钩输入；按钮与顶栏区域不触发下钩（`pointerdown` 绑定在画布容器上，不绑 `window`）。
- 画布 `touch-action:none`，避免 iframe 内滚动与双击缩放；页内 `overflow:hidden`。
- 手机竖屏优先；横屏时画布高度受限，等比缩放居中，不裁切。
- 空格 / 方向键只在 iframe 聚焦时生效，不会干扰首页；关闭后 iframe 卸载，监听自然消失。

### 3.6.1 连击与道具

**连击**：连续抓到小 / 中 / 大番茄、闪光番茄、番茄金像 → 连击 +1；抓到土块、腐烂番茄或空钩 → 归零。倍率从 ×1.0 起，每连一颗 +5%，封顶 ×1.5（第 11 颗起）。画布左上角芯片显示「连击 N ×1.25」，命中时弹一下。

**道具**（每关随机 1 个）：

| 道具 | 效果 |
|---|---|
| 炸药 | 收回时炸掉 150px 内所有土块（自身不计分、不断连击） |
| 强力胶 | 10 秒内拉速 ×2，右上角芯片倒计时 |
| 矿灯 | 本关 +8 秒 |
| 腐烂番茄 | 第 2 关起 45% 概率额外 1 颗；抓到 −40 分、断连击 |

### 3.6.2 成就 / 图鉴 / 每日 / 金币

- **独立成就 8 条**：首通、首座金像、8 连击、单局 2000、到达第 5 关、遇见 20 位矿工、累计 100 颗番茄、完成每日挑战；达成即横幅提示，写入 `save.ach`。
- **矿工图鉴**：按遇见次数排序展示已遇见月巴，入口在开始面板。
- **每日挑战**：用日期做随机种子，**矿图当天固定**；矿工沿用开始面板展示的「本局矿工」（同样只从有立绘的池里抽），另存 `save.daily` 的今日最高分。
- **每日挑战奖励**：当天首次达标（通关任意一关）→ `postMessage` 一张「隧道通行证」到首页旅行仓库，每天限 1 次（`save.daily.rewarded` 记日期键）；持有期间不重复发放。首页收到后回 `yueba-gold-item-ack`，矿工页据此弹出金色道具卡片（图标 / 名称 / 功能说明），已有道具时改为提示「本次不再重复赠送」。
- **金币回传**：每关达标按 `target / 2` 通过 `postMessage` 交给首页，结算页显示本轮累计金币。

### 3.6.3 隧道通行证（与旅行联动）

| 项 | 规则 |
|---|---|
| 获取 | 每日挑战当天首次达标，自动送入首页旅行仓库（`S.travel.wh.goldletter`） |
| 叠加 | **不可叠加**：仓库或行囊里已有 1 张时，新的每日挑战不再赠送（矿工侧 `hasTicket()` 预检 + 首页消息监听二次拦截） |
| 使用 | 在 💼 行囊里「装进行囊」；放在行囊里出发即生效，**不强制带便当** |
| 效果 | 无论目的地，旅行时长固定 **5 分钟**，且必寄回 1 封信（`cardQuota ≥ 1`，约第 4.5 分钟送达） |
| 消耗 | 出发时一次性消耗；未出发可随时从行囊取回仓库 |
| 说明 | 不参与目的地判定，只改写时长与信件配额；目的地仍按「手动指定 > 铃铛/油灯等定向道具 > 豪华便当+护身符去雪地 > 便当分流」决定。因此「隧道通行证 + 铃铛 + 任意便当」会优先按铃铛前往小镇地区，同时 5 分钟快速归来。与幸运护身符、装备时间加成互不叠加（时长以 5 分钟为准） |

### 3.7 随机月巴矿工

| 项 | 规则 |
|---|---|
| 数据来源 | `goldminer.html` 内置 `POOL`（由 `index.html` 的 `TYPES / TYPES2 / TYPES3` 导出 `id / name / img / color / shape / r`） |
| 收集过滤 | 开局时只读解析 `localStorage['idle-yueba-save-v2']` 的 `collection / collection2 / collection3` 键；池 = 已收集 ∩ `POOL` ∩ **有外链立绘**（无图月巴不出场） |
| 兜底 | 池子 < 8 只时，用 `POOL.filter(t => t.img && t.r <= 2)` 补齐（当前 30 只）；极端情况下退回全部有立绘的月巴（87 只） |
| 刷新时机 | **每局开始时重新读一次主存档**，主页面刚收集的新月巴下一局就能当矿工 |
| 矿工去重 | 池子 > 1 时排除上一局的矿工 id，保证「每局都不一样」的体感 |
| 矿工权重 | 均匀抽取；不按稀有度加权（稀有月巴当矿工是惊喜，不是概率陷阱） |
| 矿工影响 | **纯外观**：立绘 / 名字 / 台词；不加速度、不加分值、不加时间 |
| 矿工展示 | 开始面板大图 + 「本局矿工 · 金月巴」；对局中缩到 64px 挂在绳枢上方；结算页再次显示名字 |
| 台词 | 4 条通用矿工台词（`{n}` 替换为名字），开始 / 抓到闪光番茄 / 抓到硬土块 / 达标 / 抓到番茄金像时随机播报；**不为 100+ 只月巴逐只写台词** |

**立绘细节**：有 `img` 的月巴用 `<img>`（固定 64px 框、`object-fit:contain`、`decoding="async"`，失败时回退到色块）；无 `img` 的月巴在页内用 35 行左右的迷你 SVG 按 `color + shape` 画出来（与主游戏 `fatSVG` 观感一致，但不复用其代码）。头顶叠一个 CSS 安全帽（黄色半圆 + 帽檐），随摆角反向轻转 `-θ×0.08`；抓到重物时下沉 4px，达标时上跳一次，未达标时低头（`translateY +3px` + 轻微灰度）。

### 3.7.1 番茄金像（固定形象）

| 项 | 规则 |
|---|---|
| 形象来源 | 直接复用 `survivor.html` 的番茄玩家立绘外链：`PLAYER_ART_SRC = 'https://origin.picgo.net/2026/10/22/8972a81ecea59da5668b010802d3bfcb1c75cde7c34bfa6e.th.png'` |
| 与月巴脱钩 | **不再从矿工池抽取**；金像永远是这只番茄，与「番茄矿脉」主题一致 |
| 金色处理 | `<img>` + `filter: sepia(1) saturate(2.6) hue-rotate(2deg) brightness(1.05) contrast(1.05)`，叠加金色渐变层 + 斜向扫光 + 金色轮廓光；滤镜不可用时至少有金色叠层 |
| 尺寸 | 30px 半径（略大于大番茄），固定缩放到 60×60 框内 `object-fit:contain` |
| 展示 | 埋在地里时持续缓慢扫光；钩中后随绳移动；回顶时金色爆闪 + 横幅「番茄金像 · +888」 |
| 加载失败 | `onerror` 回退为页内绘制的大番茄 + 金色描边，保证观感不塌 |
| 记录 | `yueba-gold-v1.statues` 记为次数（int）；结算显示「本局挖到 n 座番茄金像」，开始面板显示「已挖到 n 座番茄金像」 |

## 六、技术方案

| 模块 | 方案 |
|---|---|
| 渲染 | Canvas 2D，逻辑 480×720；`DPR = min(devicePixelRatio, 2)`；CSS `aspect-ratio:2/3` + `max-width:560px` 等比缩放 |
| 离屏缓存 | 土层背景烘焙到 `bgCv`（`resize` 时重建）；静态矿点烘焙到 `oreCv`，仅在生成 / 抓走 / 炸掉 / 立绘到达时重烘焙；宝石、番茄钟、炸药与钩住的矿点逐帧绘制 |
| 自适应画质 | 连续 90 帧平均低于 44fps 时把 DPR 从 2 → 1.5 → 1.25，最多降两档 |
| 横屏布局 | `@media (orientation:landscape) and (max-height:560px)` 下 HUD 改为左侧竖栏，矿区吃满高度 |
| 游戏循环 | `requestAnimationFrame` + 固定步长累加器（1/60s，单帧最多补 3 步）；页面隐藏时暂停 |
| 卸载 | 外层 `gbFrameClose()` 把 iframe 设为 `about:blank`，rAF / 音频 / 定时器随文档销毁 |
| 月巴矿工 | DOM 覆盖层；有 `img` 用 `<img>`，无图用页内迷你 SVG；加载失败回退色块 |
| 番茄金像 | 固定 `TOMATO_SRC`（复用 `survivor.html` 的 `PLAYER_ART_SRC`）；`<img>` + `.gm-statue` 类：`filter: sepia(1) saturate(2.6) hue-rotate(2deg) brightness(1.05) contrast(1.05)`，叠加金色渐变层与 `::after` 斜向扫光；每帧用 `transform: translate()` 跟随钩爪；不影响矿工池 |
| 碰撞 | 钩尖圆 vs 目标圆；每帧只对「钩尖附近 80px」内的目标做检测，数量上限 32，无需空间索引 |
| 生成 | 关卡开始时一次性生成；圆-圆不重叠；失败重试 60 次后跳过；金像位置尽量靠矿区内侧 |
| 输入 | `pointerdown` 绑在画布容器；`keydown` 只监听 Space / ArrowDown / Enter，窗口卸载即失效 |
| 状态 | `gm = {raf,last,acc,phase,angle,len,hold,statue,ores,parts,texts,score,lvScore,lv,time,best,...}` |
| 特效 | 粒子与飘字用对象池（≤60 / ≤12）；震动用容器 `transform`，`prefers-reduced-motion` 或低功耗时关闭 |
| 音频 | 页内 Web Audio 合成；首次手势解锁；静音 / 低功耗跟随主存档初始值 |
| i18n | 页内字典 zh/en/ja/ko；`?lang=` → 主存档 `lang` → 浏览器；DOM 文案统一走 `t()` |
| 低功耗 | 开局读主存档 `lowPower`：关震动、粒子减半、飘字减半、去掉柔和光影、`backdrop-filter` 与金像扫光 |
| 移动端 | `touch-action:none`；按钮 ≥44px；底部 safe-area；横屏不裁切 |
| 数据池 | `POOL` 常量由 `index.html` 的 `TYPES / TYPES2 / TYPES3` 一次性导出；字段 `id / name / img / color / shape / r` |

## 八、验收标准

1. 百巴箱出现「黄金矿工」卡片，图标为金月巴；点击后 iframe 打开，外层标题显示「🎁 黄金矿工」，关闭后回到百巴箱。
2. **首页照常**：游玩期间主游戏番茄钟继续计时、月巴继续生长、5 秒自动存档继续；关闭游戏后立刻能看到这期间的增长，无刷新、无跳页。
3. **独立可用**：直接双击 `goldminer.html` 也能完整游玩（无主存档时用基础矿工池）。
4. **随机矿工**：连续开 5 局，矿工至少在 4 局不同（池 >1 时不会连续重复）；新档也能抽到基础池矿工；中途新收集的月巴下一局可能出场。
5. **番茄金像**：形象固定为幸存者游戏的番茄外链；外观为金色 + 反光 + 扫光；外链失败时回退金色描边番茄；每 3 关至少 1 个。
6. **矿工纯外观**：同一关卡下，换不同矿工不影响番茄分布、钩速、目标与得分上限。
7. **钩爪手感**：摆角 ±68°、下钩即时、空钩快速返回、重物明显变慢；一次一钩；点击与空格都能触发；按钮区域不误触。
8. **关卡闭环**：第 1 关 60 秒内达标 → 横幅 → 第 2 关重新铺番茄；未达标 → 结算；最高分 / 最高关正确落盘，刷新后保留。
9. **可挖物**：7 类都能出现、计分正确；大小番茄分值 / 重量有差异；闪光番茄有特效且轻；番茄钟加时不加分；硬土块慢且分低；金像每 3 关至少 1 个。
10. **四语言**：zh / en / ja / ko 下 HUD、开始面板、结算面板、台词均无漏翻、无溢出；`?lang=` 优先于主存档。
11. **适配**：360×640 竖屏完整可玩；横屏不裁切；iOS 安全区不遮挡底提示；连续点击不缩放页面。
12. **性能**：切后台自动暂停、回前台继续；低功耗模式无震动、粒子减半、无扫光；连续游玩 10 分钟无内存增长、无控制台报错；关闭后 iframe 音频立即停止。
13. **隔离**：`idle-yueba-save-v2` 在游戏期间只读不写；删除 `yueba-gold-v1` 可干净重置，不影响首页任何数据。
14. **数值**：1–4 关目标 400/600/800/1000，之后 ×1.15；土块占比封顶 26%；矿物总价不足目标 1.2 倍时会自动替换补足。
15. **连击**：连续抓番茄累加、抓土块/腐烂番茄/空钩归零；倍率 5% 递增、封顶 ×1.5；左上角芯片实时显示。
16. **道具**：每关恰好 1 个；炸药清掉 150px 内土块、强力胶 10 秒拉速 ×2 且右上角倒计时、矿灯 +8 秒；腐烂番茄 −40 并断连击。
17. **成就**：8 条达成后写入存档并弹横幅；成就面板进度与勾选状态正确。
18. **图鉴**：按遇见次数排序展示已遇见矿工；未遇见时显示空状态。
19. **每日挑战**：同一天两次挑战的矿图完全一致；矿工与开始面板的「本局矿工」一致；今日最高分独立于普通模式。
20. **金币**：每关达标回传 `target/2`，首页金币即时增加并落盘；结算页显示本轮累计。
21. **隧道通行证**：每日挑战当天首次达标后，仓库出现 1 张；装进行囊出发（可无便当）后时长固定 5 分钟、必回 1 封信；出发即消耗，每天最多 1 张，**仓库或行囊里已有则不再发放**。

## 十、风险与对策

| 风险 | 对策 |
|---|---|
| 钩爪手感不对（太快 / 太黏 / 瞄准难） | 参数集中在 `GM_CFG`；钩尖判定加 8px 容错；先做 M2 手感验收再铺内容 |
| 重土块过多导致挫败 | 土块占比封顶 34%；土块也给 15 分；第 3 关起才逐步加压 |
| 金像与普通番茄区分度不足 | 金色 + 持续扫光 + 金色轮廓光 + 金色爆闪；尺寸略大并带横幅 |
| 金色滤镜在旧浏览器不生效 | 先画立绘再叠金色渐变层；滤镜只是增强，叠层保证「金像」观感 |
| 番茄金像外链断网 / 加载失败 | `<img onerror>` 回退为页内绘制的大番茄 + 金色描边，功能与分值不变 |
