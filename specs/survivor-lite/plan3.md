# 番茄幸存者 · Plan 3（构筑深化 + 后四关 + 模式 + 收尾修复）

> 前置：Plan 1（独立页 + 奖励/成就/立绘）与 Plan 2（6 关 + 8 事件 + 6 特殊敌人 + Boss 三阶段 + 18 遗物 + 宝箱）已落地。
> 本文档回答两件事：**Plan 3 还要加什么内容**、**Plan 2 留下了什么要修**。
> 原则不变：单文件 `survivor.html`，Canvas 2D，逻辑坐标 1280×720；只借鉴《吸血鬼幸存者》的系统结构，不复用素材与数值。

| 项 | 内容 |
|---|---|
| 核心目标 | 把「单武器 + 遗物」变成「主武器 + 副武器 + 进化」的构筑循环，让每局有明确的成长方向 |

## 四、新增游戏内容

### 4.1 武器与进化（3B · P0）

#### 4.1.1 槽位规则

| 项 | 规则 |
|---|---|
| 主武器 | 固定 1 把「番茄籽」，不可替换 |
| 副武器 | 最多 2 把，从升级三选一里获得 |
| 武器等级 | 每把 Lv1–Lv5，升级卡出现时占一个卡位 |
| 进化 | 副武器 Lv5 + 指定遗物 → 进化形态，占原槽位，不再继续升级 |
| 卡池 | 升级池 = 基础强化 ∪ 新武器 ∪ 武器升级 ∪ 遗物 ∪ 可用的进化 |

#### 4.1.2 三把副武器

| id | 名称 | 机制 | 每级成长 | 上限 |
|---|---|---|---|---|
| `aura` | 番茄光环 | 每 1.0s 对半径内敌人造成伤害，透明红环 | 半径 +6，伤害 +2.5 | 5 |
| `orbit` | 环绕籽 | 种子绕玩家旋转，接触造成伤害，同一敌人 0.35s 内置冷却 | Lv3 / Lv5 各 +1 颗，伤害 +3 | 5 |
| `chain` | 藤蔓链 | 每 2.4s 链接最近的敌人，逐跳衰减 15% | 目标 +1（最多 5），伤害 +4，冷却 −0.18s | 5 |

数值起点：

```js
aura  : cd 1.0s, r 70, dmg 5
orbit : 2 颗, 半径 58, 转速 2.4rad/s, dmg 8
chain : cd 2.4s, 目标 2, dmg 12, 跳距 220
```

#### 4.1.3 四条进化

| 进化 | 条件 | 效果 |
|---|---|---|
| 贯穿番茄炮 | 主武器多重 ≥3 + `pierce` 遗物 ≥2 | 子弹穿透 +2；命中产生 36px / 8 伤害的小爆炸 |
| 荆棘领域 | `aura` Lv5 + `thorn` ≥1 | 光环半径 +40%，命中附加 30% 减速 |
| 日冕 | `orbit` Lv5 + `crit` ≥1 | 环籽可暴击，额外 +1 颗，拖尾变金 |
| 酸蚀链 | `chain` Lv5 + `slow` ≥1 | 链击附加酸液减速，链接目标 +1，颜色转绿 |

- 进化只在「条件满足且本局未进化过该武器」时出现在升级池，卡片用金色边框 + 「进化」标签。
- 进化后武器名称、弹体颜色、命中音效都要变，给玩家明确的「成型」反馈。
- 进化不额外占槽位，不改变上限。

#### 4.1.4 重抽

- 每局免费重抽 1 次，暂停/升级界面可见剩余次数。
- 新遗物 `dice`（稀有，上限 2）每层 +1 次重抽。
- 重抽只换当前 3 张卡，不消耗等级。

#### 4.1.5 新增 6 件遗物（总数 18 → 24）

| id | 稀有度 | 名称 | 效果 | 上限 |
|---|---|---|---|---|
| `dice` | 稀有 | 骰子 | 每局重抽 +1 次 | 2 |
| `halo` | 史诗 | 光环扩幅 | 光环半径 +20% | 2 |
| `satellite` | 史诗 | 卫星籽 | 环绕籽 +1 颗 | 1 |
| `vine` | 稀有 | 藤蔓增生 | 链击目标 +1 | 2 |
| `greed` | 史诗 | 贪婪 | 金币 +25%，宝箱稀有度权重 +20% | 2 |
| `glass` | 史诗 | 玻璃番茄 | 伤害 +30%，最大生命 −20 | 2 |

- 同步补四语言名称/描述；`sv9` 的图鉴口径改为「收集 24 种宝物」。
- `greed` 的宝箱权重只提高「稀有/史诗」，不提高传说，避免破坏 Plan 2 的传说门槛。

#### 4.1.6 表现与 UI

- HUD 左下：主武器图标 + 副武器图标（含等级），与遗物条分两行，最多 3+8 个。
- 升级卡：武器卡显示「新武器 / Lv.X→X+1 / 进化」三种标签。
- 暂停页与结算页新增「本局构筑」：主武器、副武器、进化、遗物列表。
- 命中反馈：进化武器使用独立音色；环绕籽命中加小粒子。

### 4.3 开放 7–10 关（3C · P0/P1）

#### 4.3.1 开放规则

- 把 `STAGES` 中 7–10 的 `reserved` 改为 `false`，`playableCount()` 自动变成 10。
- 解锁链、`stageClearN()`、结算「下一关」无需改逻辑。
- `sv4` 口径改为「前 6 关」，新增 `sv7`「通关全部 10 关」。
- 第 10 关通关后显示「全部关卡已通关」，并解锁无尽模式。

#### 4.3.2 关卡机关

| 关卡 | 机关 | 表现 | 伤害/效果 |
|---|---|---|---|
| 7 熔心 | `lava` 熔岩喷口 | 地面红圈预警 1.4s → 喷发 2.2s → 冷却 | 14 伤害，圈半径 65 |
| 8 月影海 | `tide` 月影潮汐 | 全屏方向预警 1.5s → 推挤 1.8s | 6 伤害 + 70px/s 推力 |
| 9 王座前庭 | `beam` 横扫光束 | 两柱之间亮线预警 1.2s → 扫过 1.6s | 18 伤害，线宽 26 |
| 10 归家终点 | `meteor` 归家陨石 + Boss 四阶段 | 落点预警 1.0s → 爆炸 | 20 伤害，半径 55 |

统一数据结构：

```js
G.hazards = [
  { type:'lava', x, y, r:65, warn:1.4, active:2.2, cycle:5.5, t:0, dmg:14, state:'idle' }
];
```

- 机关只在对应关卡生成；`resetRun()` 清空。
- 所有机关先预警再生效，预警颜色与事件预警区分（机关用关卡主题色）。
- 玩家受机关伤害走 `damagePlayer()`，因此护盾/无敌/复活都能正确交互。

#### 4.3.3 新敌人

| kind | 血量 | 速度 | 特性 | 出现 |
|---|---|---|---|---|
| `brute` | 高 | 慢 | 接触时把玩家击退 40px，体型大 | 7–10 关 |
| `phantom` | 中 | 中 | 每 3s 短距离瞬移一次，受击闪白更弱 | 8–9 关 |
| `warden` | 高 | 慢 | 给 140px 内敌人 20% 减伤光环，自身不叠加 | 9–10 关 |

- `warden` 的减伤在子弹结算时读取，不与护盾巴的正面减伤乘算超过 60%。

#### 4.3.4 第 10 关 Boss 四阶段

| 血量段 | 行为 |
|---|---|
| 100%–66% | 每 7s 召唤 4 只小怪 |
| 66%–33% | 每 2.5s 环形 12 发弹幕 |

| 15%–0% | 弹幕 24 发 + 每 6s 陨石 + 召唤 6 只，持续到死亡 |

- 阶段切换沿用 `toast + 屏幕震动 + Boss 外环变色`。

### 4.4 模式（3D · P1/P2）

#### 4.4.1 难度

| 难度 | 敌人血量 | 敌人伤害 | 刷怪 | 金币 | 解锁 |
|---|---|---|---|---|---|
| 普通 | ×1.00 | ×1.00 | ×1.00 | ×1.0 | 默认 |
| 困难 | ×1.35 | ×1.20 | ×1.15 | ×1.5 | 通关第 3 关 |
| 噩梦 | ×1.70 | ×1.45 | ×1.30 | ×2.0 | 通关第 6 关 |

- 难度在开始页切换；关卡最佳记录按 `stage:diff` 存，普通沿用旧键，旧档默认普通。
- 难度不影响关卡解锁，只影响奖励倍率与记录。

#### 4.4.2 无尽模式

- 解锁：通关第 6 关。
- 规则：使用第 6 关场景；5:30 Boss 后不结算，每 90s 追加一轮精英+Boss，敌人血量随时间继续上扬。
- 记录：`endlessBest`（秒）、`endlessKills`；失败结算显示「坚持时长 / 击杀」。
- 成就 `sv10`：无尽坚持 10 分钟。

#### 4.4.3 每日挑战（P2，可选）

- 固定种子 + 固定关卡 + 固定角色，每天一次，失败可看广告？不做广告，直接一次机会。
- 存档 `daily:{day:'2026-10-21', best:0}`；只记录本地最佳。
- 如果排期紧，整块砍掉，不影响 3A–3C。

## 五、存档与数据（v2 → v3）

```js
S.survivor = {
  v: 3,
  // Plan 1/2 字段保持不变
  clears: 0, bestTime: 0, bestKills: 0,
  unlocked: {}, read: {}, lastReward: null,
  stageClear: 0, stageSel: 1, stageBest: {},
  relics: {}, relicSeen: {}, chests: 0,
  // Plan 3 新增
  chars: { unlocked: { tomato: true }, sel: 'tomato' },
  diff: 'normal',                 // normal / hard / nightmare
  mode: 'campaign',               // campaign / endless
  endlessBest: 0, endlessKills: 0,
  daily: { day: '', best: 0 },
  sanctuary: { hp: 0, dmg: 0, luck: 0, reroll: 0 },
  settings: { dmgNum: true, shake: true, parts: true }
};
```

迁移规则：

- `v:1 → v:2 → v:3` 只增字段、不删旧字段；`load()` 继续显式深合并 `chars / sanctuary / settings / daily`。
- `stageBest` 普通难度继续用数字键 `1..10`；困难/噩梦用 `"7:hard"` 这类字符串键，读取时缺省回退普通。
- 旧档没有 `chars` 时补 `{unlocked:{tomato:true}, sel:'tomato'}`；没有 `diff` 时按 `normal`。
- 写回前先重新 `readSave()`，避免首页与幸存者页多标签互相覆盖金币。
