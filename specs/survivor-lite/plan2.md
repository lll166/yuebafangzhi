> 前置：Plan 1 已落地（`survivor.html` 独立页 + index 入口 + 金币/图鉴/成就 + 立绘）。

### 2.1 预留关卡的规则

- `STAGES[i].reserved = true` 的关卡在选关页显示为「敬请期待」，不参与解锁链、不可进入。
- 解锁链只统计**可玩关卡**：`playableStages()` 过滤 `reserved`，第 6 关通关后显示「当前版本全部通关」，而不是「全部 10 关通关」。
- 成就 `sv4` 的口径保持「通关 6 个可玩关卡」，不因预留位改动而失效。
- 预留关卡的数据先写全（名称四语言、时长、倍率、背景色），以后只需把 `reserved` 改为 `false` 并调数值，不改代码。

## 三、关卡内事件（参考 VS 的节奏段落）

### 3.1 事件类型

| ID | 名称 | 表现 | 目的 |
|---|---|---|---|
| `ring` | 月巴潮 | 环形一次性刷 18–30 只，从四周同时收拢 | 制造包围压力，逼玩家移动 |
| `line` | 冲锋巴阵 | 一侧横向排开 8–12 只，同向直线冲锋 | 考验横向走位 |
| `rain` | 月巴雨 | 从上方随机落点落下 12–20 只，落地前有阴影预警 | 打断站桩 |
| `elite` | 精英巴巡游 | 1 只精英 + 4–6 只护卫 | 现有精英升级为事件节点 |
| `chest` | 宝箱守卫巴 | 场地随机位置出现宝箱，伴随 1 精英 + 4 小怪 | 宝物系统入口 |
| `split` | 分裂巴巴群 | 6 只分裂体，死亡后各分裂 2 只更小的 | 清场能力考验 |
| `shield` | 护盾巴队 | 3 只护盾怪 + 后排远程月巴 | 逼迫换位绕后 |
| `heal` | 治疗巴群 | 2 只治疗月巴持续给周围回血 | 优先级判断 |

### 3.2 事件调度

```js
// 每关一张事件表；t 为触发秒数，type 为事件 ID，n 为数量倍率
const STAGE_EVENTS = {
  1: [{t:45,type:'ring',n:18},{t:90,type:'chest'},{t:135,type:'line',n:8}],
  2: [{t:40,type:'ring',n:22},{t:85,type:'chest'},{t:120,type:'split'},{t:165,type:'line',n:10}],
  // ...
};
```

- `G.nextEvent` 指向事件表下标；`update()` 每帧比较 `G.time`，到点触发并从表中移除。
- 事件之间保留 30–45 秒普通刷怪窗口，避免疲劳。
- 事件发生前 2 秒在 HUD 顶部弹出预警条（`#eventWarn`），给玩家反应时间。
- 同屏敌人上限仍为 140；事件触发时若已超限，先清理最远的 10 只。

### 3.3 特殊敌人扩展

在现有 `ENEMY_DEF` 的 `small/fast/tank/elite/boss` 之外新增：

| kind | 血量 | 速度 | 特性 | 立绘来源 |
|---|---|---|---|---|
| `swarm` | 低 | 快 | 单体弱，成群出现 | `small` 池 |
| `charger` | 中 | 中→快 | 直线冲刺，撞墙后短暂停顿 | `fast` 池 |
| `splitter` | 中 | 慢 | 死亡分裂 2 只 `swarm` | `tank` 池 |
| `shield` | 中 | 慢 | 正面减伤 60%，背面正常 | `tank` 池 |
| `healer` | 中 | 慢 | 每 3 秒给 120px 内敌人回 3% 血 | `elite` 池 |
| `bomber` | 低 | 中 | 死亡后 1 秒爆炸，范围伤害 | `fast` 池 |

- 全部复用 `ENEMY_DEF` + `ART_POOL`，不新增美术资源。
- 特性通过 `e.trait` 字段驱动，`killEnemy()` 里按 `trait` 分支（分裂/爆炸/掉落）。

### 3.4 Boss 三阶段

| 血量段 | 行为 |
|---|---|
| 100%–66% | 每 7 秒召唤 4 只小怪（现状） |
| 66%–33% | 停止召唤，改为每 2.5 秒打出一圈 12 发慢速弹（复用 `G.ebullets`） |
| 33%–0% | 速度 ×1.4，边冲锋边召唤，弹幕频率减半 |

- 阶段切换时 `toast` + 屏幕震动 + Boss 外环变色。
- `G.ebullets` 字段已存在但未使用，直接启用，不新增对象类型。

## 四、宝物系统（遗物 / 宝箱）

### 4.1 结构

| 概念 | 说明 |
|---|---|
| 遗物 `RELIC` | 局内永久被动，获得后整局生效，可叠层 |
| 宝箱 `chest` | 场地物件，靠近后开启，弹出 3 选 1 遗物 |
| 稀有度 | 普通 / 稀有 / 史诗 / 传说，决定边框色、权重与强度 |
| 图鉴 | 局外记录「见过 / 获得次数」，与现有 `collection` 分开存 `relics` |

### 4.2 稀有度与权重

| 稀有度 | 颜色 | 基础权重 | 关卡修正 |
|---|---|---|---|
| 普通 | `#b9c4d6` | 60 | 每高 1 关 −4 |
| 稀有 | `#5fa8ff` | 28 | 每高 1 关 +1 |
| 史诗 | `#b06bff` | 10 | 每高 1 关 +2 |
| 传说 | `#f0c05a` | 2 | 第 5 关起 +1，第 7 关起 +2 |

- 权重下限为 1；宝箱与升级共用同一套抽取函数 `rollRelic(stage)`。

### 4.3 遗物表（首版 18 件）

| 稀有度 | ID | 名称 | 效果 | 叠层上限 |
|---|---|---|---|---|
| 普通 | `dmg_s` | 小番茄 | 伤害 +8% | 5 |
| 普通 | `hp_s` | 果皮 | 最大生命 +15 | 5 |
| 普通 | `spd_s` | 轻步 | 移速 +6% | 5 |
| 普通 | `mag_s` | 磁石 | 拾取范围 +15% | 4 |
| 普通 | `bspd_s` | 弹弓 | 弹速 +8% | 4 |
| 稀有 | `pierce` | 穿透籽 | 子弹穿透 +1 | 3 |
| 稀有 | `multi_s` | 双生籽 | 多重弹 +1 | 2 |
| 稀有 | `slow` | 酸液 | 命中减速 25%，持续 1.2s | 2 |
| 稀有 | `thorn` | 荆棘 | 接触反伤 8 | 3 |
| 稀有 | `regen` | 急救包 | 每 30 秒回 8 生命 | 3 |
| 史诗 | `crit` | 暴击 | 15% 概率造成 2 倍伤害 | 3 |
| 史诗 | `leech` | 吸血 | 击杀回复 1 生命 | 3 |

- 所有效果通过 `p.relic` 汇总层数后计算，不直接散落在 `newPlayer()` 里。
- 传说遗物只在 Boss 宝箱或第 5 关以后的宝箱出现。

### 4.4 获取途径

| 途径 | 频率 | 数量 | 说明 |
|---|---|---|---|
| 升级三选一 | 每次升级 | 3 选 1 | 池子改为「基础强化 + 遗物」混合；已有强化仍保留 |
| 关卡宝箱 | 每关 2 个（约 30%、65% 进度） | 3 选 1 | 由 `chest` 事件生成，需先清掉守卫 |
| Boss 宝箱 | 击败 Boss 后 | 1 件传说 | 若该次为胜利结算，则改为结算页展示，不打断流程 |

### 4.5 宝箱交互

- 宝箱为静态物件，玩家靠近 40px 自动开启，**不暂停游戏**（避免打断战斗节奏）。
- 开启时右侧滑出遗物条，1.2 秒内可点击选择；不点则 1.2 秒后自动选第一项。
- 若正在升级选择中，宝箱延后到升级结束后再弹出；队列最多缓存 2 个。

### 4.6 局外图鉴与存档

```js
S.survivor = {
  v: 2,
  // Plan 1/2 已有字段保持不变
  stageClear: 0, stageSel: 1, stageBest: {},
  relics: {},      // relicId: { count, firstAt }  获得次数
  relicSeen: {},   // relicId: true  仅在宝箱/升级中出现过
  chests: 0        // 累计开箱数，用于成就
};
```

- 与现有 `collection`（月巴图鉴）分开，避免奖励口径混淆。
- 首页成就新增：
  - `sv5`「第一件宝物」：`relics` 非空
  - `sv6`「收藏家」：`relics` 种类 ≥ 10
- 四语言文案沿用 `ach_sv5/sv6` 的 `n` 与 `_desc` 结构。

### 4.7 UI

| 位置 | 内容 |
|---|---|
| `#lyChest` | 开箱层：3 张遗物卡，稀有度色边框 + 图标 + 名称 + 效果 + 叠层 |
| HUD 左下 | 遗物条：已获得遗物图标 + 层数，最多显示 8 个，超出折叠为「+N」 |
| 结算页 | 新增「本局宝物」一行，列出获得的遗物 |
| 首页 | 后续可接入独立宝物图鉴页；本次先在成就里体现 |
