# 月巴垂钓 · 计划书

> 状态：**M4 已完成**（2026-10-31，随行月巴 DEX_ART 外链接入 + 选择器 + 心情机制 + sync 白名单；M1–M3：垂钓流程 + 张力/自动/离线 + 100 种鱼图鉴）。M5 待开发。
> 原始草案 v1 已确认。
> 定位：放置月巴百巴箱的新小游戏——一款节奏舒缓的像素风钓鱼游戏。
> 建议文件名：`fishing.html`（根目录，与 pacman.html / memory.html / survivor.html 同级）。

## 一、一句话定位

带上一只月巴，去四个地区的十六张旅行地图上钓鱼；拉杆控张力，慢慢收线，把鱼一条条记进图鉴。

- **节奏舒缓**：无倒计时压力、无惩罚性失败、支持挂机自动收线
- **收集为主**：鱼是像素风，全部进图鉴；月巴用图鉴外链图
- **与主线互通**：钓点即旅行地图，把现有的旅行系统盘活

## 二、与现有系统的关系

| 现有系统 | 本作怎么用 |
| --- | --- |
| `index.html`（放置月巴主游戏） | 只做入口与联动存档字段（同幸存者模式：`游戏本体在 survivor.html，index 只保留入口与存档/成就字段`） |
| 百巴箱 | 最后一步接入：游戏卡片进百巴箱，用 iframe 内嵌打开（同幸存者）；**实装接入前，箱内暂时不显示该卡片** |

## 三、核心循环

> 选钓点 → 选月巴出发 → 浮标等待 → 咬钩提竿 → **拉杆控张力** → 收线入篓 → 图鉴点亮 → 兑换番茄/特产 → 换个地图继续。

单局一条鱼约 30–90 秒；不想手动可开「自动收线」挂机（产出略低），关页面后钓点按真实时间缓慢积攒挂机渔获，回来一次性收——整体贴合放置主游戏的基调。

## 五、垂钓玩法：拉杆控张力

### 5.1 流程

1. **下竿**：选好钓点与月巴，点「下竿」进入等待。
2. **等待**：浮标轻晃（纯氛围，8–20 秒随机）；月巴立绘坐在岸边，偶尔有小动作。
3. **咬钩**：浮标下沉 + 轻震提示，玩家点「提竿」（晚了 2 秒鱼就溜，无惩罚）。
4. **拉杆（核心小游戏）**：进入张力阶段，见 5.2。
5. **收线成功**：结算——鱼入篓、图鉴点亮、番茄/兑换所得入账。

### 5.2 张力玩法（手动模式）

- 一根**张力条（0–100）** + 一个**目标带**：
  - **按住**收线键：张力上升、收线进度增加
  - **松开**：张力自然回落、收线暂停
- 鱼会周期性**挣扎**（力度与时长由鱼种/稀有度决定）：挣扎时张力上升更快，目标带短暂变窄或移动。
- **张力 ≥ 100（过载）**：线断，鱼跑了——**无任何惩罚**，只提示「下次温柔一点」。
- **张力长期贴 0**：鱼缓慢积攒「逃逸值」，满了才跑；正常游玩几乎遇不到。
- 张力保持在目标带内时收线效率最高，并偶尔触发「顺滑时刻」小字提示（纯正反馈）。
- 单鱼时长 30–90 秒，稀有的更久；**没有硬性倒计时**。

### 5.3 自动收线（放置模式）

- 开启后不需要操作，张力由 AI 维持在安全区，但**收线效率约 ×0.7**，传家宝鱼不出。
- 关闭页面后，钓点继续挂机，按时间积攒自动渔获（上限 8 小时），回来一次性结算。
- 手动/自动随时切换；同一时间只有一个钓点在作业（多竿位作为后期成长线）。

## 六、鱼与图鉴

- **鱼是像素风**：不依赖外部图片，用参数化像素鱼模板（canvas 绘制，约 16×12 基础像素，程序化配色/鳍型/花纹变化），保证 100+ 条鱼风格统一、体量可控。
- **图鉴系统**：
  - 按地区分组（同旅行图鉴的分组方式），每条鱼记录：首次捕获时间、累计条数、最大尺寸。
  - 未捕获显示剪影 + 名字「??？」。
  - 完成度奖励：单图鉴集齐、地区集齐、全图鉴集齐各给一次性奖励（番茄/称号/钓竿皮肤）。
- **稀有度四档**：普通 / 稀有 / 传说级 / 传家宝（地区图四限定鱼即传家宝级）。

## 七、月巴伙伴

- **随行月巴 = 庭院当前 3 只月巴三选一**（2026-10-31 修订）：iframe 内由主游戏经 `yueba-fishing-ready/roster` 桥下发庭院名册（`S.travel.yardIds`，庭院每 10–30 分钟轮换）；庭院轮换后旧随行自动回落为未选。独立打开时回退为 DEX_ART 抽 3 只（会话内固定）。
- 立绘直接用外链图（2D-HD：原图平滑缩放+像素化放大），无外链的月巴用主题色色块兜底。
- 月巴是氛围担当：坐在岸边看竿、对渔获有零星台词式反应；随机「心情好」时该钓点小鱼概率小幅上升（数值待定）。
- 立绘表由 `sync-dex-art.js` 白名单同步：`fishing.html` 按 3 字段格式登记，规则与 pacman/memory 完全一致（只登记有外链立绘的月巴，沿序追加，`--check` 校验）。

## 八、UI 与美术

- **整体风格：2D-HD**（2026-10-31 修订）：月巴/番茄立绘与场景底图用原图 + 像素滤镜（原图平滑缩到 256×144 逻辑网格，整体 pixelated 放大）；UI 框架与道具保持浅色像素风。
- **场景为程序生成的 HD-2D 舞台**（2026-11-03 修订，16 张钓点全覆盖）：逻辑坐标仍是 256×144（竖屏 144×256）。**先按 4× 渲染（1024×576 / 576×1024），再平滑降采样回 256 网格，最后由 CSS 最近邻放大**——光影保留高清层次，颗粒回到像素大小（像素滤镜）。画面里所有元素同分辨率：天空渐变 + 三层远景雾化（森林松林 / 小镇楼宇窗灯 / 大海远岛灯塔 / 雪地雪峰）+ 水面渐变与倒影、波光、天体光柱 + 木栈桥与岸坡，逐帧再叠日月泛光、云、光柱、暗角与各图小景（灯笼 / 棕榈 / 花瓣 / 极光 / 雾 / 深海光 / 灯塔光束）；番茄 / 月巴立绘按原图平滑缩放，竿是 2px→1px 的锥形填充（降采样后仍成线）+ 1px 贝塞尔鱼线，浮标与咬钩提示是圆角物件，鱼跃贴图与水滴 / 气泡 / 金星粒子同样走高清绘制。静态底图按「地图 + 尺寸」烘焙一次，逐帧只跑动效 + 一次降采样，不做实时模糊；低端机连续 90 帧均值 > 22ms 时 4× 舞台自动降到 3×。零外部图片依赖。
- 整页统一 HD-2D：页面底纹为低对比像素抖动纹理，UI 面板沿用切角像素骨架。
- **角色设定**（2026-10-31 第三次修订）：持竿的钓手是**玩家番茄**（「番茄立绘-普通」原图，自动裁边 + HD-2D 平滑缩放，略矮）；陪伴角色是**圆脑袋圆耳朵的小兔子**（代码手绘像素图，待机 Q 弹呼吸、每隔几秒一蹦一蹦，起跳拉伸落地压扁），随行月巴选择器退役，羁绊与心情机制转由小兔子继承；鱼线从兔子身后经过。
- **浅色配色**：米白/浅青/浅木色底，低饱和点缀色；像素字体与 2px 描边风格。
- **垂钓动效**（2026-10-31 增补）：等待期水下鱼影绕浮标游动、随机试咬轻点、气泡上浮；咬钩瞬间水花迸溅 + 感叹号弹跳；收线期**钓竿随张力弯曲**、**鱼线绷直微颤**、挣扎水花、顺滑时刻金星沿线闪烁；收线完成**鱼跃出水弧线**飞向月巴再开结算；断线弹竿 + 鱼影逃窜。全部走统一墙钟时间泵，delta-time 驱动保证丝滑。
- **布局参考蛇月巴与番茄幸存者**：
  - 顶部 HUD：番茄余额、当前钓点、鱼篓/图鉴入口、设置。
  - 主画面：钓点场景（像素背景按四地区×小地图微调配色与元素）+ 岸边月巴 + 浮标水面。
  - 弹窗统一 openModal 风格（图鉴、旅行笔记式的记录页、设置）。
- 主游戏侧遵守其皮肤/磨砂玻璃 UI 约定；本作内部 UI 独立成浅色像素风。
- 文案接入 `data-i18n`（与百巴箱内其他游戏一致）。

## 九、技术方案

| 项 | 方案 |
| --- | --- |
| 形态 | 单文件 `fishing.html`，零构建、零外部 JS 依赖（同合集内其他游戏） |
| 存档 | `localStorage` 独立 key（如 `ybf_fishing_save_v1`），含图鉴、番茄、设置、挂机时间戳 |
| 嵌入 | 百巴箱 iframe 内嵌打开（同幸存者 `gbGameFrame`），自身也能直接双击打开 |
| 联动通信 | hash 参数 + postMessage（同幸存者模式）；主游戏只保留入口与存档/成就字段 |
| 月巴立绘 | DEX_ART 外链 + `sync-dex-art.js` 白名单同步 |
| 鱼 | 参数化像素模板程序生成，无外部资源依赖 |

## 十、旅行系统联动（盘活方案，待确认）

1. **进度互通**：钓点解锁与旅行进度挂钩——某张旅行地图去过 ≥1 次即解锁对应钓点；图四钓点沿用旅行图四的解锁条件。
2. **渔获折算**：鱼可在本作内兑换 🍅；也可选「做成特产」，同步回主游戏作为特产（用于招待访客/图鉴特产页）——方向为 fishing → index 单向上报。
3. **便当联动**：出发前买对应地区便当，该地区钓点当日小鱼概率上升（消费回流到主游戏商店）。
4. **旅行笔记**：渔获里程碑写入主游戏的旅行笔记（如「在沉海遗城钓到了古城石鲷」）。

> 以上 4 条彼此独立，可按里程碑取舍；2、4 涉及主游戏改动，放在最后做。
