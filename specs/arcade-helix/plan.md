# 「月巴螺旋跳」Helix Jump · 计划书

> 状态：**已实现，待放开入口**（M1–M4 完成；页内真机流程已实测：准备/选月巴搜索/连续下坠/暂停恢复/撞红块结算/再来一局/四语言/低功耗；首页只读接入已验证；`GB_GAMES` 卡片仍为 `hidden:true`，验收后删掉该标记即上线）

## 三、玩法设计

### 3.1 核心循环

```
百巴箱点「月巴螺旋跳」
  → 准备页：选中月巴 + 最佳深度 + [选月巴] [开始]
  → 倒计时 3 → 2 → 1 → GO!
  → 下坠：左右拖动旋转塔身 / ← → 键旋转
      → 缺口对准 → 穿过一层（深度 +1，连降 +1）
      → 没对准 → 落在实心塔面上弹起，连降清零
      → 撞到红色区块 → 本局结束
  → 结算：本局深度 / 历史最佳 / 新纪录
  → 再来一局 / 换月巴；关闭由百巴箱外层 ✕ 完成
```

### 3.2 基础规则

| 项 | 规则                           |
|---|-----------------------------|
| 塔身 | 由多层圆环叠成；每层有一个缺口（gap）与若干红色危险区块（red）                           |
| 旋转 | 玩家拖动旋转整座塔，月巴固定在屏幕正前方，不左右移动                           |
| 下落 | 月巴受重力下坠；当脚底越过某一层平面时判定                           |
| 通过 | 月巴角度落在缺口内 → 穿过该层，深度 +1，短暂加速/收窄反馈                           |
| 弹起 | 落在实心区块上 → 向上弹起（约 18px 当量），播放「咚」声与压扁回弹，**不结束**                   |
| 死亡 | 脚底接触红色区块 → 立即结束，屏幕微震 + 番茄红闪                           |
| 缺口 | 角度从 95° 随深度收窄到 46°；每层缺口中心与上一层偏移有上限，保证可达                         |
| 红块 | 深度 ≥ 15 开始出现 1 段（80°–120°）；深度 ≥ 60 出现 2 段；永不覆盖缺口                |
| 旋转层 | 深度 ≥ 40 后部分层缓慢自转（±0.4 rad/s），增加读图压力                           |
| 连降 | 连续穿过 N 层未弹起 → 显示「连降 ×N」，仅作视觉/音效奖励，不额外加分                         |
| 结束条件 | 撞红块；或落在塔底安全垫（到达本局最大深度上限时）                           |
| 深度上限 | 单局 999 层，达到后进入「到底了」结算（避免无限生成耗尽内存，玩家游玩时，只生成后面几层能看到的地方，不要一口气全部生成） |

### 3.3 难度曲线

| 深度 | 缺口宽度 | 红块 | 自转层 | 下坠速度 |
|---|---|---|---|---|
| 0–9 | 95° → 88° | 无 | 无 | 基础 |
| 10–29 | 88° → 76° | 15 起 1 段 | 无 | +8% |
| 30–59 | 76° → 62° | 1 段 | 40 起 30% 层 | +18% |
| 60–119 | 62° → 52° | 2 段 | 45% 层 | +30% |
| 120+ | 52° → 46°（封顶） | 2 段 | 60% 层 | +40%（封顶） |

难度全部由 `depth` 计算，无随机跳变；生成器保证「下一层缺口相对当前塔身角度」永远在玩家一次拖动的可达范围内。

### 3.4 操作

| 输入 | 行为 |
|---|---|
| 触屏 / 鼠标拖动（Canvas 区域） | 水平位移 1:1 映射塔身旋转，带惯性衰减 |
| 键盘 ← → | 匀速旋转（桌面） |
| 松手 | 惯性继续 0.25s 后归零，不突然刹停 |
| 暂停 | 顶栏 ⏸ / `P` / `Esc`；切后台自动暂停 |
| 重开 | 结算页按钮 / `R` |

手感目标：**1:1 跟手、低延迟**；旋转速度上限约 12 rad/s，避免甩飞；拖动区覆盖整个游戏舞台，不要求点中月巴。

### 3.5 计分与记录

- 成绩 = **深度**（穿过层数，1 层 = 1m）；本局另记最长连降。
- 历史最佳深度、最长连降、总游玩次数、总深度写入独立存档。
- 结算只展示「本局深度 / 历史最佳 / 新纪录标记」，不做金币、不做排行榜。

## 四、技术方案

### 4.1 单文件结构

```
helixjump.html
├─ <style>  全息终端版式 + 页面局部变量（默认薄荷青）
├─ DOM      顶栏 / 舞台(#stage) / 月巴层(#ballLayer) / 弹层(准备/选月巴/暂停/结算) / 提示
└─ <script>
   ├─ 语言字典 TXT（zh/en/ja/ko）
   ├─ 独立存档 helSave/normHelSave
   ├─ 名册握手（postMessage ready → roster）+ 直开兜底
   ├─ 选月巴页（搜索 / 选中 / 滚动定位）
   ├─ 状态机 menu → ready → countdown → playing → paused → dead
   ├─ 伪 3D 渲染（Canvas 2D）
   ├─ 物理解算 / 层生成器 / 对象池
   ├─ 音效（Web Audio 合成，无音频文件）
   └─ 页面生命周期（visibilitychange / pagehide / resize）
```

### 4.2 伪 3D 投影

不引入 Three.js，不做真 3D；用 2D 椭圆环模拟俯视塔身：

- 世界坐标：层 `y`（向下递增）、缺口中心角 `gapA`、缺口宽 `gapW`、红块区间 `red[]`、自转 `spin`。
- 屏幕投影：
  - `screenY = CY + (ring.y - by) * K`，`K = clamp(H * 0.195, 66, 156)`（每层像素间距，值越大可见环数越少、纵深越强）；
  - 透视缩放 `s = clamp(1 - dy * 0.070, 0.42, 1.12)`，远处层缩小更快；淡出 `fade = clamp(1 - dy * 0.135, 0.15, 1)`；视口外 `dy > 7.6` 直接不画；
  - 椭圆参数：`x = cx + R*s*sin(a)`，`y = cy + R*s*E*cos(a)`（`E=0.25` 为椭圆压扁系数，`cos(a)>0` 为前侧）。
- 每层圆环拆成若干扇区：外弧 + 内弧闭合填充；缺口留空；红块用 `--danger`。
- 绘制顺序：背景 → 远侧层 → 近侧层 → 粒子 → 月巴（DOM 永远最上层，因 Helix Jump 的球始终在塔身正前侧）。
- 月巴 DOM：`#ballLayer` 内一个 `<div class="ball">`，内部放父页下发的立绘 `<img>` 或 `fatSVG` 字符串；用 `transform: translate3d(...) scale(sx,sy)` 做压扁/拉伸与弹起。

### 4.3 物理与判定（固定 60fps 折算）

```
vy += G * f              // G = 舞台高 * 0.0016 / 帧
vy  = min(vy, VMAX)      // 终速上限，避免瞬移穿层
ballY += vy * f
```

- 每帧检查 `ballY` 是否跨过最近未处理层的平面：
  - 用「上帧 y < 层 y ≤ 本帧 y」判定穿越，禁止只比较当前帧，避免高帧率/掉帧漏判；
  - 取月巴角度 0 与 `gapA + towerRot` 的最短角差 `d`；
  - `d ≤ gapW/2` → 穿层；若同时落在任一红块区间 → 死亡；否则实心 → 弹起。
- 弹起：`vy = -sqrt(2 * G * bounceH)`，`bounceH ≈ 18px`；播放压扁回弹。
- 穿层：深度 +1，若连续穿层则连降 +1，否则清零；播放升调叮声。
- 所有角度差统一用 `wrapToPi`，防止 359°/1° 误判。

### 4.4 层生成与对象池

- 初始生成 12 层；相机跟随月巴下移后，把上方已过的层回收进池，在底部补新层。
- 层生成约束：
  - `gapW` 按深度查表；
  - `gapA` 相对上一层偏移 ≤ 55°（保证一次拖动可达）；
  - 红块区间与缺口至少间隔 12°；
  - 前 3 层固定无红块、缺口 100°，作为新手缓冲。
- 自转层用 `spin` 属性，角度在渲染与判定时统一加上 `spin * t`。
- 对象池上限 32 层；深度 999 硬停。

### 4.5 性能与低功耗

- Canvas 实际像素 = CSS 尺寸 × `min(devicePixelRatio, 2)`；`resize` 时重建。
- 所有动画走 `requestAnimationFrame`；`dt` 上限 50ms，防止切回前台瞬移。
- 粒子对象池 ≤ 80，低功耗模式为 0；扫描线用 CSS 伪元素，低功耗时 `display:none`。
- 不使用 `backdrop-filter`（弹层用半透明纯色），不逐帧改 DOM 文本（HUD 数字变化才写）。
- `visibilitychange` → 暂停并停止 RAF；`pagehide` → 存最佳记录。
- 关闭 iframe 即 `about:blank` 卸载，计时器与 AudioContext 一并销毁。

## 五、选月巴页与名册握手

### 5.1 名册范围

父页筛选：

```js
fgAllTypes()                              // TYPES + TYPES2 + TYPES3
  .filter(t => colCount(t.id) > 0)        // 已开启/已收集
  .map(t => ({
    id: t.id,
    name: t.name,                         // 已是当前语言名
    color: t.color || '#8fd0de',
    scale: picScale(t),
    art: artURL(t) || '',                 // 有立绘才下发
    svg: fatSVG(t)                        // 无立绘时的 SVG 兜底
  }))
```

- 排序沿用图鉴顺序（`TYPES → TYPES2 → TYPES3`），不额外做稀有度分组。
- 不下发未解锁月巴，避免剧透；`colCount === 0` 一律不出现。
- 152 只全量 SVG 字符串约几十 KB，`postMessage` 足够；实测后再决定是否需要压缩。

### 5.2 握手协议

| 方向 | 消息 | 说明 |
|---|---|---|
| 子 → 父 | `{type:'yueba-helix-ready'}` | iframe `DOMContentLoaded` 后发送 |
| 父 → 子 | `{type:'yueba-helix-roster', list, muted, lowPower, lang}` | 父页收到 ready 后回包，`origin` 校验沿用现有规则 |
| 子 → 父 | `{type:'yueba-helix-coins', coins}` | **首版不发送**，仅预留 |

- 子页 800ms 内未收到名册 → 使用内置名册开局：收录图鉴中已配置外链立绘的月巴（含 zh/en/ja/ko 名称与立绘 URL，约 98 只；图片加载失败就地回退默认 SVG），并显示「从百巴箱进入可选全部月巴」；保证直接双击 `helixjump.html` 也能看到图鉴形象。
- 父页在现有 `message` 监听（第 14702 行）里加一个分支，不新建监听器。

### 5.3 选月巴 UI（参照飞行页）

- 顶部：标题「选择月巴」+ 已开启数量 + 搜索框。
- 网格：手机 3 列、桌面 4 列；卡片 = 立绘/SVG 圆底 + 名称 + 稀有度小点。
- 搜索：输入即过滤 `data-name`（当前语言名）；无结果显示「没找到这只月巴」。
- 选中：高亮描边 + 轻微上浮 + `scrollIntoView({block:'nearest'})`。
- 记住上次选择：存独立存档 `pick`；若该月巴已不可用则回落到第一只。
- 立绘缩略图 `loading="lazy"`、`decoding="async"`，避免一次性解码 150 张图。

### 6.2 生命周期

| 低功耗 | 继承父页 `lowPower` 初值；页面内可临时关闭粒子，**不写回主存档** |
| 静音 | 继承父页 `muted` 初值；页内可临时切换，**不写回主存档** |

### 6.3 开发期入口

- 开发时直接双击 `helixjump.html` 可玩（内置兜底名册）。
- 需要验证百巴箱名册时，临时把 `hidden:true` 去掉，或在地址栏打开 `index.html` 后手动调用 `gbFrameOpen()`；验收完成再恢复隐藏、最后统一放开。

## 七、存档设计

独立键 `yueba-helix-v1`：

```js
{
  pick: '',            // 上次选择的月巴 id
  best: 0,             // 历史最佳深度
  bestCombo: 0,        // 最长连降
  plays: 0,            // 总游玩次数
  totalDepth: 0,       // 累计深度
  muted: null,         // null=跟随主存档；true/false=页内覆盖
  lowPower: null,      // 同上
  v: 1
}
```

- 读档做字段校验与钳制（深度 0–999、次数非负）。
- 每局结束写一次；新纪录才更新 `best/bestCombo`。
- `pagehide` 兜底保存，防止刷新丢记录。
- 不写 `idle-yueba-save-v2`，避免与首页 5 秒自动存档互相覆盖。

## 八、UI / 动效 / 音效

### 8.1 视觉基调

沿用 `snake.html` 的全息终端语言，默认给一套「薄荷苏打」配色（全部可改）：

| Token | 默认值 | 用途 |
|---|---|---|
| `--bg` | `#07131a` | 页面底色 |
| `--bg2` | `#0b2029` | 渐变第二层 |
| `--panel` | `rgba(10,34,44,.92)` | 面板/弹层 |
| `--line` | `rgba(120,230,220,.22)` | 细描边 |
| `--line2` | `rgba(130,245,225,.50)` | 高亮描边 |
| `--text` | `#e2fbf7` | 主文字 |
| `--dim` | `#7ea9a6` | 次文字 |
| `--accent` | `#3ee0c6` | 主色（缺口边、按钮、光标） |
| `--accent2` | `#b6fff0` | 高亮文字 |
| `--danger` | `#ff6b6b` | 红块 / 死亡 |
| `--gold` | `#ffc857` | 连降 / 新纪录 |

塔身环色按深度分段：薄荷 → 青蓝 → 靛紫，每 30 层循环；红块始终 `--danger`。月巴自身颜色仅用于拖尾粒子与选中光晕。

### 8.2 页面布局

```
┌──────────────────────────────┐
│ 螺旋·月巴   DEPTH 123  BEST 456  ⏸ │  34px 顶栏
├──────────────────────────────┤
│                              │
│        （Canvas 塔身）        │  自适应主舞台
│            月巴               │  DOM 图层
│                              │
├──────────────────────────────┤
│ 拖动旋转 · 对准缺口落下          │  提示条（6s 后淡出）
└──────────────────────────────┘
```

- 手机竖屏优先：舞台宽度 `min(100vw, 460px)`，高度铺满安全区。
- 顶栏数字变化时 `pop` 缩放（0.26s），不逐帧刷新。
- 弹层沿用四角光标 + 切角面板 + 扫描线；低功耗时扫描线关闭。

### 8.3 反馈

| 事件 | 表现 |
|---|---|
| 穿过一层 | 环边闪白 → 深度数字 pop → 升调叮声（音高随连降升高） |
| 连降 | 右侧「×N」大字弹入，`--gold` 描边，0.4s 后收敛 |
| 弹起 | 月巴压扁 0.86 → 回弹 1.04 → 1.0；低频「咚」 |
| 撞红块 | 0.18s 屏幕微震 + 红色边缘闪 + 月巴碎散粒子（低功耗无粒子） |
| 新纪录 | 结算页金色横幅 + 两段上扬音 |
| 倒计时 | 3 → 2 → 1 → GO!，650ms/跳，GO 后 420ms 开跑（沿用飞行页节奏） |

### 8.4 音效

- 复用 Web Audio 合成，无外部音频文件；全部 sine/triangle，避免刺耳方波。
- 共享一个 `AudioContext` + 总输出限幅（≤0.7）+ 单音音量钳制 + 并发 ≤8 + `onended` 释放。
- 键位：`rotateTick`（节流 80ms）、`fall`、`pass`、`bounce`、`red`、`record`、`uiClick`、`count`、`go`。
- 静音跟随主存档 `muted`，页内可切换。

### 8.5 月巴个性文案

- 死亡时随机抽 1 条「番茄对月巴说」口吻的短句，共 12–16 条，中文优先，四语言同步补齐。
- 新纪录时 1 条庆祝短句；不做复杂剧情，避免文案膨胀。

## 九、多语言

- 页内 `TXT` 字典四语言，键与 `tetris.html` 同风格；`?lang=` 优先，其次主存档 `lang`，最后浏览器。
- 月巴名称由父页下发时已本地化，子页不再翻译专名。
- 所有静态文案走页内 `T()`；未翻译项原样显示中文，绝不出现空白/`undefined`。
- 游戏名四语言同步补进 `I18N_UI`（首页百巴箱卡片用）。

## 十二、风险与待拍板

### 风险

| 风险 | 处理 |
|---|---|
| 150+ 张立绘同时加载拖慢选月巴页 | 缩略图 `loading="lazy"` + `decoding="async"`；无立绘走内联 SVG |
| 跨域立绘无法在 Canvas 绘制 | 月巴走 DOM 图层，不画进 Canvas，彻底避开污染问题 |
| 高刷新率/掉帧导致穿层漏判 | 用「上帧 y → 本帧 y」区间判定，角度统一 `wrapToPi` |
| 手机拖动与页面滚动冲突 | `touch-action:none` + `overscroll-behavior:none` + Pointer Capture |
| 低端机发烫 | DPR ≤ 2、粒子池、无模糊、后台停 RAF、低功耗开关 |
| 层生成不可达导致劝退 | 缺口偏移上限 55°、前 3 层新手缓冲、红块与缺口强制间隔 |
