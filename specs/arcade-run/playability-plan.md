## 二、现状盘点与缺口

**已有**：三车道弹簧切道、跳跃（预输入/落地缓冲）、3 种障碍、两层番茄、金番茄道具（ITEMS 表 + 权重池）、全力冲刺、小成就台词、最高分/累计统计、浅色伪 3D 田园跑道。

**缺口**：

1. **动作只有一种**：所有障碍都是「跳」，熟练后单局没有新决策；
2. **道具只有 1 种**：表结构留了但没内容，随机性低；
3. **风险回报弱**：擦边、连吃没有额外收益，最优策略单调；
4. **没有目标层**：只有「最高分」，玩家不知道自己「今天该干什么」；
5. **没有成长层**：玩 10 局和玩 1 局收获一样；
6. **长局单调**：2000m 后画面与节奏完全一样。

## 三、P1 动作纵深（最高优先）

### 3.1 滑铲（第三个动作）

- **输入**：`↓`/`S` 或下滑手势（与左右滑/上滑不冲突）；dpad 加「▼」键。
- **时长**：0.5s 滑铲，可被跳跃打断（滑铲中按跳 → 立即起跳）。
- **判定**：滑铲期间月巴身高压扁到 45%，可穿过**新障碍「藤架横杆」**（离地 34px 的横杆，跳不过去、只能滑）；滑铲中不能吃二层番茄（保持高度语义）。
- **表现**：月巴压扁 + 影子拉长，滑动时脚下扬尘；透视下压扁非常明显。
- **冷却**：0.15s（防连滑贴地），与跳跃互斥规则简单化：任一时段只能一个动作。
- **生成规则**：新增 `bar` 类型后，每行仍 ≤2 道；**同一行不得同时出现「必须跳」与「必须滑」**（避免无解组合）；bar 只出现在第 1 层且不叠加。

### 3.2 道具矩阵（复用现有 ITEMS 表）

| 道具 | 效果 | 分值 | 权重 | 视觉 |
| --- | --- | --- | --- | --- |
| 金番茄（已有） | 立即全力冲刺 5s | 200 | 1.0 | 金色果体 + 强光晕 |
| 辣椒 | 瞬时提速 ×1.35 持续 2s（不无敌） | 120 | 2.0 | 红色尖椒 |
| 磁铁 | 8s 内吸附半径 2 车道内的番茄 / 道具 | 100 | 1.5 | 环形磁铁 |
| 护盾 | 抵挡一次碰撞（撞后爆盾，不结算） | 80 | 1.0 | 半透明气泡 |
| 秒表 | 3s 全场减速到 ×0.6（番茄照吃） | 60 | 0.8 | 怀表 |

- 掉落间隔由 160~240m 收紧到 **140~220m**（种类变多，保持「偶尔惊喜」密度）。
- 全部走 `ITEMS` 表 + `ITEM_POOL`：新道具 = 一条表项（name/score/burst/draw/onEat）+ 权重，主循环零改动。
- 道具效果互斥规则：冲刺期间再吃金番茄 = 续时；护盾与冲刺并存（护盾仅兜底结算）。

### 3.3 连击与擦边（风险回报）

- **番茄连击**：同一条串内连续吃满 ≥5 颗 → 进入 combo，此前每颗追加 +10 分（串结束或漏吃即断）；HUD 在 combo≥2 时显示小角标 `×N`。
- **擦边闪避**：未跳/未滑、在 ±22px 内掠过障碍 → +20 分 + 短促音效 + 「险避！」气泡（由已有台词系统触发，冷却内静默）。
- 结算增加 **最高连击** 一行。

**P1 验收**：键盘（↓/S）与下滑手势均可滑铲；滑过横杆不吃判定、站着撞横杆即结算；5 种道具全部可生成/可拾取/效果正确；combo 与擦边计分精确；单帧 ≤0.5ms。

## 四、P2 目标感

### 4.1 每日挑战

- **种子**：`seed = 日期(YYYYMMDD)` → mulberry32 决定所有随机（行生成、番茄串层、道具种类与位置），当天全球同构（离线同构）。
- **每日修正**（按星期轮换）：周一「双金茄」、周二「速度 +10%」、周三「番茄 ×2 分」、周四「无道具」、周五「夜间版」、周六「密集障碍」、周日「全道具」。
- **存档**：`yueba-run-daily-v1 = { date, best, streak }`；连续天数在首页显示。
- **入口**：开始前小面板（首次运行展示，之后记忆上次模式），或暂停菜单「换模式」。

### 4.2 模式选择

| 模式 | 规则 | 目标 |
| --- | --- | --- |
| 标准无尽 | 现状 | 最远距离/最高分 |
| 限时 60s | 倒计时；撞障碍 −5s 不结束 | 60s 内最高分，节奏快、适合碎片时间 |
| 竞速无道具 | 禁用 ITEMS，纯走位+吃茄 | 最远距离，硬核玩家 |

### 4.3 本地榜单

- 本机 Top5（分数 / 距离 / 番茄 / 日期），`yueba-run-v1.board`；结算显示「历史第 N / 新纪录」。
- 兼顾离线与零依赖；不做网络同步。

**P2 验收**：同一天两次进入每日挑战布局完全一致（种子可复现）；三种模式规则正确；榜单跨会话保持；模式切换不污染标准模式存档。

## 五、P3 成长线

### 5.1 成就墙（16 条，持久化）

- 里程：单局 500 / 1000 / 1500 / 2000m
- 收集：累计吃茄 100 / 500 / 2000
- 冲刺：单局 3 次 / 累计 20 次
- 技巧：单局 10 连击 / 单次冲刺碎 5 箱 / 单局零道具 1000m
- 每日：连续 3 天 / 连续 7 天
- 交互：首次滑铲穿过横杆 / 首次擦边 5 次

存档：`yueba-run-v1.ach = {id: unlockTs}`；暂停菜单加「成就」小面板（切角卡片列表）。

### 5.2 皮肤解锁（复用图鉴立绘）

| 皮肤 | 解锁 | 效果 |
| --- | --- | --- |
| 吃茄月巴（默认） | — | 现配色 `#c96a73` |
| 金月巴 | 累计冲刺 30 次 | 主色换 `#e6c44c`，冲刺拖尾更亮 |
| 茄汁月巴 | 单局 1500m | 主色换 `#e5533d`，吃茄粒子加倍 |

头像/图标用 `DEX_ART`（已同步 132 条）；赛道内仍程序化绘制，只换主色 + 耳色，零新素材。

### 5.3 环境主题轮换

- 每 800m 在 3 套浅色主题间接力：**清晨**（现状）→ **黄昏**（天空暖橙、田野加深 5%）→ **雨前**（灰米色、雾带加厚）。
- 通过 lerp 配色 1.2s 过渡；种子/模式共享。避免长局视觉疲劳。
- 全部由现有绘制参数驱动，不动布局。

**P3 验收**：成就在跨会话后仍解锁；三套皮肤解锁/切换生效；主题每 800m 平滑切换且不闪帧。

## 九、风险与规避

| 风险 | 规避 |
| --- | --- |
| 滑铲让移动端操作变复杂 | 下滑手势即可；dpad 只加一个「▼」；教学只讲一次 |
| 新障碍与旧组合产生无解行 | 生成器加「同行动作互斥」硬规则 + 3 分钟机器人仿真回归（沿用现有测试手法） |
| 道具过多导致数值膨胀 | 每种道具分值封顶；冲刺/护盾互斥规则明确；每日修正单独平衡 |
| 每日种子可被「刷」 | 每日只有 1 次有效成绩，重玩只更新当天最佳 |
| 存档字段升级出错 | 只加字段 + 默认值合并；`try/catch` 包裹；旧档自动补全 |
| 单文件继续膨胀 | 当前 ~66KB，P1~P4 预计 +15KB，仍在可接受范围 |
