## 四、核心玩法设计

### 4.1 场景与视角

- 竖向画布自适应 iframe / 直开双环境；**伪 3D 透视**：路面为向地平线收束的梯形，世界坐标改为 `z`（前方距离），投影 `p = Z0/(Z0+z)` 同时决定屏幕 y 与物体缩放（近大远小）。
- 切道为**速度连续的二阶弹簧**横移（刚度 220、阻尼比 0.72，约 0.2s 完成 95%、约 2% 轻微回弹，中途反向保留惯性）；侧倾跟随横向速度、起止自然归零——替代原 120ms 定时缓动，消除起步「突然」感。跳跃为固定时长抛物线（腾空约 0.42s + 0.18s 缓冲），**腾空期间不与地面障碍碰撞**；跳跃时月巴抬升、影子缩小留在路面——透视下跳跃高度一目了然。
- 跳跃时长固定是手感关键：速度提升只改变障碍密度，不压缩反应窗口。

### 4.2 操作

| 环境 | 操作                                                           |
| -- | ------------------------------------------------------------ |
| 键盘 | `←`/`→`（或 `A`/`D`）切道；`↑`/`空格`/`W` 跳；`P`/`Esc` 暂停；结算层 `回车` 重开 |
| 触屏 | 左右滑切道、上滑跳；另配贪吃蛇式 dpad 兜底（窄屏显示）                               |
| 细节 | 跳跃支持 80ms 预输入缓冲（落地即跳）；`touch-action:none` 防滚动与双击缩放           |

### 4.3 番茄与道具（2026-11-01 调整）

- 番茄按「串」生成：直线串（顺路）+ 折线串（引导变道），串间隔随难度缩短。
- **两层番茄**：约 28% 的串整串悬在**第二层**（离地 52px，带地面影子提示高度），必须**跳起来吃**（判定窗 52±24px，站着或刚起跳够不到）；其余贴地第一层照旧。整串同层，不与障碍同道。
- **普通番茄：只加分**——+50 分并计入番茄计数与小成就（10/20/30 茄），**不加速、不充能**。
- **金番茄（道具）**：稀有掉落（约每 160~240m 一颗），必落在安全车道；吃到立即进入**全力冲刺 5 秒**：速度 ×1.8、无敌、撞碎障碍 +30 分、屏幕微暖高亮 + 月巴拖尾；结束前 1s 闪烁预警 + 结束再给 0.6s 渐出宽限（碎箱不计分），防「刚结束就撞」。道具分 **+200**，不计入番茄计数。
- **道具表接口**：`ITEMS`（name / score / burst / draw / onEat）+ `ITEM_POOL` 权重池。以后加新道具 = 加一行表项 + 池子加一行权重；生成、拾取、绘制、音效全部走表，不改主循环。瞬时提速 `addBoost(Δ)` 保留为道具可调用接口（普通番茄不再调用）。

### 4.4 障碍与难度曲线

- 首版障碍 2 种：木箱（单格）、长条栅栏（更宽，需提前跳）。
- 生成规则硬性保证：**任意时刻三车道不同时封死**；低速期不出现「连续双跳」组合。
- 基线速度每 200 米 +一档，上限 ×2.2；障碍密度同步上调。

### 4.5 结算与记录

- 结算层（贪吃蛇范式）：本次距离 / 番茄数 / 总分 / 历史最高分，一键重开。
- 破纪录时结算层加小型庆祝演出（彩纸粒子，低功耗档关闭）。

### 4.6 音效与台词

- 合成音效：吃茄 pop、跳跃 whoosh、冲刺号角、碰撞 thud；`muted` 从主存档只读。
- 台词气泡（幸存者范式）：首颗番茄 / 冲刺启动 / 摔跤 / 破纪录四类触发，随机 + 冷却 + 不重复。

## 七、存档与数据

独立存档键 `yueba-run-v1`（对齐 `yueba-<game>-v1` 惯例），`try/catch` 包裹读写：

```json
{
  "best":  { "dist": 0, "tomato": 0, "score": 0 },
  "totals": { "runs": 0, "dist": 0, "tomato": 0, "sprints": 0 },
  "settings": { "muted": false, "lowPower": false }
}
```

主存档 `idle-yueba-save-v2` 仅启动时**只读** `lang / muted / lowPower`，全程零写入。

## 九、风险与规避

| 风险                  | 规避                                               |
| ------------------- | ------------------------------------------------ |
| 立绘外链失效              | 程序化绘制兜底（pacman 先例），圆形头像降级为 SVG 月巴                |
| iframe 内触控滚动 / 双击缩放 | `touch-action:none` + 父页同款 `user-scalable=no`    |
| 手感断裂（提速后反应窗被压缩）     | 跳跃时长固定，速度只改密度；冲刺无敌期给容错；M2 起留固定 seed 回归用例         |
| 低端设备掉帧              | 车道层预渲染离屏 Canvas、粒子池上限 48、结算态常驻零 rAF              |
| 高分屏模糊               | 按 `devicePixelRatio` 缩放画布                        |
| 存档污染                | 只写 `yueba-run-v1`；全部 localStorage 调用 `try/catch` |
| 障碍生成出死局             | 生成器保证三车道永不同时封死 + 单元测试式抽样校验                       |
