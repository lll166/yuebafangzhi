## 三、叙事与主题映射

### 3.1 一句话故事

> 万圣夜的月巴迷宫亮起南瓜灯，一只番茄抱着一袋南瓜糖路过。四只月巴从窝里探出头——它们等这一口，等了一整年。

### 3.2 元素映射

| 吃豆人概念 | 本作表现 |
| --- | --- |
| 豆子 | **南瓜籽**，暖黄小点，吃掉记 10 分 |
| 能量豆 | **南瓜糖**，四角各一颗；吃下后番茄变「酸番茄」，月巴变慢、掉头、可被反吃 |
| 幽灵 | **不同月巴**，各有立绘与 AI 性格 |
| 幽灵屋 | **月巴窝**（迷宫中央），月巴从这里依次出发 |
| 受惊幽灵 | 酸番茄状态下的月巴：立绘降饱和 + 白色描边 + 头顶「!」 |
| 水果奖励 | **糖霜番茄**：每夜中期在中央出现 6 秒，价值 300 分（冒险奖励） |
| 生命 | 3 个番茄图标 |
| 过关 | 吃光南瓜籽，南瓜灯自左向右依次点亮 |

### 3.3 文案基调

- 万圣节氛围，但**可爱、不吓人**：月巴是真的想吃番茄，不是恶灵。
- 番茄嘴硬心软，吐槽多于卖萌；月巴一本正经地讲「一口一个」。
- 被吃、被反吃都用轻喜剧处理，不出现血腥描述；失败文案不责备玩家。

示例：

- 番茄开局：「今晚只想安安静静吃糖。」
- 月巴逼近：「别跑呀，一口就好。」
- 番茄反吃：「现在轮到我追你们了。」
- 月巴被反吃：「等等，这剧本不对。」

## 四、形态与接入

### 4.1 独立页 + 百巴箱 iframe

对齐 `minesweeper.html` / `goldminer.html` / `nonogram.html` 的方式，不把迷宫塞进 `index.html`：

| 对比项 | 贪吃蛇 / 幸存者 | 本作 |
| --- | --- | --- |
| 游戏本体 | 独立页 / 页内浮层 | 独立 `pacman.html` |
| 打开 | 百巴箱或图鉴入口 | 百巴箱卡片；M5 后加图鉴入口 |
| 关闭 | 卸载 iframe | `fr.src='about:blank'`，回百巴箱或图鉴 |
| 首页计时 | 继续运行 | 继续运行 |
| 存档 | 独立键 | 独立键 `yueba-pacman-v1` |
| 语言 | 页内字典 + 主存档 | 页内字典 + 主存档只读 |

- iframe 盖在首页之上，番茄钟、月巴生长、自动收获、5 秒自动存档全部继续；
- 页面只负责迷宫、计时、音效、台词；关闭即销毁；
- 首页只加 `gb-lock`（`overflow:hidden`），不碰任何计时器与存档逻辑。

### 4.2 两条入口

| 入口 | 出现位置 | 行为 | 实装前 |
| --- | --- | --- | --- |
| 百巴箱卡片 | 首页底部 dock「百巴箱」→ 卡片网格 | `gbFrameOpen` 打开，关闭回百巴箱 | **不显示**（`hidden:true`） |
| 图鉴入口 | 图鉴 → 万圣月巴 / 吃茄月巴 详情与卡片 | `dexPacmanEntry()` → `gbFrameOpen(g,'dex')`，关闭回图鉴 | **不接入**（M5 再加） |
| 直接打开 | 双击 `pacman.html` | 完整游玩，默认语言/主题 | 开发期可用 |

### 4.3 实装前隐藏策略

1. **M1 起**就把卡片写进 `GB_GAMES`，但带 `hidden:true`；箱内看不到，也不影响现有卡片。
2. **M1–M4 不改** `DEX_GAME`，避免图鉴出现打不开的按钮。
3. **M5 验收通过后**：删除 `hidden:true`，并接入 `DEX_GAME` 与 `dexPacmanEntry`。
4. 开发期直接双击 `pacman.html`，或 `?selftest=1` 自检，不依赖百巴箱入口。

## 五、玩法设计

### 5.1 核心循环

```
百巴箱点「月巴追茄」
  → 标题页（主题 / 音效 / 台词开关 / 最佳记录 / 成就 / 开始）
  → 第 N 夜开局：迷宫铺满南瓜籽，4 只月巴在窝里待命，番茄在底部出生
  → 3 秒倒数 → 月巴依次出窝
  → 移动、吃籽、躲月巴
      → 吃到南瓜糖：番茄变酸，8 秒内可反吃月巴
      → 被碰到：掉 1 条命，重生，月巴回窝
      → 吃光南瓜籽：过关，南瓜灯依次点亮，进下一夜
  → 3 条命用完
      → 夜记：本局分数 / 到达夜数 / 反吃次数 / 最佳纪录
      → 再来一次 / 换主题 / 查看成就 / 返回百巴箱
```

### 5.2 迷宫与出生点

- **19 列 × 21 行**，左右镜像手绘，保证每个连通块都有出口，不存在只有一条死路的窄袋。
- 360px 宽下每格约 18px（342px 宽），竖屏优先；桌面端整体最大 460px。
- 中央 3×2 为「月巴窝」，四只月巴按 2 秒间隔依次出窝。
- 第 10 行左右两端为**隧道**：走出左边界从右边界进入，月巴同样适用（速度在隧道内降 40%）。
- 4 颗南瓜糖分布四角，距离出生点均有一段路；每夜固定位置。
- 南瓜籽总数约 170–190，按迷宫手工点数，不随机生成。
- 3 张迷宫（`M1 / M2 / M3`）手写数据，第 4 夜起循环使用；每张都是左右对称结构，只在中央窝与隧道位置有差异。

### 5.3 移动与输入

| 项 | 方案 |
| --- | --- |
| 坐标 | 浮点格坐标（格 = 1.0），速度单位「格/秒」 |
| 逻辑步长 | 固定 1/120 秒累加，最多补 4 步，避免后台回来跳帧 |
| 转向 | 只在格中心 ±0.12 格容差内生效；缓存「最近一次输入方向」 |
| 反向 | 允许在任意位置立即掉头（含半格内） |
| 番茄速度 | 6.2 格/秒 |
| 月巴速度 | 第 1 夜 5.6，每夜 +0.35，上限 7.2；酸番茄状态降至 3.8 |
| 碰撞 | 中心距离 < 0.55 格判为碰到；吃籽 < 0.62 格 |
| 卡墙 | 撞墙时停在格中心，保留输入方向继续等待 |

**不要做**：不做逐格跳跃、不做惯性滑行、不做八方向。手感必须像原版吃豆人：贴墙拐弯顺、掉头干脆。

### 5.4 月巴 AI

| 月巴 | 目标格 | 行为特征 |
| --- | --- | --- |
| 吃茄月巴 | 番茄当前格 | 直线压迫，最容易被玩家绕柱甩开 |
| 墨镜月巴 | 番茄前方 4 格（按番茄朝向） | 提前卡位，封住玩家的下一段路 |
| 进食月巴 | 番茄关于迷宫中心的对角镜像点 | 从另一侧包抄，逼玩家改道 |
| 小月巴 | 追时随机选路口，距离 < 8 格改为逃跑 | 制造不确定，不硬追 |
| 万圣月巴（第 3 夜起） | 番茄当前格 + 随机 ±2 格偏移，每 4 秒刷新 | 走位刁钻，速度 +0.25 |

- 共同规则：路口禁止直接掉头；同向优先；每次到达格中心才决定下一格。
- 追击 / 散开节奏：散开 7s → 追击 20s → 散开 7s → 追击 20s → 散开 5s → 追击常驻。
- 散开目标为四角固定点，形成「绕圈喘息」的节奏，避免全程贴脸。
- 酸番茄：全体减速、强制掉头 0.6 秒，并进入「逃跑」目标（各自回窝方向）。
- 不做「每只幽灵独立随机种子」这种不可复现的设计；随机只用于小月巴与万圣，且用固定种子便于自检。

### 5.5 南瓜糖与反吃

| 项 | 规则 |
| --- | --- |
| 南瓜糖数量 | 每夜 4 颗，吃后本夜不刷新 |
| 持续时间 | 第 1–2 夜 8 秒；第 3 夜起 6 秒；第 6 夜起 5 秒 |
| 反吃分值 | 同一次酸番茄内 200 / 400 / 800 / 1600 / 3200（第 5 只起封顶） |
| 连吃奖励 | 一次酸番茄吃满 4 只：额外 +1000，屏幕轻震 2px（低功耗关） |
| 状态表现 | 番茄外圈烛黄色光晕 + 轻微脉冲；月巴立绘降饱和 + 白描边 + 「!」 |
| 结束提示 | 最后 1.5 秒光晕闪烁，月巴恢复原色 |

### 5.6 计分、生命与夜数

| 项 | 规则 |
| --- | --- |
| 南瓜籽 | 10 分 |
| 南瓜糖 | 50 分 |
| 反吃月巴 | 200 / 400 / 800 / 1600 / 3200 |
| 糖霜番茄 | 300 分，每夜出现 1 次，持续 6 秒 |
| 过关 | +1000 × 当前夜数 |
| 加命 | 每 10,000 分 +1 条命，上限 5 |
| 初始生命 | 3 |
| 夜数 | 无尽；第 3 夜起万圣月巴加入，第 4 夜起循环迷宫 |

- 分数只在 HUD 与结算页展示，不做逐帧数字动画以外的特效。
- 夜数越高，月巴速度与出窝间隔都更紧；南瓜糖时间更短。
- 第 10 夜后不再加难度，防止变成不可能通过的数值墙。

### 5.7 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 移动 | 方向键 / WASD | 全屏滑动（阈值 18px）或虚拟方向键 |
| 暂停 | `Esc` / 暂停按钮 | 暂停按钮 |
| 开始 / 重开 | `Enter` / 结算页按钮 | 同左 |
| 主题切换 | 标题页 / 暂停页 | 同左 |
| 音效 | 标题页开关 | 同左 |

- 默认在触屏设备显示虚拟方向键（沿用 `snake.html` 的 3×3 dpad，尺寸 42–50px），可在设置里关掉改用滑动。
- 滑动取「最近一次有效方向」，不要求手指跟随；转向仍以格中心为准，保证精确。
- 键盘只在 iframe 聚焦时生效，关闭后随文档销毁。
- 暂停页不冻结台词冷却计时（恢复后继续），避免暂停刷台词。

### 5.8 暂停、后台与结束

- `visibilitychange` 隐藏时自动暂停，回来停在暂停层，玩家点「继续」再恢复。
- 计时与 AI 全部由固定步长驱动，暂停即停止累加，不使用 `setInterval`。
- 3 条命用完进入结算；不提供「原地复活」，避免破坏分数意义。
- 结算后可「再来一次」（同主题、同设置），分数不继承。

## 六、UI 与视觉规范

### 6.1 参考什么、改什么

**沿用（来自贪吃蛇 / 幸存者）：**

- 顶部 HUD：左侧标题，右侧分数 / 夜数 / 剩余命的切角小芯片；
- `clip-path` 切角、1px 细边 + 左侧 2px 高亮边、等宽字体、`//` 前后缀小标签；
- 四角光标框、底部操作条、结算 / 暂停 / 成就层的卡片结构与按钮节奏；
- `snake.html` 的虚拟方向键布局与按压缩放；
- `survivor.html` 的左下角番茄头像气泡（边框、箭头、淡入淡出）；
- 低功耗与 `prefers-reduced-motion` 降级规则。

**改掉：**

- 深青底 `#031019` + 冷青主光 `#46e6f2` → **万圣节紫黑底 + 南瓜橙**；
- 扫描线 / 暗角 → **淡雾 + 烛光呼吸**（静态渐变 + 2 处轻微动画）；
- 全息发光描边 → **细描边 + 柔和暖光**，不做霓虹管；
- 冷青 HUD 高亮字 → 烛黄 / 南瓜橙高亮字。

> 结论：**骨架像贪吃蛇，气泡像幸存者，气质是万圣夜的糖果纸**。

### 6.4 立绘在迷宫里的处理

| 项 | 方案 |
| --- | --- |
| 尺寸 | 立绘绘制为 **1.35 格**，允许压过墙面一点点；碰撞仍按 0.55 格判定 |
| 裁切 | 圆形裁切（`ctx.clip()`），显示中心脸，不做像素化 |
| 识别 | 每只月巴外圈 2px 角色色描边（吃茄橙红 / 墨镜紫 / 进食青绿 / 小月巴淡紫 / 万圣深紫） |
| 朝向 | 不做整体旋转；仅左右镜像 + 移动时 1.03 倍挤压，避免立绘「倒着走」 |
| 酸番茄 | 立绘 `saturate(.25) brightness(.85)` + 白描边 + 「!」气泡标记 |
| 加载失败 | 回退到程序化圆形 + 耳朵 + 眼睛（与幸存者同思路），保证离线与 404 时不空白 |
| 预渲染 | 启动时把每张立绘烘到 2× DPR 的离屏 Canvas，主循环只 `drawImage` |

> 不做 `getImageData` 等像素读取，避免外链图片的 CORS 限制；只做 `drawImage` + `clip`。

### 6.5 动效与打击感

| 动作 | 表现 | 低功耗 |
| --- | --- | --- |
| 吃籽 | 籽 90ms 缩到 0，分数 +10 上浮 90ms | 保留 |
| 吃南瓜糖 | 番茄橙光外扩 220ms，月巴集体「!」 | 关闭外扩 |

- **禁止全屏闪白**（用户明确不喜欢闪烁）；命中反馈只做局部。

- 月巴用「立绘 + 描边色 + 头顶标记」区分，不只靠颜色。
- 分数、命、夜数都有文本；不只靠图形。
- 对话可关闭；关闭后台词位保留为空占位。

## 七、台词系统（重点预留）

### 7.1 双通道

| 通道 | 位置 | 数量 | 生命周期 |
| --- | --- | --- | --- |
| 番茄 | 底部台词常驻位（头像 + 气泡） | 同时最多 1 条 | 2.6 秒淡出，可被更高优先级覆盖 |
| 月巴 | 跟随说话月巴头顶 / 脚下 | 同时最多 1 条 | 2.4 秒淡出，靠近边缘自动翻转方向 |

- 两条通道互不阻塞，可以同时出现（番茄吐槽 + 月巴回嘴），但不允许同一通道排队超过 1 条。
- 月巴说话者选择：**当前距离番茄最近的月巴**；同一事件不重复触发。
- 台词位在布局中**始终占位**，无台词时也不塌陷。

### 7.2 触发事件与示例

| 月巴进入 3 格内 | 月巴 | 中 | 「别跑呀，一口就好。」 |
| 擦身而过（<1 格且脱离） | 番茄 | 高 | 「差一点点！差一点点！」 |
| 反吃第 1 只 | 番茄 | 高 | 「现在轮到我追你们了。」 |
| 反吃第 4 只 | 番茄 | 高 | 「今晚的糖，我请。」 |
| 月巴被反吃 | 月巴 | 中 | 「等等，这剧本不对。」 |

- 反吃第 4 只、最后一条命、过关属于「一局只出现一次」的高光台词，用后即标记。

### 7.3 冷却与去重

| 规则 | 值 |
| --- | --- |
| 全局最小间隔 | 4 秒 |
| 番茄通道 | 8 秒 |
| 月巴通道 | 6 秒 |
| 最近不重复 | 各通道最近 3 条不重复 |
| 排队上限 | 每通道 1 条，超出丢弃 |
| 暂停时 | 冻结计时与显示，恢复后继续 |
| 结算页 | 不显示气泡，改在结算文案里显示一句 |

- 高优先级事件可打断低优先级气泡，低优先级不可打断高优先级。
- 单局台词总量上限 40 条不设限，重复由「最近 3 条」与「高光一次性」共同控制。

## 八、音效

- 全部 Web Audio API 合成，复用「单一 AudioContext + 总输出限幅 + 单音音量钳制 + 并发上限 + 节点释放」规范。
- 不引入音频文件；静音开关读主存档 `muted`，本作不另存。
- 低功耗模式**不影响音效**，只关视觉特效。
- 整体可爱、圆润，避免尖锐与杂乱；不使用长混响、不做奇怪的空间效果。

| 事件 | 音色方向 |
| --- | --- |
| 吃籽 | 木琴短音，连续吃时按阶梯升调（最多升 5 档） |
| 吃南瓜糖 | 上行四音 + 低频轻微 wobble |
| 反吃月巴 | **四档奖励音**：200 / 400 / 800 / 1600 各不同音高与音色厚度 |
| 一口气四只 | 额外一层和声小上行 |
| 被碰 | 柔和下降三音 + 轻「噗」，不刺耳 |
| 过关 | 小调琶音，短混响 |
| 开场 | 两声木琴 + 低音垫 |
| 台词气泡 | 极轻的「啵」 |
| 按钮 | 轻点 |

- 同帧多事件按 120ms 前缘节流合并，避免并发爆音。

## 十三、动效清单（M6，克制档）

> 依据已确认的选择：**A 打击反馈 / B 追逐动感 / C 场景氛围 / D UI 与结算 四批全做，强度取「克制」**。
> 实施顺序 **A → B → C → D**，每批独立可交付、可回滚；不新增图片、不新增音效、不改存档结构。

### 13.0 总原则（所有动效必须遵守）

| 约束 | 规则 |
| --- | --- |
| 强度 | 位移 ≤ 6px、缩放 ≤ 1.12、旋转 ≤ 8°、单次时长 ≤ 0.6s（场景循环除外） |
| 时钟 | 只复用 `animT`（`update()` 已累加）与 CSS 类重播（`void el.offsetWidth`）；**不新增 setInterval / 逐帧定时器** |
| 上限池 | 飘字 ≤ 8、冲击环 ≤ 4、残影每角色 ≤ 4、萤火 ≤ 8；粒子沿用现有 48 上限 |
| 降级 | `body.lp` 或 `prefers-reduced-motion` → 去掉位移/缩放/循环动画，只保留透明度与颜色变化 |
| 自检 | `?selftest=1`（`quiet`）下不弹 toast、不震屏、不生成飘字与粒子 |
| 禁用 | 全屏 `filter` / `backdrop-filter`、动画 `box-shadow`、新图片资源、新音效 |
| 调参 | 新增 `FX` 常量块集中写时长与幅度，一次改档即可整体变「更含蓄 / 更明显」 |

实现上分成两类，互不干扰：

- **Canvas 层**（角色、粒子、飘字、灯）：在 `draw()` 内按 `animT` 求值，走现有渲染循环，零额外开销结构。
- **DOM/CSS 层**（HUD、气泡、覆盖层、萤火、雾、月亮）：新增 class + `@keyframes`，事件里加类，不碰逻辑循环。

### 13.2 批次 B：追逐动感（5 项）

| 编号 | 动效 | 触发点 | 实现位置 | 参数（克制档） | 低功耗 / reduceMotion |
| --- | --- | --- | --- | --- | --- |
| B1 | 朝向翻转 | 番茄 `player.want.x`、月巴 `g.dir.x` 变化 | `drawSprite()` 增 `flip` 参数，`ctx.scale(flip,1)` | 瞬时翻转，无过渡；正负沿用上次值防半格抖动；以圆心为轴，不影响 ring 与 lift | 不降级（属静态朝向） |

- B4 只在隧道段启用，常速区不生成残影——克制档不追求「全程拖尾」。
- 「逼近时月巴淡拖影」与 B4 共用同一残影池即可，若启用则阈值取距离 < 3 格、alpha ≤ .08，属可选增强，不单独占一项。
