# 月巴追茄 · 文案总表

> 用途：把游戏里所有对玩家可见的文字集中到一处，方便修改与追加台词。
> 唯一来源：`pacman.html` 内的 `I18N` 对象。本文件只是清单，**不参与运行**；改完后需要同步回代码。
> 四种语言：`zh` 简体中文 / `en` English / `ja` 日本語 / `ko` 한국어。缺键时页面回退到中文。

---

## 一、怎么改、怎么加

1. **改界面文案**：改第二节表格里对应单元格，回代码替换 `I18N` 中同名的键。
2. **加台词**：直接往第四节对应台词池追加一条，数量不限，代码随机抽取（`pickLine` 只保证不和上一次同组重复）。
3. **新增全新的键**：四种语言都要加，否则非中文语言会缺字。
4. **长度**：英文 ≤ 48 字符、日文 ≤ 24 字、韩文 ≤ 22 字，360px 宽下才能压在 2 行内。
5. 台词里的 `{n}` 是占位符（夜数），不要删。

## 四、台词池

- **番茄**的台词显示在底部台词位（左下角番茄头像 + 气泡）。
- **月巴**的台词显示在追兵头顶的小气泡，五只月巴**共用**同一组池子。
- 抽取规则：同组随机，且不会和上一次同组那句重复；番茄冷却 5.5 秒，月巴气泡显示 2.2 秒、冷却 7–10 秒。
- 高光台词（开局、吃糖、连吃、过关、掉命、被榨干）是**必出**，不受冷却影响。

## 七、待确认 / 可以继续扩的

1. **`startLine` 键**：四种语言都写了，但当前代码没有引用（实际开局台词走 `start` 池）。可以删，也可以留给「标题页固定一句」。
2. **成就只有名称，没有描述**：计划书里写了「8 条名称 + 8 条描述」，代码目前只显示名称。要做的话给每条补一句描述，我再加字段与排版。
3. **月巴没有独立台词**：五只共用 `near / flee / eaten`。如果想让吃茄 / 墨镜 / 进食 / 小月巴 / 万圣月巴各说各的，需要把 `lines` 改成按角色 id 分组（代码改动，文案可以先在这里按角色分栏草拟）。
4. **标题页大标题**：之前固定为中文「月巴追茄」，已改为跟随语言（`#ttl` 现在读 `title` 键）。
