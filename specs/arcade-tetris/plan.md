## 四、玩法设计

### 4.1 核心循环

```
百巴箱点「俄罗斯巴块」
  → 准备页：经典无尽 + 最高分 + 操作提示
  → 对局：方块下落 → 移动/旋转/暂存/硬降
      → 堆叠 → 填满整行 → 月巴被「收获」→ 计分/连击/升级
      → 堆到顶 → 月巴睡着 → 结算（分数/行数/等级/最长连击）
  → 再来一局 / 返回百巴箱
```

### 4.2 棋盘与基础规则

| 项 | 规则 |
|---|---|
| 尺寸 | 内部 10 列 × 22 行；可见 10×20，顶部 2 行为出生缓冲区 |
| 出生 | 方块在顶部缓冲区内生成；若出生位置已被占用 → 立即结束 |
| 重力 | 按等级计时下落；`重力间隔 = max(45ms, 1000ms × 0.86^(等级-1))` |
| 升级 | 每累计消除 10 行升 1 级，最高 20 级（间隔封顶 45ms） |
| 锁定 | 落地后 500ms 锁定延迟；移动/旋转可重置，最多 15 次；硬降立即锁定 |
| 旋转 | 顺时针 / 逆时针两向；使用轻量墙踢偏移表（0、±1、±2、上 1） |
| 随机 | 7-bag：每袋 7 种各一次，洗牌后依次发出；预览 3 个 |
| 暂存 | 每落一个方块只可暂存一次；暂存后不可立刻再换 |
| 影子 | 显示落点虚影（可在设置关闭） |
| 结束 | 新方块无法出生，或锁定后整块完全位于可见区之上 |

### 4.3 计分

| 行为 | 分数 |
|---|---|
| 消 1 / 2 / 3 / 4 行 | 100 / 300 / 500 / 800 × 等级 |
| 软降 | 每格 +1 |
| 硬降 | 每格 +2 |
| 连击 | 从第 2 次连续消除起，每次 +50 × 连击数 × 等级 |
| 全清（Perfect Clear） | 额外 +1000 × 等级 |

不实现 T-spin、Back-to-Back、旋转加分，避免判定复杂度与规则争议。

### 4.4 模式

只有 **经典无尽** 一种模式：标准规则，升级到 20 级封顶，直到堆顶结束。记录历史最高分、最高行数、最高等级、最长连击；不做每日一局、不做日期种子、不做每日最佳。

### 4.5 操作

| 输入 | 桌面 | 手机 |
|---|---|---|
| 左/右移 | ← / →（DAS 150ms，ARR 33ms） | 左右拖动 1:1（每跨 0.45 格移动 1 格）；底部 ◀ ▶ 长按连续移动 |
| 软降 | ↓ | 缓慢下滑 / 底部 ▼ 长按 |
| 旋转 | ↑ / X（顺时针），Z（逆时针） | 轻点棋盘 = 顺时针；底部 ↻ |
| 硬降 | 空格 | 快速下滑甩动 / 底部 ⇩ |
| 暂存 | C / Shift | 上滑 / 底部 HOLD |
| 暂停 | P / Esc | 顶栏 ❚❚ |

细节：

- 拖动阈值 0.45 格，逐格触发，不做惯性滑动，保证「1:1 跟手」；
- 轻点判定 <200ms 且位移 <8px；甩动判定为末段速度 >0.8 格/16ms；
- 锁定前 200ms 内允许一次输入缓冲（旋转/暂存），减少「按了没反应」；
- 触屏默认同时显示手势与按钮；设置里可切换「仅手势 / 仅按钮」；
- 所有触控区域 `touch-action:none`，阻止页面滚动与长按菜单。

### 4.6 判定与反馈节奏

| 事件 | 反馈 |
|---|---|
| 移动 | 兔耳 1–2px 惯性滞后；极短促「嗒」声 |
| 旋转 | 耳朵轻微甩动 + 70ms 高光 |
| 锁定 | 身体 2 帧压扁 + 轻尘粒子 + 低频桌响 |
| 消行 | 该行月巴睁眼 → 番茄横扫 → 身体碎成番茄色粒子 → 行塌缩（约 220ms） |
| 连击 | 连击数弹出，音高随连击上升 |
| 四消 | 全屏淡紫脉冲 + 红色「大丰收」横幅 + 更重的低频冲击 |
| 全清 | 棋盘短暂留白 + 满屏星星 + 专属提示 |
| 堆顶 | 全场月巴闭眼、去饱和，结算面板「月巴们睡着了」 |

消行动画期间不接受连续移动，缓存至多一次旋转/暂存并在动画结束后立即执行（总时长 ≤220ms），避免手感发黏。低功耗模式关闭粒子、震屏、脉冲与扫描线，仅保留必要的行闪烁与计分弹字。

### 4.7 声音

- 全部使用 Web Audio 合成，不引入音频文件；
- 单音音量 <0.2、并发 ≤8、总输出限幅 0.7，沿用主游戏调音习惯；
- 音色以 sine / triangle 为主，移动与旋转用短脉冲，消行用上行音阶，四消加低频冲击；
- 静音初值读主存档 `muted`，页面内切换只影响本页；
- 首次用户交互后才创建 `AudioContext`，避免自动播放限制。

## 五、月巴方块造型（本作核心）

### 5.1 设计原则

「每个俄罗斯方块都是月巴形状（有兔耳）」按**整块一只月巴**实现，而不是每格一只：

1. **下落中**：4 个格子融合成一个完整剪影，只画一张脸、一对兔耳，整块读起来就是一只月巴；
2. **落地后**：月巴「睡着」，保留身体颜色与耳朵，脸部降为低对比闭眼，作为墙体的一部分；
3. **被消行时**：整行月巴睁眼、耳朵抖动，被番茄收走，强化「收获月巴」的主题；
4. **预览/暂存**：显示缩小版清醒月巴，一眼能认出下一只是谁。

这样既满足「每个方块都是月巴」，又不会出现「一格一张脸」导致棋盘过花、格子边界难辨的问题。

### 5.2 七种月巴身份

| 方块 | 造型 | 耳朵 | 脸的位置 | 主色（建议） |
|---|---|---|---|---|
| I | 长条月巴，趴得很长 | 双耳平贴 | 左起第 2 格 | `#f0f1fc` 月白 |
| O | 圆圆月巴，四格一团 | 双耳直立 | 左上格偏内 | `#d2d6ee` 浅薰衣草 |
| T | 顶格双耳、下摆三点 | 双耳竖立 | 下方中间格 | `#b4b9de` 薰衣草 |
| S | 歪头月巴 | 左高右低 | 左中格 | `#9699c8` 灰紫 |
| Z | 反向歪头月巴 | 右高左低 | 右中格 | `#7277a6` 深灰紫 |
| J | 左撇月巴 | 左竖右垂 | 左下格 | `#535884` 深靛 |
| L | 右撇月巴 | 右竖左垂 | 右下格 | `#b23642` 砖红（全盘唯一红色，呼应立绘中的红块） |

> 配色取自 `m3_eluosi` 立绘采样：身体 `#e0e1f2`、灰紫 `#7e81ab`、红色 `#a12323`。七块沿「月白 → 深靛」做明度阶梯，仅 L 块使用红色，使红色始终是点缀而不是主色。

- 身体：圆角合并剪影 + 2px 深色描边 + 底部浅色腹毛；
- 耳朵：每只高约 0.55 格，耳内粉色；不参与碰撞，允许伸到格子之上；
- 脸：两颗小眼睛 + 小嘴 + 腮红；清醒/闭眼两套；
- 影子：10% 填充 + 虚线轮廓，不画脸与耳朵，避免干扰判断。

### 5.3 渲染规则

1. 活跃方块：统一剪影，一张脸，一对耳；耳朵绘制在「整块最上方那一格」；
2. 落地方块：按格绘制圆角月巴块；**只有上方没有相邻方块的格子才画耳朵**，避免每格都长耳；
3. 顶部缓冲区：画布上方预留 0.6 格内边距给耳朵，耳朵不侵入顶栏，也不改变碰撞；
4. 每块落地后保留一个低透明闭眼脸（≤0.35），既保留「这是一只月巴」的记忆，又不糊满屏；
5. 同色相邻块之间留 1px 深色缝，保证堆叠网格可读；
6. 颜色之外再用不同耳形与脸的落点区分 7 种，照顾色弱玩家。

### 5.4 动效与性能

- 棋盘静态层用离屏 Canvas 缓存，只有棋盘变化（锁定/消行/塌缩）才重绘；
- 活跃方块 + 粒子 + 行闪光画在动态层，每帧只重绘这一层；
- 粒子上限 120，超出从最旧的回收；
- 低功耗：粒子上限 0、关闭震屏、关扫描线与发光，重力与判定完全不变。

## 六、页面与视觉

### 6.1 布局

**竖屏（主）**

```
┌────────────────────────────┐
│ 俄罗斯巴块   SCORE BEST 行/级  🏆 ❚❚ │
├────────────────────────────┤
│  HOLD   [月巴]   NEXT [x3]  │
├────────────────────────────┤
│                            │
│        10×20 棋盘           │
│      （兔耳可在顶部溢出）      │
│                            │
├────────────────────────────┤
│ ◀  ▶   ↻   ▼   ⇩   HOLD    │
└────────────────────────────┘
```

**横屏 / 宽屏**：棋盘居中，HOLD 与 NEXT 移到左侧，分数与连击移到右侧；底部按键可收成一行。

- 棋盘高度 = 可用高度 − 顶栏 − 预览条 − 触控条 − 安全区，最小保证 10×20 可读；
- 视口不足时优先缩小棋盘，不隐藏操作键；
- 字号与按钮沿用蛇月巴的紧凑风格，避免手机端溢出；
- 宽屏最大棋盘宽度受限，不无限拉伸。

### 6.2 视觉语言（沿用蛇月巴版式，配色取「俄罗斯巴块」）

- 背景 `#0a0c16 → #141728` 径向渐变，棋盘区更深（`#0d1020`）；

- 语言判定顺序与蛇月巴一致：`?lang=` → 主存档 `lang` → `navigator.language` → `zh`；

- 需要翻译的范围：标题、模式、HUD 标签、操作提示、暂停/结算、设置、15 项成就、7 种月巴名、无障碍 `aria-label`；

- 提供 `?selftest=1` 时的「字典键一致性」检查，缺键直接列在自测面板。

## 十、测试与验收

### 10.1 页内自测（`?selftest=1`）

在页面内跑一组不依赖网络的检查，结果面板逐条显示通过/失败：

1. 7-bag：抽 70 个，7 种各出现 10 次；
2. 四向旋转：7 种 × 4 态，边界坐标不越 4×4；
3. 碰撞：左右墙、地板、堆叠、出生区；
4. 墙踢：贴墙旋转不穿墙、不卡死；
5. 消行：0–4 行识别与塌缩结果一致；
6. 计分：单/双/三/四消、软降、硬降、连击、全清；
7. 等级：每 10 行升级、20 级封顶、重力下限；
8. 存档：写入/读取/缺字段兜底/损坏重置；
9. 四语言字典：键集合一致、无空值；
10. 渲染冒烟：7 种方块 + 20 行堆叠绘制无异常。

### 10.2 手动验收清单

- [ ] 桌面键盘可完整游玩：移动、双向旋转、软降、硬降、暂存、暂停、重开；
- [ ] 手机竖屏：所有按键可见可点，滑动不滚动页面，轻点旋转不误触；
- [ ] 横屏/矮屏：棋盘不被裁切，操作区仍在屏幕内；
- [ ] 连续游玩 10 分钟无卡死、无输入丢失、无音效叠加爆音；
- [ ] 消行动画不吞输入，动画结束后手感立即恢复；
- [ ] 切换标签页自动暂停，回来需手动继续；
- [ ] 关闭 iframe 后音效立即停止，再次打开是全新一局（或保留记录但不出声）；
- [ ] 低功耗模式：粒子/扫描线/震屏消失，规则与计分不变；
- [ ] 四语言切换后无残留中文（专有名词除外）；
- [ ] 刷新/重开页面后最高分、成就、设置都还在；
- [ ] 开发前后对比 `localStorage`：`idle-yueba-save-v2` **无任何变化**；
- [ ] 实装前：百巴箱内看不到卡片，图鉴详情无入口；
- [ ] 实装后：取消注释即出现卡片，进入/关闭回百巴箱，图鉴入口关闭回图鉴。

### 10.3 通过标准

满足以下全部条件才算可上线：

1. 经典模式可稳定游玩 10 分钟以上，规则与手感无明显缺陷；
2. 手机端主要操作路径（移动/旋转/硬降/暂存/暂停）全部可用且响应及时；
3. 7 种方块一眼可辨认为「带兔耳的月巴」，堆叠后网格仍清晰；
4. 消行、连击、四消反馈明显强于普通移动，符合「爽快」目标；
5. 主存档零写入、零奖励、零消息通道；
6. 入口隐藏/开放切换只需取消注释，无需改游戏逻辑。

## 十二、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 月巴造型糊成一片，格子边界不清 | 影响可玩性 | 活跃块统一剪影；落地块分格 + 1px 缝；耳朵只在顶部空格出现；7 色 + 耳形双重区分 |
| 兔耳遮挡上方格子 | 误判落点 | 耳朵只占顶部 0.55 格内边距，不进入棋盘行；影子单独绘制 |
| 手机手势与页面滚动冲突 | 误操作 | `touch-action:none`、阈值分离、按钮兜底、可切「仅按钮」 |
| 墙踢边界情况卡死 | 破坏手感 | 使用固定偏移表 + 自测 + 随机模糊输入测试 |
| 消行动画吞输入 | 手感发黏 | 动画 ≤220ms，期间只锁硬降，缓存一次旋转/暂存 |
| 低端机掉帧 | 体验下降 | 静态层缓存、粒子上限、低功耗、DPR 封顶 |
| 入口提前暴露 | 半成品被看到 | 配置保持注释；上线前全局搜索 `id:'tetris'` 确认只有一处取消注释 |
| 无奖励导致动力不足 | 留存偏低 | 本地成就 + 历史纪录 + 结算页强反馈；不引入外部经济 |
| 文件过大 | 加载慢 | 零图片、零依赖、复用系统字体；目标 <180KB |
