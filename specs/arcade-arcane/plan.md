## 0. 一句话

月巴在五所学院之间辗转，攒魔力、修咒力、逐阶晋级，最后渡过试炼成为大魔法师。

### 0.1 叙事主线（暗线）

**月巴想成为大魔法师。因为只有走到那一步，它才能去找那样东西。它不说那是什么，也不说为什么。**

- 表象：一只月巴在塔里熬魔力，逐阶晋级。
- 里象：它想变强，但从不说明为了什么。
- 玩家：从开场「你说，找一样东西」与回环「你朝着那一点红，又坐了下去」自行拼合。

写作规则、意象库、频率配比、反例，全部见 `story.md`。
**回环机制由这条暗线提供理由：不是变强了才重来，是没找到才重来。**

写作红线：正文永不出现「番茄」二字；不写闪回、不给原因、不写「原来」。

## 3. 设计目标

| 目标 | 判断标准 |
|---|---|
| 3 秒看懂 | 一眼看到「咒力进度 + 魔力 + 当前学院」，没有二级入口才能玩 |
| 30 秒有反馈 | 施法月巴、咒力涨、环数升、有飘字与音效，不空转 |
| 挂机有获得感 | 离线 8 小时回来有明确结算，不是只涨一个数字 |
| 学院有差异 | 换学院会改变产出、晋级、离线、远征的实际玩法，不只是换皮 |
| 浅而轻 | 浅色纸面配色、低饱和、无霓虹；中端手机 60fps，低端 ≥30fps |
| 不抢主线 | 独立存档键，纯休闲，不污染月巴放置主节奏 |

### 3.1 UI 参考与差异

- 参考 `其他小游戏/snake.html`：顶部 HUD 切角数据条（左侧主色描边）、四角括号、细扫描线、数值 pop 动效、弹层 kicker。
- 参考 `幸存者游戏-番茄幸存者/survivor.html`：HUD 层级、状态条、卡片式面板、弹层开合节奏、`// KICKER //` 标签。
- 差异：两者都是深色科幻。本作做**两套配色**——日间「宣纸」与夜间「烛下书库」，同一套结构令牌切换，不换布局。

## 4. 核心循环

```
在线：看产能 → 施法/切换姿态 → 花魔力升塔 → 咒力满 → 铭环 → 九环 → 晋级
      → 解锁学院/遗迹 → 抽法术/炼药 → 继续挂机
长线：学院学分 → 职称晋升 → 院传法术
      → 法术收集/升级 → 学徒 → 远征 → 试炼 → 封圣（回环）
```

情绪节奏：

- **秒级**：施法反馈、进度条、飘字。
- **分钟级**：环数提升、设施升级、事件二选一。
- **小时级**：大阶晋级、学院职称、远征归来。
- **天级**：新学院、学徒、试炼、封圣。

### 5.2 阶位与环

10 阶 × 9 环 = 90 个节点。

```
魔力/秒   = 2.6^阶 × (1 + 0.10 × (环-1)) × Σ倍率
咒力/秒   = 魔力/秒 × 0.6 × 咒力倍率
本环需求 = 18 × 7.5^阶 × (1 + 0.32 × (环-1))
晋级成本 = 当前咒力/秒 × 300 × (1 + 0.20 × 阶)   魔力
```

- 环内 1→9 只需咒力满，点「铭环」推进，不消耗魔力；**离线自动推进**。
- 9 环满 →「晋级」进入下一阶，消耗魔力并按成功率判定。
- 失败：损失 50% 晋级魔力、咒力回落到本环 35%、专注 −25、杂念 +1。
- 成功率 = 基础 + 设施法术(≤15pp) + 学院(≤8pp) + 晋阶药剂 + 专注修正，封顶 95%、保底 20%。

### 5.3 姿态

| 姿态 | 魔力 | 咒力 | 额外 |
|---|---|---|---|
| 冥想 | −15% | +60% | 专注恢复 +50% |
| 咏唱 | +60% | −15% | 施法收益 +25% |
| 游历 | −30% | −30% | 远征时长 −50%，事件概率 +50% |

切换免费，10 秒冷却。游历的远征加速**在出发时一次性结算**，之后换姿态不回滚。

### 5.4 施法（主动点击）

- 点击月巴：立即获得 `1 秒魔力产能 × 施法倍率`。
- 3 秒内连续点击累计连击，20 连击 +100%，之后衰减；每秒最多计 10 次。
- 表现：压扁回弹、魔力波纹、飘字、连击芯片；**不做全屏闪烁**。

### 5.5 学院（6）

| 学院 | 学派 | 解锁 | 常驻加成 |
|---|---|---|---|
| 翠庭学院 | 自然 | 初始 | 魔力 +30%，专注恢复 +50%，魔药效果 +20% |
| 赤炉结社 | 火焰 | 见习 3 环 | 咒力 +35%，炼金台升级 −15%，施法 +50% |
| 深潭塔 | 水 | 初阶 1 环 | 离线 +15%，魔药时长 +30% |
| 磐石堡 | 土 | 初阶 5 环 | 晋级 +8pp，杂念 −50%，塔升级 −12% |
| 星辉塔 | 星 | 中阶 1 环 | 远征 +30%，事件 +40% |
| 月巴之塔 | 月 | 首次封圣后 | 全产出 +20%，法术效果 +10% |

**职称**：旁听生 / 学员 / 研究员 / 首席，学分 0/300/1000/3000，倍率 1.00/1.15/1.35/1.60。
职称倍率**只放大该学院自己的常驻加成**，不是全局产出。

**转院**：首次免费，之后 `6000 × 3^次数` 魔力，冷却 30 分钟；各院学分与职称独立保存。

### 5.6 法师塔（6 设施）

魔力池 / 冥想垫 / 星镜 / 炼金台 / 书库 / 守护法阵，各 20 级，成本 `80 × 1.55^等级`（磐石堡 −12%）。

> 两处结构性修正（沿用）：星镜 `1.5%/级`（避免离线效率被单一设施吃满）；守护法阵 `0.75pp/级`（0.75×20 正好等于 15pp 封顶）。

### 5.7 法术（24）

- 4 品阶：白 / 蓝 / 紫 / 金，掉落 60 / 28 / 10 / 2%。
- 6 系 × 4 品阶：魔力、咒力、施法、晋级、离线、远征。
- 装备槽 3 个：见习 1 / 初阶 2 / 中阶 3。
- 抽取成本随次数递增（`×(1 + 0.02 × 累计抽取)`），80 抽金阶保底；重复转残页。
- 升级 1→10，消耗「当前等级」张残页；书库等级再放大效果。

### 5.8 魔药（5）

魔力药剂 / 咒力药剂 / 晋阶药剂 / 清心药剂 / 回响药剂。
同类刷新时长，不同类叠加（最多 3 种）；**离线不消耗时长**（存 `remainMs`）。

### 5.9 学徒（4 职）

书房助手 / 同窗 / 采集员 / 护卫，4 个位置随阶位解锁；资质 平庸 / 聪慧 / 天才 / 星选（65/28/6/1%）。
招募需 150 学分 + 30 秒产能，**且职称 ≥ 学员**。

### 5.10 远征（4 处遗迹）

学院后园 / 霜雾峡谷 / 旧纪元遗迹 / 浮空废墟，10min ~ 6h。
同时 1 队，用 `tripEndAt` 判定（不依赖 tick，离线也完成）；收益按阶位差浮动 80%~130%；10% 轻伤。

### 5.11 事件 / 机缘 / 每日

- **事件**：在线 6~10 分钟一次，30 条（24 通用 + 6 学院专属），二选一，有得有失；离线最多缓存 1 条。
- **天降机缘**：40~70 分钟生成，3~5 分钟产能 + 30 学分，不领一直保留。
- **每日任务**：3 条，本地 0 点重置，全完成 60 学分 + 1 瓶随机魔药。

### 5.12 试炼（3）

进入高阶 / 大法师 / 大魔法师 时各一次；弹层 3 道雷，每道 1.2 秒窗口、+12pp；20 秒不操作自动结算；存盘防重抽。

### 5.13 封圣 / 星图

大魔法师 9 环触发。星辉 `floor(总环数^1.5 / 8)`（满 90 环 = 106）。
重置阶位/塔/法术等级/魔药/材料/学徒/学分/职称；保留图鉴、成就、星图、已解锁学院、月巴之塔。

### 5.14 离线

上限 12 小时（项目硬约束）。基础效率 60%，星镜 +1.5%/级（最高 +30%），玄水… 见 `data.md`；总上限 120%。
**离线期间环内自动推进**，到 9 环封顶，不自动晋级。系统时间回拨按 0 处理；距上次保存不足 60 秒不弹窗。

### 5.15 成就与图鉴

成就 30 条；图鉴 5 类（法术 24 / 学院 6 / 遗迹 4 / 魔药 5 / 试炼 3）。图鉴只记录「见过/得到过」，不提供战力。

## 6. 数值与节奏

**全部数值、公式、标定表在 `data.md`。** 本文件只保留设计意图：

- 目标：**10~14 天**通关（每天主动 1~2 小时 + 夜间离线 8 小时）。
- 首轮不点任何养成时约 750 小时；正常养成路径约 90 小时。
- 所有产出为加算百分比；只有职称是乘算（且只作用于本院加成）。
- 成本护栏：设施/法术/炼药 ≤ 当前产能 180 秒；晋级按**咒力产能** 300~840 秒计价。
- 任何公式对 0、负数、NaN、Infinity 做保护。
- 离线不超过 12 小时；单次结算只发一次。
- 阶位总环数封顶 90；封圣后重新计数，星辉按历史最高环数计算。

## 7. 技术方案

### 7.1 文件与结构

单文件 `arcane.html`：

```
<head>  meta / title / 内联 CSS
<body>  HUD / 场景 / 页签 / 面板容器 / 弹层 / 开场
<script>
  I18N     LANGS / TXT / t() / tf() / 语言解析
  G        全局常量（源自 data.md）
  CFG      阶位、学院、职称、设施、法术、魔药、遗迹、事件
  S        运行时状态
  SAVE     load / persist / migrate
  ECON     所有产出、成本、成功率公式
  UI       HUD、场景、面板渲染，缓存 DOM 引用
  PANEL    法师塔 / 法术 / 学院 / 远征 / 手记
  FLOW     铭环、晋级、试炼、封圣、远征结算、事件
  SFX      共享 AudioContext 与音效表
  LOOP     250ms 经济 tick + 4Hz UI + RAF 视觉
</script>
```

- 零外部依赖、零网络请求、无外链图片；月巴用内联 SVG，预留 `artUrl`。
- 不用框架；状态变更后调用对应 `renderX()`，不做全页重绘。

### 7.2 存档

- 键 `yueba-arcane-v1`（命中主存档 `MINI_KEY_RE`，自动进备份包）。
- 必须持久化的时间戳：`ts`、`tripEndAt`、`eventAt`、`jibanAt`、`jibanGot`、`transAt`、`postureAt`、`dissonEndAt`、`buffs[].remainMs`、`draughtArmed`、`trialAt`、`daily.key`。
- 保存时机：每 10 秒、每次晋级/购买/抽取/结算、`pagehide`、`visibilitychange`。
- 体积目标 < 200KB；版本迁移按默认值补字段。

### 7.3 循环与离线

- 经济 tick 固定 250ms，`performance.now()` 累加；后台用 `Date.now()` 补算。
- 可见时 RAF 只驱动视觉；隐藏时停 RAF、停微粒、记录时间。
- 回到前台：`offlineSec = clamp((now - lastTs)/1000, 0, 43200)`。
- 晋级、试炼、封圣必须玩家确认，离线不自动执行。

### 7.4 调试与自测

- `?selftest=1`：公式有限、成本非负、离线封顶、存档往返、成功率一致性、UI 无脏值。
- `?debug=1`：暴露 `window.__cult`，且**跳过开场**（避免挡自动化）。
- 静态验收：全文无 `http://` / `https://` 外链依赖。

### 7.5 百巴箱接入（M7，验收后才做）

1. `GB_GAMES` 增加 `{id:'arcane', codex:'m2_kuji', name:'🌙 月巴奥术', html:'arcane.html', hidden:true}`。
2. `GB_FRAME_THEMES` 加 `'arcane'`；`GB_FRAME_SEED` 加 `arcane:'arcane'`。
3. CSS：`#gbGameOverlay.t-arcane` 功能栏浅纸色 **+ 必须写 `#gbGameOverlay.t-arcane #gbGameFrame{background:#f6f3ea}`**。
4. 载入后 `postMessage({gbTheme:'arcane'}, '*')`。
5. `gbBusy()` 加 `arcane` 分支 + `window.__arcaneState()`，弹层打开时不许热更新。
6. `I18N_UI` 补卡片名四语条目。
7. `yueba-arcane-v1` 已在白名单内，无需改正则。
8. `?selftest=1` / `?debug=1` 只能双击直开触发（父页只透传 `lang=`）。
