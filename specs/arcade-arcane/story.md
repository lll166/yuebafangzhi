# 月巴奥术 · 叙事设定书（story）

> 叙事层唯一源 · 对应 `plan.md` v0.4 / `glossary.md` / `content.md` · 2026-11-02
> 本文件定义「能说什么、不能说什么」，以及所有主线文案的改写口径。

---

## 0. 一句话（内部，不对外）

**月巴想成为大魔法师。因为只有走到那一步，它才能去找那样东西。它不说那是什么，也不说为什么。**

> 设计者知道那样东西是番茄。玩家不需要被告知，只需要被暗示到能自己拼出来。
> 一旦写明，整个游戏就从「一个人的执念」降格成「一个设定」。

---

## 1. 硬规则

### 1.1 可以写

- 红色的**存在**，不写红色的**名字**。
- 空碗、塔下的小镇、旧书上的印子、被布盖住的东西、很眼熟。
- 「有人在问你」这种旁人视角，用来反衬它不答。
- 短句。常体。不抒情，不解释，不回头。

### 1.2 绝对不写

| 禁 | 例 |
|---|---|
| 「番茄」二字 | ~~月巴想找番茄~~ |
| 闪回 / 回忆 | ~~它想起了那天~~ |
| 任何解释动机的句子 | ~~因为番茄被抢走了~~ |
| 「原来」「其实」「后来才知道」 | ~~原来它一直在找的是…~~ |
| 情绪直述 | ~~它很伤心~~ ~~它好想它~~ |
| 给红色加定义 | ~~像一颗番茄那样红~~ |
| 修仙词汇 | 修为、灵气、境界、宗门、洞府、功法、丹药、天劫、飞升 |

### 1.3 唯一例外

**回环（封圣后重开）那一段**可以出现一次「一点红」，且只作为方位，不作为对象。

---

## 2. 三层信息

| 层 | 玩家看到 | 出现位置 |
|---|---|---|
| 表层 | 一只月巴在学徒塔里熬魔力，逐阶晋级 | 全部玩法 UI |
| 中层 | 它想成为大魔法师，但不说为了什么 | 开场、晋级、学院描述、事件 |
| 底层 | 那样东西是番茄 | 永不明写，靠意象与界面主色自行拼合 |

三层之间**不解释、不翻译**。中层给到「一样东西」就停，底层交给玩家。

> 奇幻设定在这里帮了大忙：**「成为大魔法师」本身就是个响亮且合理的目标**。
> 玩家先接受它想变强，再慢慢发现它变强是为了别的。

## 3. 意象库

按强度从弱到强排。同一段落最多用一个。

| 意象 | 用法 | 已用位置 |
|---|---|---|
| 往塔下的方向看了一眼 | 它在看某个方向 | 见习 |
| 形状有点眼熟 | 不提颜色 | 初阶 |
| 抬头往上看 | 目标在上面 | 中阶 |
| 还记得一样东西的颜色 | 颜色不明说 | 高阶 |
| 怕散了就找不到了 | 第一次露出「怕」 | 精英 |
| 少了一小块 | 缺损，不解释 | 大师 |
| 不再往下看 | 放弃了退路 | 大法师 |
| 一点红 | **仅此一次** | 回环 |
| 红霞落在脚边 | 给了，但不是它要的 | 天降机缘 |
| 被布盖着的东西 | 掀开也不写看到了什么 | 事件 q_24 |
| 画了个红的圆 | 孩子的画 | 事件 q_12 |
| 空碗 | 未用，留给图鉴/成就 | — |

## 4. 主线文案

### 4.1 开场（5 句，首启逐条淡入，仅一次）

```
intro_1  学院塔顶的雪化了又落，落了又化。
intro_2  你在书库最底层坐了三年，魔力才第一次在指尖亮起来。
intro_3  有人问你学这个做什么。
intro_4  你说，找一样东西。
intro_5  你没有说是什么。
```

第 4、5 句是全部剧情的枢轴，**不要**在后文重复。

### 4.2 逐阶晋级（9 次 + 回环）

| key | 文案 | 暗线 |
|---|---|---|
| brk_1_d | 指尖那点光稳住了。你抬头，先往塔下的方向看了一眼。 | 方向 |
| brk_2_d | 魔力在掌心结成一枚小小的印。它的形状让你想起点什么，你没细想。 | 形状 |
| brk_3_d | 印里坐着一个很小的你，闭着眼。它睁开眼的第一件事，是抬头往上看。 | 向上 |
| brk_4_d | 那个小小的你看了你一眼，又闭上了。你记不清在塔里待了多久，但还记得一样东西的颜色。 | 颜色 |
| brk_5_d | 身体轻得像一张纸，风一过就要散。你怕散了就找不到了，于是又坐了回去。 | 怕 |
| brk_6_d | 散出去的东西一片片回来，拼成你原来的样子。好像少了一小块。你没说什么。 | 缺 |
| brk_7_d | 塔下的小镇已经小成一个点了。你不再往下看。 | 断退路 |
| brk_8_d | 天上不再落雨，只落雷。你站着，没有躲。 | 决心 |
| brk_9_d | 最后一道雷过去，云散开一条缝。缝的那一边，很远。 | 接近 |
| ascend_d | 你站起来，灰落了满肩。塔下有人在喊你的名字，你已经听不见了。你朝着那一点红，又坐了下去。 | 兑现 + 轮回 |

> `ascend_d` 是全篇唯一出现「红」的地方，也是回环机制存在的理由：
> **它不是变强了才重来，它是没找到才重来。**

### 4.3 三次试炼

```
tb_1_d  云压下来，第一道雷在云里翻了个身。天不让上去，说得很明白。
tb_2_d  三道雷，一道比一道近。手要跟上眼睛。
tb_3_d  最后一道雷落下时，天是白的。你只有三次抬手的机会。
```

## 5. 系统叙事映射

每个系统都要回答：**它和「找」有什么关系？** 答不上来就只留玩法，不写叙事。

| 系统 | 叙事身份 | 一句话 |
|---|---|---|
| 阶位 | 唯一的路 | 它不知道怎么找，只知道往上 |
| 学院 | 打听消息的地方 | 换一所学院，换一批人，听更多说法 |
| 学分 / 职称 | 待得够久，才有人肯说 | 从旁听生熬到首席，才有人把你当回事 |
| 转院 | 走 | 这里问完了，换个地方 |
| 法师塔 | 它给自己搭的窝 | 一个能坐很久的地方 |
| 法术 | 抄来的旧咒式 | 有些书页上有印子，看不出是什么印的 |
| 魔药 | 看得更远一点 | 喝下去，能多撑一会儿 |
| 学徒 | 跟着它找的人 | 它们不知道要找什么，也没问 |
| 远征 | 派出去找 | 每次都带回东西，从不是要的那样 |
| 事件 | 路上的说法 | 三十种说法，没有一种是对的 |
| 试炼 | 学院不许你越级 | 越往上，拦得越狠 |
| 封圣 / 回环 | 还没找到，再来一次 | 它坐下去了 |

### 5.1 六所学院（落点统一为「听了，但没有用」）

| 学院 | 落点 |
|---|---|
| 翠庭学院 | 说法很多，没有一种是你想听的 |
| 赤炉结社 | 他们说你这样升不上去。你听完，又往炉里添了一块炭 |
| 深潭塔 | 这里安静到能听见心里的动静，你还是没听清 |
| 磐石堡 | 他们不问你来做什么，只问你今天坐了几个钟头 |
| 星辉塔 | 听了所有的消息，没有一条有用 |
| 月巴之塔 | 你在这里坐得最久，也没有人问你为什么 |

### 5.2 远征归来

常态：列出收获，不提目标。
低概率（约 20%）追加：

```
tip_disc_none  带回来的东西都在这儿了。
```

### 5.3 天降机缘

「天边落下一缕红霞，正正落在你脚边」**保留**——
它给了红色的东西，但不是它要的那样。这是全篇最漂亮的一次反讽。

## 6. 频率与配比

| 位置 | 出现暗线 | 说明 |
|---|---|---|
| 开场 | 5/5 句 | 唯一高强度区 |
| 晋级 | 9/9 段 | 每段一句，强度递增 |
| 回环 | 1 段 | 唯一一次「红」 |
| 学院描述 | 6/6 段 | 全部落在「没有用」 |
| 事件 | 3/30 条 | q_12、q_24、q_s_bany |
| 机缘 | 1 段 | 红霞（反讽） |
| 提示 | 1 条 | tip_disc_none |
| 成就 / 图鉴 | 0 | 留给后续，可加「空碗」 |

**新增内容先问：它是在加线索，还是在加解释？加解释的一律砍掉。**

## 7. 反例

| 别写 | 为什么 | 改成 |
|---|---|---|
| 月巴想成为大魔法师去拿番茄 | 明写 | 你说，找一样东西。 |
| 它在等一个人回来 | 换了动机 | 你怕散了就找不到了 |
| 番茄被抢走了 | 给原因 | （不给） |
| 它想起那年秋天 | 闪回 | 你记不清在塔里待了多久 |
| 那颗番茄红得像火 | 定义红色 | 还记得一样东西的颜色 |
| 终于找到了 | 闭合 | 你朝着那一点红，又坐了下去 |
