# 月巴奥术 · 术语对照表（glossary）

> 世界观从「修仙」整体替换为「奇幻学院」。数值**一律不变**，只换名与叙事。
> 本表是 `plan.md` / `data.md` / `content.md` / `story.md` / `arcane.html` 的唯一用词标准。

---

## 0. 一句话

**月巴是一名学徒。它要成为大魔法师——只有走到那一步，它才能去找那样东西。**

> 标题：`月巴奥术`（YUEBA ARCANA）· 文件 `arcane.html` · 存档键 `yueba-arcane-v1` · 卡片 id `arcane`
