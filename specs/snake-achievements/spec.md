# 贪吃月巴 · 成就系统（方向稿）

> 目标：给独立小游戏「贪吃月巴」加一层本地成就，短局也能有即时目标，长线有可追的里程碑。
> 本文只定规则与界面方向，确认后再改代码，最后再补英/日/韩三语。
>
> **当前进度**：界面与判定均已落地——顶栏 `🏆 0/15` 入口、成就弹层（分组滚动、隐藏成就 `???`、已完成 ✅）、15 条中文文案、累计统计、实时判定、解锁横幅、存档读写（`mb_snake_ach_v1`）全部可用；除隐藏成就外的 14 条全达成时自动换墨镜 + 兔嘴微笑（ω）。剩余：英/日/韩三语翻译。
> 本套成就**只属于贪吃月巴页面**，不写入主页面 `index.html` 的 `ACHS`，也不被主存档读写。

***

## 1. 现状（可判定数据）

蛇的全部状态都在 [贪吃月巴.html](../../测试页面/贪吃月巴.html) 的闭包里，成就判定所需的量都能现取，不需要新增输入：

| 变量 / 时机                  | 含义               | 用途                    |
| ------------------------ | ---------------- | --------------------- |
| `eaten`                  | 本局吃到番茄数          | 单局分数类成就               |
| `snake.length`           | 当前蛇身长度（初始 3）     | 长蛇成就                  |
| `tickMs`                 | 当前速度，150 → 70    | 可选：速度类成就              |
| `step()` 转向分支            | 队列里的有效转向         | 贴墙转向、单局转向数            |
| `die()`                  | 死亡（目前未区分撞墙 / 自食） | 局数、死亡类成就（需补 `reason`） |
| `spawnFood()` 返回 false   | 256 格占满          | 满屏隐藏成就                |
| `best` + `mb_snake_best` | 历史最高分            | 复用，不重复存               |

需要补的唯一一项：`die(reason)` 增加 `'wall' | 'self'`，用于「自食其果」。

**可复用约定**：存档 key 独立（`mb_snake_ach_v1`），不碰最高分存档；接入主游戏时再迁。

***

## 2. 设计原则

1. **不打扰**：解锁提示是 1.4 秒横幅，不弹窗、不拦输入，连续解锁排队。
2. **短局友好**：15 条里 6 条能在前几局拿到，其余靠累计，不设每日/每周（蛇局重复度高，日活档会变成打卡负担）。
3. **只认事实**：全部用现有变量判定，不做「感觉类」条件；进度数字精确到个位。
4. **失败也算数**：撞墙、自食都会记一局；只有「满屏」算通关。
5. **可迁移**：成就 ID 统一 `sn_` 前缀，结构与主游戏 `ACHS` 对齐，后续接飞行入口时不返工。

| 编号             | 图标 | 名称  | 条件          | 说明    |
| -------------- | -- | --- | ----------- | ----- |
| `sn_eat_100`   | 💯 | 满分！ | 累计吃 100 个番茄 | 中期目标  |
| `sn_games_30`  | 📅 | 常客  | 累计完成 30 局   | 不要求分数 |
| `sn_games_100` | 🏅 | 老手  | 累计完成 100 局  | 长期目标  |

### 隐藏（1 条）

| 编号              | 图标 | 名称   | 条件         |
| --------------- | -- | ---- | ---------- |
| `sn_full_board` | 🧱 | 满屏月巴 | 单局占满 256 格 |

> 合计 15 条。前 6 条（第一口 / 十口 / 初次上路 / 小有成就 / 自食其果 / 贪吃月巴）基本一两局内能见。
> 「贴墙」定义：蛇头到任意一边的距离 ≤ 1 格，即 `min(x, y, 15-x, 15-y) ≤ 1`。
> 「有效转向」定义：被队列消费、且与当前前进方向不同的输入（不含反向无效输入，不含开局默认方向）。

## 4. 判定时机

| 时机                         | 动作                                                |
| -------------------------- | ------------------------------------------------- |
| 吃到番茄（`step()` 内）           | `eatenAll++`、更新 `maxLen`、判定单局分数 / 长蛇 / 累计口数 / 贴墙吃 |
| 有效转向生效                     | `wallTurns++`（贴墙时），本局 `turns++`                   |
| 死亡结算（`die()`）              | `games++`；判定局数类、静默猎手、单局转向、自食；写 `reason`           |
| 满屏（`spawnFood()` 返回 false） | 直接解锁满屏成就，按通关结算                                    |
| 打开成就页                      | 自动暂停，**不计入**手动暂停次数                                |
| 切后台                        | 自动暂停，同样不计入「静默猎手」的暂停统计                             |

- 单局类成就在**达成的瞬间**解锁并弹提示，不等死亡结算（更爽快）。

- 解锁立即写盘；普通统计每 400ms 节流写一次，避免每次吃番茄都落盘。

## 5. 存储结构

```js
// localStorage['mb_snake_ach_v1']
{
  v: 1,
  done: {              // 已解锁：id → 时间戳
    sn_first_bite: 1760000000000
  },
  stat: {
    games: 0,          // 完成局数（撞墙 / 自食 / 满屏都算）
    eatenAll: 0,       // 累计吃番茄
    bestScore: 0,      // 历史单局最高得分
    maxLen: 3,         // 历史最长蛇身
    maxTurns: 0,       // 历史单局最多有效转向
    quietBest: 0,      // 未手动暂停的单局最高分
    wallTurns: 0,      // 贴墙转向累计
    nearWallEats: 0,   // 贴墙吃番茄累计
    selfBites: 0,      // 自食累计
    wins: 0            // 满屏通关次数
  }
}
```

- 读取失败 / 字段缺失 / `v` 不匹配：用默认值补齐，已有 `done` 尽量保留。

- 最高分仍然只存 `mb_snake_best`，成就侧只读不写。

- 本地存储不可用（隐私模式）：降级为内存态，本局有效、刷新即失，不报错。

- 写入策略：解锁立即写盘；普通统计 400ms 节流写一次，避免每次吃番茄 / 转向都落盘。

## 6. 界面方案

**入口**：顶栏在「❚❚ 暂停」左边加 `🏆` 按钮，按钮内显示 `3/15` 小徽章（已实装；未做「新解锁小红点」）。

**成就弹层**（复用现有 `#overlay` 样式，限制在正方形窗口内）：

```
🏆 贪吃月巴 · 成就                  ✕
──────────────────────────────
入门  5/5
🍅 第一口        累计吃 1 个番茄      ✅
🐍 初次上路      完成 1 局            ✅
...
进阶  1/6
🎯 毫厘之间      贴墙吃番茄   3 / 5   [进度条]
?? ?             隐藏成就
──────────────────────────────
合计 6/15
```

- 卡片：图标 + 名称 + 说明 + `当前/目标`；已完成显示 ✅ 已达成（当前不显示达成日期）。

- 隐藏成就未解锁：名称显示 `???`，说明显示「隐藏成就」；解锁后立刻显形。

- 分组标题带小计（入门 / 进阶 / 长线 / 隐藏），不做页签，一次滚动看完，手机上更省操作。

**解锁提示**：窗口顶部滑入一条横幅 `🏆 成就达成 · 十口`，1.4s 后自动消失；同时解锁多条时依次排队（**已实装**，排队逐条播放，不做合并）。

**结算弹层**：在得分下方加一行 `本局达成 2 项 · 总进度 6/15`，点击直接打开成就页（**未实装**，可选）。

**首页弹层**：`开始` 按钮下方加一行小字 `🏆 6/15 · 最近：十口`（**未实装**，可选）。

**低功耗 / 减弱动效**：横幅改为淡入淡出，无滑移。

## 8. 与主游戏的关系

- 现有 [index.html](../../index.html) 的 `ACHS` 是 40 条全局成就（[成就样式与入口](../../index.html#L3301-L3327)），本系统**不复用**其存档，也不会被蛇小游戏改写。

- ID 全部 `sn_` 前缀，后续把「贪吃月巴」挂到飞行旁时，可选择：

  - A. 蛇成就保持独立页，主游戏只做入口跳转（当前实现）。

  - B. 并入全局 `ACHS`，作为「贪吃月巴」分组，解锁同步到主存档（未实现，仅保留结构对齐的可能）。

- 本次实现按 A 方案：独立、零侵入，存档 key 与 `ACHS` 完全分离。

## 9. 验收标准

1. 新档打开：顶栏 `🏆 0/15`，成就页 15 条全部显示（隐藏的 `sn_full_board` 显示为 `???`）。
2. 第一局吃到第一个番茄：立刻弹「第一口」横幅，进度变 1/15，刷新后仍在。
3. 单局 10 分：达标瞬间弹「小有成就」，不需要等死亡。
4. 撞墙死亡：`初次上路` 解锁；咬到自己：`自食其果` 显形并解锁。
5. 打开成就页：游戏自动暂停，关闭后继续，不计入手动暂停（`静默猎手` 不受影响）。
6. 连续解锁 3 条以上：横幅排队，不遮挡操作、不丢帧。
7. 清空 `localStorage`：回到 0/15，最高分同步归零（现有行为）。
8. 手机与电脑均可完整浏览成就页，无横向滚动；`prefers-reduced-motion` 下无滑入动画。
9. 语法检查通过，控制台无报错。
10. 除隐藏外的 14 条全部达成时，月巴自动换上墨镜并出现兔嘴微笑；隐藏成就达成不触发；清掉成就存档后回到普通眼镜。

***

## 10. 奖励外观：墨镜 + 兔嘴微笑（已定）

- **不发番茄/道具**，奖励改为外观解锁：**除隐藏成就外的 14 条全部达成**后，月巴自动戴上「墨镜」，并一直保持。
- 戴墨镜时嘴部从一条小横线变成**兔嘴微笑（ω）**；未解锁时是普通方框眼镜。
- 两种眼镜的镜片都**不透出眼睛**（普通镜片是浅蓝镜面，墨镜镜片深色 + 高光）。
- 判定只读 `mb_snake_ach_v1` 的 `done`：启动与打开成就页时调一次 `refreshLook()`；隐藏成就 `sn_full_board` 不参与计数。
- 存档里没有额外字段，卸载成就数据即回到普通眼镜。

## 11. 已定项（原待确认）

1. **数量**：15 条，不压缩。
2. **隐藏成就**：只保留 `sn_full_board` 一条隐藏；`sn_self_bite` 明示在「进阶」组。
3. **累计口径**：吃到即累计（刷新不丢）；单局类成就达标瞬间解锁，不等死亡结算。
4. **进度显示**：显示精确 `当前/目标`（如 `3 / 5`）。
5. **每日 / 每周档**：不做。
