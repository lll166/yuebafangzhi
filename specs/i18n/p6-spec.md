### 1.1 数据结构的真实情况（与 `I18N_LETTER` 注释不一致）

代码注释写「`I18N_LETTER`：t=正文 w=落款 m=留言」，但 `TV_LETTERS` 每条实际只有三个字段：`d`（氛围背景 class）、`e`（火漆 emoji）、`txt`（正文）。

- **落款**：不是数据字段，由 `tvOpenLetter()` 用 `'—— '+nm` 自动拼出，`nm` 取自已本地化的月巴名 → **无需翻译**。
- **留言**：`tvOpenNoteHTML()` / `tvLetterEnv()` 渲染的是玩家自己写的 or 程序生成的 `mood` 字符串（存档里 `cardMoods[].m`）→ **属玩家内容，不译**。
- 因此 P6 的翻译对象**只有 216 条 `txt` 正文**。

### 1.2 需要保留的符号

- `{name}` 占位符：仅 1 封带（`A1`），渲染时被替换成月巴名。**译文必须原样保留 `{name}`**。
- 48 封正文内含「」/『』/“” 引号（对白或文书引用）。按 P4 定稿：**en/ko 用 `"…"`，ja 用「」**；嵌套时 en/ko 用 `'…'`，ja 用『』。
- 中文破折号「——」在译文里按各语言习惯处理（en 用 em dash `—`，ja 用 `——`，ko 用 `——`）。
- emoji、`▊▊▊▊`（G13 的人为涂黑）、数字均原样保留。

### 1.3 顺带补的 1 条漏译（P2 遗留）

`tvLetterEnv()`（line 9799）与 `tvOpenNoteHTML()`（line 9802）在无留言时渲染字面量 `（无留言）`，四语下均显示中文。本批补 1 条 `I18N_UI`：
`'（无留言）':{en:'(no note)',ja:'（メモなし）',ko:'(메모 없음)'}`。

## 二、键名方案（沿用 P0 已建的空表）

`I18N_LETTER` 已存在且为空（line 5488），键 = **信件代号**（`A1`…`U13`），字段 `t`：

```js
const I18N_LETTER={
  A1:{t:{en:'…',ja:'…',ko:'…'}},
  A2:{t:{en:'…',ja:'…',ko:'…'}},
};
```

取值助手（放在 `$tn()` 附近）：

```js
/* 信件正文：键=信件代号，字段 t；中文档直返 fallback */
function $tl(c, fb){ return $tn(I18N_LETTER, c, 't', fb); }
```

## 三、施工方式

### 3.1 渲染点（仅 2 处，改动极小）

| 位置 | 现状 | 改法 |
|---|---|---|
| `tvOpenLetter()` line 9857 | `const txt=L.txt.split('{name}').join(nm)` | `const txt=$tl(c,L.txt).split('{name}').join(nm)` |
| `tvJournalCardChip()` line 9989 | 摘要 + `title` 均用 `L.txt` | 两处改 `$tl(id,L.txt)` |

### 3.2 来信弹窗重绘（需小重构，避免副作用）

`tvOpenLetter()` 现在既做「拆信」副作用（从 inbox 移除、`save()`、播音效），又拼 HTML。若直接把 `()=>tvOpenLetter(c)` 作为 `openModal` 的 rebuild，切语言时会**重复执行拆信逻辑**——且此时 `inbox.indexOf(c)` 已是 `-1`，`splice(-1,1)` 会误删**最后一封**未拆信。

因此拆成两个函数：

```js
function tvOpenLetter(c){ …原有副作用…; tvShowLetter(c); }
function tvShowLetter(c){ …只拼 HTML…; openModal('💌 来信', h, ()=>tvShowLetter(c)); }
```

`_afterClose`（关闭后回到信箱 / 旅行图鉴）保持在 `tvShowLetter` 内设置。

### 3.3 另两处补 rebuild

- `tvOpenMail()` line 9865：`openModal('📮 信箱 · 来信', tvMailHTML())` → 追加 `, ()=>tvOpenMail()`（信箱卡片上的留言摘要需随语言刷新）
- `tvOpenJournal()` line 10014：`openModal('📔 旅行笔记', tvJournalHTML())` → 追加 `, ()=>tvOpenJournal()`（信件摘要 chip 需随语言刷新）

`tvOpenBook()` 已有 rebuild（line 9798 传了 `tvOpenBook`），旅行图鉴里的信件卡片自动刷新。

## 四、翻译口径

- **语体**：信件是叙事抒情文本 → **日文常体（だ・である）、韩文한다체**（与 P4 简介一致；不使用敬体/해요체）。
- **第一人称**：原文「我」指月巴 → en 用 `I`，ja 用 `ボク`（「我们」→ `ボクたち`），ko 用 `나는/내가`（依助词）。番茄、NPC、古参生物等非月巴说话时的「我」保持 `私`/`私たち`（如 B15、M3、Q6、R6、T3、U5/U7/U9/U10/U11、N9、H10、F12、H5、T12、U4、P13）。
- **番茄/月巴**：照术语表 — Banny / バニー / 버니；Tomato / トマト / 토마토。**不要把「番茄」音译成 tomato 之外的词**。
- **专名一致**：地图名、特产名若在正文出现，须与 P3 译文一致（如 世外桃源 = Fairy Hideaway / 桃源郷 / 무릉도원；失落王庭 = Lost Court 系列以 P3 为准；雪山 = Snowy Peak）。
- **文学性**：允许逐句意译，但**不删信息、不加情节**；拟声词（沙沙/唰/噗噗）用各语言惯用拟声（en 用 `rustle`/`whoosh`/`pff`，ja 用「さらさら」「シュッ」「プッ」，ko 用 `사각사각`/`쓱`/`푸푸`）。
- **语气统一**：同一地图内保持同一叙事声音（A/H/M 轻松童趣、G 档案腔、Q/R 悬疑紧张、S/T/U 冒险抒情）。

1. **静态解析**：逐 `<script>` `new Function` → `scripts 1 bad 0`。
