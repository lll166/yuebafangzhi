> 版本 **v1.0**（2026-10-30）｜适用范围：本项目**全部** HTML 游戏（主游戏 `index.html` + 各小游戏）
> 本表是**唯一权威口径**：新译文一律照本表；与代码里既有译文冲突时，**以本表为准**，并在 §10 登记待改项。

## 一、十条铁律（先看这里）

| # | 规则 |
|---|---|
| 1 | **月巴 = `Banny` / `バニー` / `버니`**。英文首字母大写（句中同理）；仅代码标识符、文件名、URL 用小写 `banny`。 |
| 2 | **番茄 = `Tomato` / `トマト` / `토마토`**。旅行货币，必须与「金币」区分。 |
| 3 | **日文一人称：月巴=`ボク`（片假名），番茄=`オレ`（片假名）**；月巴称番茄 **`きみ`**（平假名）。 |
| 4 | 语体：日文 **叙事=常体（だ・である）/ UI=敬体（です・ます）**；韩文 **叙事=한다체 / UI=해요체**。 |
| 5 | 专名**造词不音译**：`花巴→Flowerbanny`，不写 `Hua Ba`、不写 `Bunny`。 |
| 6 | 日文**不留空格**（`バニー食堂`）；韩文按「独立名词短语空格 / 后缀黏着不空格」判断（§6）。 |
| 7 | 引号：英/韩 `"…"`，日 `「…」`，嵌套日 `『…』`、英 `'…'`；省略号统一单字符 `…`。 |
| 8 | 数字保留阿拉伯数字与千分位（`1,000,000`）；`R1~R6` 四语**原样不译**。 |
| 9 | **禁用译名**：`Bunny`、`Tomato Clock`、`Yueba`、`Moon Banny`（详见 §9）。 |
| 10 | 中文原文是键；缺译文**原样回退中文**，绝不出现空白 / `undefined` / 半句混排。 |

## 二、语言档位与工程机制

| 项 | 决定 |
|---|---|
| 语言档位 | `zh` 中文 / `en` English / `ja` 日本語 / `ko` 한국어（固定四档，不加语种） |
| 判定顺序 | URL `?lang=` → 主存档 `S.lang` → 浏览器语言（ja/ko/en，其余 zh） |
| 主游戏取值 | `$t(中文原文)` 界面短文案｜`$tn(表, 条目id, 字段, 中文兜底)` 内容条目｜`$tf(key,{…})` 带占位符｜`$tm/$sp/$fi/$tl` 语义化封装 |
| 小游戏取值 | 各页自建 `I18N` / `TXT` 字典 + 本地 `t(key, vars)`；语言取自父页 `postMessage` 或主存档 `lang` |
| 静态文案 | 元素加 `data-i18n` / `data-i18n-title` / `data-i18n-placeholder` |
| 切语言刷新 | 主游戏走 `_i18nRepaint` + `applyI18n()`；子页重绘自身 DOM |
| 禁止 | 不把字号写死成中文宽度；不把文字烘进背景图；不新增第五种语言键位 |

> 函数名固定 `$t/$tn`，**不要**改成 `T()/tr()` —— 斗月巴牌型代码有局部变量 `T`、`tr`，会遮蔽。

## 四、月巴命名法

### 4.1 三条构词规则

| 规则 | 说明 |
|---|---|
| **A. `X月巴` → `X Banny` / `Xバニー` / `X버니`** | `小月巴→Little Banny`；`尴尬月巴→Awkward Banny`；`午夜月巴→Midnight Banny`。带「小」的昵称统一 `Little` / `ちび` / `꼬마`（`小巴软糖→Little Gummy Banny / ちびグミバニー / 꼬마구미버니`） |
| **B. `X巴`（单字根）→ `Xbanny` / `Xバニー` / `X버니`** | `花巴→Flowerbanny`；`心巴→Heartbanny`；`史莱姆巴→Slime Banny`（多为可读性可加分词） |
| **C. 谐音梗/专有梗：保梗不拆** | `酒巴→Bar Banny`、`抛瓦月巴→Power Banny`、`大巴车→Bus Banny`、`巴总→Boss Banny` |

> 核心原则：**不音译、不丢字根、不写成 Bunny**。宁可造词，也不要译成拼音。

## 五、人称与语气

### 5.1 人称对照

| 说话者 / 对象 | 中文 | English | 日本語 | 한국어 |
|---|---|---|---|---|
| **月巴（本人）** | 我 | I | **ボク**（复数 `ボクたち`） | 나（复数 우리） |
| **番茄（本人）** | 我 | I | **オレ**（复数 `オレたち`） | 나 |
| **月巴 → 番茄** | 你 | you | **きみ**（平假名） | 너 |
| 月巴 → 玩家 | 你 | you | **君**（汉字，**已定稿不改**：信件、蛋的离线台词等直接对玩家说的话） | 너 |
| 番茄 → 月巴 | 你 | you | **君**（汉字，已定稿） | 너 |
| NPC / 古参生物 / 旁白 | 我 | I | 私 / 私たち | 나 / 저 |
| 系统提示（无人称） | — | — | 敬体直述（`〜しました`） | 해요체直述 |

> **三条角色标记，任何语言都不许丢：**
> ① 月巴自称一律 **片假名「ボク」** —— 片假名是为了幼感与可爱，**不是错字，不要「纠正」成汉字「僕」**；
> 　**没有角色例外**：反派、凶狠、老成的月巴也一律 `ボク`，不用 `俺`/`僕`（巴巴博弈的「俺」已定改为 `ボク`）；
> ② 番茄自称一律 **片假名「オレ」** —— 略带粗糙的大哥腔，**不用「私」、不用「僕」**，和月巴的「ボク」形成对照；
> ③ 月巴叫番茄一律 **平假名「きみ」** —— 比汉字「君」更软、更亲近，也不用「あなた」。
> 　**片假名只用于一人称**（`ボク`/`オレ` 是角色招牌）；二人称写成片假名「キミ」会带强势、喊话语感，和月巴撒娇/温柔的台词打架，**故固定平假名，已确认不改**。
>
> 现状（2026-10-30 全部落地）：`ボク` 系 **223 处**（其中 `ボクたち` 39）、`オレ` 系 **21 处**（其中 `オレたち` 4）、`きみ` **32 处**。
> 仍保留：`君` 19 处（番茄→月巴 11、系统→玩家 2、名词「君王」2、其余为中文串）、`あなた` 38 处（对玩家/UI/NPC）、`私` 13 处（`私たち` 7 + NPC 单数 3 + 中文注释 3）。

### 5.2 复数与互称（已定稿）

| 项 | 定稿 | 说明 |
|---|---|---|
| 月巴复数 | `ボクたち` | 一人称片假名，复数同源 |
| 番茄复数 | `オレたち` | 同上 |
| 番茄 → 月巴 | `君`（汉字） | 与「月巴→玩家」同一档；月巴→番茄才用平假名 `きみ` |
| NPC / 旁白复数 | `私たち` | 不随角色改片假名 |

> 一句话记法：**片假名只给「月巴」和「番茄」两个角色的自称（含复数）；凡是对别人说话的第二人称或 NPC 的自称，一律汉字/平假名常态写法。**
>
> **判定看「对谁说」，不看「在哪个界面」**：同一封信里月巴对番茄说话，仍用 `きみ`；对玩家说话才用 `君`。

### 5.2 语体对照（按文本类型，不按页面）

| 文本类型 | 中文 | English | 日本語 | 한국어 |
|---|---|---|---|---|
| 信件正文、月巴简介、事件文案 | 叙述体 | 一般过去/现在时，文学化 | **常体**（だ・である） | **한다체** |
| 按钮、标签、toast、弹窗标题 | 简短动宾 | 首字母大写短词（`Save`、`Claim`） | **敬体**（です・ます） | **해요체** |
| 数值/单位/表头 | 名词 | 全大写可（`BEST`、`TIME`） | 名词或片假名 | 名词 |
| 角色台词 | 保口语 | 口语缩写（`I'm`、`don't`） | 常体 + 口语终助词 | 반말 |

> 反例：UI 按钮写成「保存するのだ」= 语体错；信件写成「〜です」= 语体错。

## 六、标点、空格、数字、日期

| 项 | 规则 | 正确示例 | 错误示例 |
|---|---|---|---|
| 英文引号 | 双引号 `"…"`，嵌套单引号 `'…'` | `"Here — this one is mine."` | `「Here…」` |
| 日文引号 | `「…」`，嵌套 `『…』` | `「ほら、これはボクのトマト。」` | `"ほら…"` |
| 韩文引号 | 双引号 `"…"` | `"자, 이건 내 토마토야."` | `「…」` |
| 省略号 | 统一单字符 `…` | `I don't know…` | `...` |
| 破折号 | 英 `—`，中日韩 `——` 或 `—`（同一文本内保持一致） | `Here — this one` | `Here - this one` |
| 日文空格 | **词间不留空格** | `バニー食堂`、`テトリスバニー` | `バニー 食堂`、`月バニー` |
| 韩文空格 | 独立名词短语加空格；后缀黏着不加 | `버니 식당`、`버니 박스` / `테트리스버니`、`버니산` | `버니식당`、`테트리스 버니` |
| 标题牌序 | 日/韩可按本地语序重排，英中保持「Banny + 玩法」 | ja `五目|バニー`、ko `오목|버니`、en `BANNY|GOMOKU` | ja `バニー|五目` |
| 数字 | 阿拉伯数字 + 千分位，不本地化单位 | `1,000,000`、`R6`、`×3` | `100万`、`백만` |
| 日期 | en `Oct 20` / ja `10月20日` / ko `10월 20일` / zh `10月20日` | — | `20/10` |
| 时长 | en `12.34s`、`1h20m` / ja `12.34秒`、`1時間20分` / ko `12.34초`、`1시간 20분` | — | `12.34 sec` |
| 金币/番茄计数 | 数字 + 空格 + emoji | `+120 🪙`、`×3 🍅` | `+120🪙`（连写易读性差） |

> 番茄语气三条底线：**自称オレ / 护短、直来直去 / 对月巴不叫「あなた」**——是有点糙的大哥腔。

### 7.1 月巴的基调：大部分可爱，严肃场合才收起来（作者定稿）

**默认语气是可爱**：日常事件、庭院互动、对番茄撒娇、收获与旅行 —— 一律走可爱路线。只有**严肃讨论事情**的时候（讲约定、警告、告别、谈条件）才切换成认真的语气，可爱语尾要去掉。

| 场合 | 中文 | 日本語 | 特征 |
|---|---|---|---|
| 日常（默认） | 喏，这是属于我的番茄。 | ほら、これはボクのトマト。 | 短句 + 语尾「ね／よ／〜だよ」，多用平假名 |
| 严肃（例外） | 你先走一步吧，我不着急。 | 先にどうぞ、ボクは急がない。 | 去掉撒娇语尾，平整的常体，但仍保持短句 |

> 判断标准：这句话是不是在「讲道理、做约定、给警告」。是 → 收起可爱；不是 → 可爱优先。

**语法要求（可爱 ≠ 乱写语法，日文尤其注意）：**

1. 可爱靠**词汇与语尾**实现（`ね`、`よ`、`〜ちゃう`、`〜の`），**不靠破坏语法**：助词不能错配、时态不能混、句子必须完整；
2. 禁止机翻腔：不写「〜することは〜です」式直译、不逐字对齐中文语序、不堆砌汉字词；
3. 严肃场合同理：认真 ≠ 生硬，仍然用自然的常体，只是收敛语尾；
4. 拿不准时读出声：读起来不像一个小孩/小动物会说的句子，就重写。

## 九、禁用与易错清单

### 9.1 禁用译名

| 禁用 | 正确 | 原因 |
|---|---|---|
| `Bunny` / `Bunnies` | `Banny` / `Bannies` | 与 IP 名冲突，且丢掉「月巴」音感 |
| `Tomato Clock` | `Pomodoro` | 番茄钟是工具名，不是「番茄做的钟」 |
| `Yueba` / `Moonba` / `Moon Banny` | `Banny` | 音译/直译都被否 |
| `バニーさん` / `버니씨` | `バニー` / `버니` | 不加敬称后缀 |
| `月バニー` | `バニー` | 「月」是中文残留，日文不用 |
| `僕`（汉字） | `ボク`（片假名） | 月巴自称固定片假名，汉字会丢幼感 |
| 月巴用 `俺` | `ボク` | 所有月巴无角色例外（含反派/老成角色） |
| 番茄用 `私` | `オレ` | 番茄固定片假名大哥腔，与月巴的 `ボク` 对照 |
| 番茄用 `僕` | `オレ` | 同上，`僕` 是月巴的专属 |
| `君`（汉字） | `きみ`（平假名） | 月巴对番茄固定平假名 |
| `あなた` 用于番茄 | `きみ` | 月巴对番茄不用「あなた」 |
| `バ块` / `달바니` | `バニー` / `버니` | 同上，混字/借译 |
| 中文标点（`，。「」`）出现在 en/ko | 对应语言标点 | — |

### 9.2 易错点

1. **API 名/存档键不译**：特产 `sp_<中文名>`、信件代号 `A1`、皮肤 id、`like` 数组都保持中文/英文原键。
2. **不要翻 emoji**：`🍅 🐰 ✨ 🃏` 原样保留；emoji 位置与数量与中文一致。
3. **占位符原样**：`{n} {name} {a}/{b} {time}` 不翻译、不改顺序、不加空格。
4. **HTML 标签进译文**：`<b>`、`<span>`、`<br>` 必须原样保留（翻译长句时最容易漏）。
5. **日文汉字用日文写法**：`図鑑`（非 图鉴）、`実績`（非 实绩）、`特産品`（非 特产）。
6. **韩文不要汉字**：`도감`（非 圖鑑）、`업적`（非 成就）。
7. **英文不缩写成单字母**：`Banny` 不写 `B`；UI 大写仅限表头（`BEST`、`TIME`）。
8. **同一概念一译到底**：改了术语表就全局替换，不允许同一界面两种说法。
