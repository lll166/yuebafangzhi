# P1 文案清单 · 界面骨架静态文案（待你批注）

本批范围：**顶栏 / 状态栏 / 底部 dock / 场地工具条 / 旅行页 / 飞行页 / 斗月巴页骨架 / 通用弹层**。
下方每条按「中文 → English → 日本語 → 한국어」给出拟译。**确认后再落进代码 `I18N_UI`**。

## 怎么反馈

- 想改某条 → 直接在对应格子旁写「改：xxx」，或按区块说「B 区 图鉴 改 Codex→Collection」。
- 有疑问的条目我标了 ⚠️，列在文末，等你拍板。
- 表里没列的（季节 / 天气 / 时段 / 稀有度提示等动态值）属 P2 批次，见文末「相邻但不在本批」。

## 已套用的统一约定（来自 `I18N_GLOSSARY` + 风格约定）

- 月巴 → **Banny** / **バニー** / **버니**
- UI 类文案：日文敬体（です・ます）、韩文 해요체；按钮名多用名词短语，不加敬体
- 专名一律照术语表，不另起译法；数字保留阿拉伯数字与千分位
