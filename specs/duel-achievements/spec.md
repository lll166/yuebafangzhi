# 斗月巴 · 成就系统（方向稿）

> 目标：给「🃏 斗月巴」增加一层成就，分**每日 / 每周 / 总成就**三档，让每天来打一两把都有短期目标，长期也有可追的里程碑。
> 本文只定方向与规则，确认后再改代码。

---

## 1. 现状（可用的数据基础）

斗月巴每局结束都会写入 `ddRecords`（[index.html](../../index.html) 的 `ddPushRecord`），单条记录已经包含判定成就所需的全部字段：

| 字段 | 含义 | 用途 |
|---|---|---|
| `t` | 对局时间戳 | 按日 / 周筛选 |
| `win` / `quit` | 是否获胜 / 是否认输 | 胜负类条件 |
| `diff` | `easy` / `normal` / `hard` | 难度类条件 |
| `role` | `landlord` 地主 / `farmer` 农民 | 身份类条件 |
| `stake` / `net` | 押注 / 净番茄 | 收益类条件 |
| `cheat` | 是否撞上出千月巴 | 特殊条件 |
| `plays` / `myLeft` / `foeLeft` | 出牌手数、双方剩牌 | 评级（`ddGrade`） |

已有可复用的东西：

- `ddGrade(r)` → S+ / S / A / B / C / D 评级，战绩页已有评级分布统计
- `dayKey(ts)` → 北京时间的日期字符串（`2026-10-21`），全游戏统一用它判断「今天」
- `tvTomato(n)` → 增减旅行番茄并刷新顶栏，奖励直接走它
- 现有 40 项成就（`ACHS`）是**一次性**的，不建议把日/周成就混进去，另开一套

**关键约束**：`ddRecords` 最多保留 1000 条，长期会截断。所以：
- 日 / 周条件 → 直接从最近记录里筛当天 / 当周，1000 条足够
- 总成就 → 在结算时累加独立计数器，不依赖记录条数

## 2. 三档规则

| 档位 | 条数 | 单条奖励 | 刷新 | 说明 |
|---|---|---|---|---|
| 每日 | 5 条 | 5 🍅 | 每天 0 点（北京时间） | 当天没完成不补，不累积 |
| 每周 | 7 条 | 10 🍅 | 每周一 0 点 | 同上，难度偏高 |
| 总成就 | 18 条 | 50 🍅 | 不刷新 | 达成一次即永久保留 |

- 奖励**达成即自动发放**，不需要手动领取；发奖时弹一行 `+5 🍅` 提示。
- 日 / 周成就每天 / 每周各只能拿一次，完成后打勾并置灰。
- 「随便玩玩（不押注）」的局**计入**成就（鼓励打牌，不逼押注）。
- **认输不计入「打完一局」**，也不计胜场；只用于战绩记录。
- 日期基准完全跟随现有 `dayKey`（北京时间），不做时区换算。

## 3. 每日成就（5 条，每条 5 🍅）

| 编号 | 图标 | 名称 | 条件 | 说明 |
|---|---|---|---|---|
| D1 | 🃏 | 今日开局 | 今天正常打完 1 局（非认输） | 最基础的日活钩子 |
| D2 | 👑 | 今日硬仗 | 今天在「困难（背头月巴）」赢 1 局 | 原来的「今日首胜」升级版 |
| D3 | 🎯 | 今日好局 | 今天有 1 局评级达到 A 或以上 | 用 `ddGrade`，押注/不押注都算 |
| D4 | 🔥 | 今日三胜 | 今天累计赢 3 局 | 要求当天多打几把 |
| D5 | ⭐ | 今日神局 | 今天打出 1 次 S+ 评级 | 当天最难的一条，看水平也看牌运 |

> 每日 5 条全清共 25 🍅。前三条保底、后两条拉难度：D2 逼你碰困难，D4 逼局数，D5 逼质量。
> 如果觉得 5 条太满，可把 D4 降到「赢 2 局」或直接砍掉 D4。

## 4. 每周成就（7 条，每条 10 🍅）

方向：一周至少要打十来局、且要有点水平才可能全清，不再是「打一把就顺手拿了」。

| 编号 | 图标 | 名称 | 条件 |
|---|---|---|---|
| W1 | 🏅 | 本周十胜 | 本周累计赢 10 局 |
| W2 | 🔥 | 本周五连胜 | 本周内出现过一次 5 连胜（出千月巴那局获胜同样计入） |
| W3 | 👑 | 本周硬仗 | 在「困难（背头月巴）」本周赢 5 局 |
| W4 | ⭐ | 本周神局 | 本周打出 1 次 S+ 评级 |
| W5 | 🌾 | 农民翻身 | 本周以农民身份赢 5 局 |
| W6 | 💰 | 本周大赚 | 本周斗月巴净赚合计 ≥ 2,000 🍅 |
| W7 | 📅 | 本周全勤 | 本周有 5 天各至少正常打完 1 局（认输不算） |

> 说明：
> - 全部按「本周」筛选 `ddRecords` 计算，周一 0 点清零。
> - W2 的连胜按记录时间顺序统计，遇败局或认输即断；出千月巴的局获胜同样计入（与现有 `ddStreak` 口径一致）。
> - W7 用记录的 `dayKey` 去重计数，鼓励每天来打一把，而不是周末突击。
> - 全部完成共 70 🍅，约等于一局中等难度的净收益；单条 10 🍅 只是象征性奖励，主要还是长期目标感。

## 6. 存储结构

在存档里新增一个独立字段，与 `collection`、`ach` 同级，旧存档自动兼容：

```js
ddAch:{
  day:'2026-10-21',            // 当前统计日（dayKey）
  dayDone:{d1:1, d2:1},        // 当日已完成
  week:'2026-W43',             // 当前统计周（周一起算）
  weekDone:{},                 // 本周已完成
  totalDone:{t1:1},            // 总成就已完成
  total:{
    games:0, wins:0, net:0,    // 局数 / 胜场 / 净番茄
    hardWins:0,                // 困难胜场
    diffWins:{easy:0,normal:0,hard:0}, // 分难度胜场（T8 / T18）
    splus:0, cheatWins:0,      // S+ 次数 / 赢下出千月巴次数
    landlordWins:0, farmerWins:0, // 分身份胜场（T16 / T17）
    maxStreak:0                // 历史最高连胜（T15）
  }
}
```

- `total` 在 `ddPushRecord` 之后累加，保证即使 `ddRecords` 被截断，总成就进度也不会倒退。
- 累加口径：`games` / `wins` / `net` / `hardWins` / `diffWins` / `landlordWins` / `farmerWins` / `cheatWins` 取自本局记录；`splus` 用 `ddGrade(r).g==='S+'` 判定；`maxStreak` 只在赢局时 +1、败局或认输清零，并与旧值取最大。
- 读取时发现 `day` / `week` 与当前不一致 → 清空 `dayDone` / `weekDone` 并写入新 key，不弹提示。
- 日 / 周判定只读记录，不另存中间计数，避免两份数据打架。

## 7. 界面方案

**入口**：斗月巴顶栏，在 `📜 战绩` 左边加一个 `🏅` 按钮，打开成就弹窗。

**弹窗结构**（复用现有 `openModal` + 成就卡片样式）：

```
🏅 斗月巴成就
[今日 2/5] [本周 0/7] [总成就 1/18]     ← 三个页签，默认停在「今日」
┌─────────────────────────────┐
│ 🃏 今日开局        +5🍅  ✅  │
│ ✌️ 今日首胜        +5🍅  ✅  │
│ 🎯 今日好局        +5🍅  0/1 │  ← 进度条
└─────────────────────────────┘
页脚：每日 0 点刷新 · 每周一 0 点刷新 · 达成即自动发放
```

- 已完成：金框 + ✅ + 达成时间（日/周显示「今日/本周已达成」即可）
- 未完成：显示进度条（`当前 / 目标`），与总成就卡片一致
- 顶栏 `🏅` 带小红点：当天 / 本周有未完成的新成就时点亮，打开弹窗后熄灭
- 结算结果页底部加一行小字：`今日成就 2/3 · 本周 0/3`，点击直接进成就弹窗

## 8. 触发时机

| 时机 | 动作 |
|---|---|
| 一局结束（`ddSettle` → `ddPushRecord` 之后） | 累加 `total` 计数 → 判定三档成就 → 发奖 → 弹 `+🍅` 提示 |
| `tick`（约 1.5 秒节流，与现有 `checkAch` 同频） | 比对 `day` / `week` key，跨天 / 跨周则重置；顺便补判一次（防止读档后停在旧状态） |
| 读档 | 静默结算一次（只补发已满足但未记录的成就，不弹提示） |
