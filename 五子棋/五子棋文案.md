# 月巴五子棋 · 文案修改稿

> 直接改表格里的文字，改完发我，我一次性写进 `gomoku.html` 的 `TXT`（zh / en / ja / ko 四套）并接上随机抽取。

## 修改规则（很重要）

1. **四列都要改**：中文、英文、日文、韩文各一列，漏填的语言会退回中文。
2. **key 列（第一列）不要改**：它是代码里的索引。要加台词就整行往下加，key 顺延（如 `greet9`、`sayMove9`）。
3. **台词里不要出现引号**：`"` `“` `”` `'` 都不要。台词外层会自动加中文引号。
   英文的撇号请用弯引号 `’`（如 `Let’s`），直单引号 `'` 会让代码报错。
4. **只有** **`rosterNote`** **可以用** **`{n}`**，其它行不要出现花括号。
5. **长度**：对手条是单行显示、超出用省略号。台词类中文建议 ≤ 14 字（英文 ≤ 32 字符，日文 ≤ 16 字，韩文 ≤ 16 字）；其它界面文字可略长。
6. 标点、空格、换行都按你想要的来；表格里不能换行，需要分段就拆成两行。
