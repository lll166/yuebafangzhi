## 一、结论先行

| 项 | 决定 |
|---|---|
| 游戏形态 | 单文件 `gomoku.html`（位于 `五子棋/` 下），零依赖、可离线双击打开 |
| 打开方式 | 百巴箱 → `gbFrameOpen()` → `#gbGameFrame` 内嵌 iframe（与蛇月巴 / 俄罗斯巴块同款） |
| 入口 | `GB_GAMES` 追加一张卡，带 `hidden:true`；`gbRender()` 已会跳过隐藏项，**验收后删掉该标记即上线** |
| 玩法 | 15×15 标准五子棋，玩家黑子先手，月巴白子后手；五连（含长连）即胜，棋盘满为和局 |
| 对手 | 从父页下发的**已开启图鉴月巴**名册中随机抽 1 只；标题页可「换一只」；对局中固定 |
| 规则 | 自由五子棋（无禁手、无三三/四四判负），降低理解成本，AI 也不会利用禁手 |
| 难度 | 简单 / 普通 / 困难 三档，默认普通；只影响 AI 搜索深度、候选宽度与随机扰动 |
| 悔棋 | 每局最多 3 次，撤销「月巴上一步 + 玩家上一步」；月巴落子前可撤 |
| 渲染 | Canvas 2D 低分辨率像素棋盘 + DOM HUD；月巴头像走 DOM（不画进 Canvas，避开跨域污染） |
| 奖励 | **首版不发金币/番茄、不写主存档**（与螺旋跳、俄罗斯巴块一致）；预留 `yueba-gomoku-result` 消息分支 |
| 主存档 | **只读**（名册、`muted`、`lowPower`、`lang`），绝不写入 |
| 语言 | 页内 zh / en / ja / ko 字典；`?lang=` → 主存档 → 浏览器 |
| 性能 | 无 RAF 常驻循环（只在状态变化时重绘）；AI 思考异步化；无 `backdrop-filter`、无全屏模糊；后台自动暂停 |

**不做的事**：不做联机对战、不做排位/排行榜、不做关卡模式、不做皮肤系统、不做每日残局、不做 19 路棋盘、不做禁手判负、不新增图鉴月巴、不新增任何图片资源。

## 三、玩法设计

### 3.1 核心循环

```
百巴箱点「月巴五子棋」
  → 标题页：随机抽 1 只月巴作为对手（头像 + 名字 + 一句打招呼）
      → [开始对局] [换一只] [难度：简单/普通/困难]
  → 对局：玩家执黑落子 → 月巴「思考中」→ 月巴执白落子 → 循环
      → 五连 → 结算（胜 / 负 / 和）
      → [再战一局]（同一只月巴）/ [换一只月巴] / [返回标题]
  → 关闭由百巴箱外层 ✕ 完成
```

### 3.2 基础规则

| 项 | 规则 |
|---|---|
| 棋盘 | 15×15 交叉点，共 225 个落子点 |
| 先手 | 玩家执黑，永久先手（不掷硬币，避免随机先手带来的体验波动） |
| 胜利 | 横 / 竖 / 撇 / 捺 任一方向连续 ≥5 颗同色棋子 |
| 和局 | 225 格填满仍无五连 |
| 禁手 | 无。自由五子棋，长连（6 颗以上）同样算胜 |
| 落子 | 只能落在空交叉点；落在已有棋子处播放「无效」反馈，不消耗回合 |
| 悔棋 | 每局 3 次；撤回到「玩家上一次落子前」，同时撤掉月巴的回应；月巴思考中可直接撤回并取消思考 |
| 认输 | 结算前的「认输」按钮，计入负场 |
| 暂停 | 顶栏 ⏸ / `Esc`；切后台自动暂停；AI 思考计时一并冻结 |

### 3.3 难度曲线（AI 三档）

| 档位 | 候选点 | 搜索深度 | 随机扰动 | 目标体验 |
|---|---|---|---|---|
| 简单 | 距离已有棋子 1 格内 | 1 层（只看自己这步） | 30% 概率从前 5 个候选中随机 | 会堵冲四，但常漏活三；新手能赢 |
| 普通 | 距离 2 格内，最多 60 个 | 2 层（自己下完 + 对手最佳回应） | 8% | 会堵活三、会做活二；认真下能赢 |
| 困难 | 距离 2 格内，最多 90 个 | 4 层 alpha-beta，候选前 12 | 0% | 优先成五 / 堵四 / 抢三；不犯低级错误 |

难度只影响 AI，不改变棋盘大小与规则；切换难度即时生效，下一局沿用上次选择。

### 3.4 AI 决策顺序

```
1. 我能一步成五？           → 直接下
2. 对手下一步能成五？       → 必须堵（若多处成五则堵分值最高的一处）
3. 我能一步成活四？         → 优先进攻
4. 对手有活四/冲四？        → 堵
5. 其余候选按「进攻分 + 防守分×1.1」排序，取前 N 个做搜索
6. 搜索完仍无着法（极端情况）→ 随机空点兜底
```

- 评分口径：成五 1e7、活四 1e6、冲四 1e5、活三 1e4、眠三 1e3、活二 100、眠二 10。
- 候选生成：只考虑已有棋子曼哈顿距离 ≤2 的空点；空棋盘第一手固定天元。
- 搜索节点上限 30 万、时间上限 900ms；超限立即返回当前最优（保证低端机不卡死）。
- 思考表现：至少 220ms、最多 900ms 的「月巴思考中…」脉冲，避免秒下显得像脚本。

### 3.5 月巴对手

- 每局从**已开启图鉴**的月巴中随机 1 只；标题页显示头像、名称、稀有度小点。
- 月巴固定执白；棋子样式为「白底 + 墨色描边」，与玩家实心黑子区分。
- 对局中按事件抽一句短台词（每只月巴共用同一套文案，不做逐只定制）：
  - 玩家落子后 1 句（如「唔…这里？」「这步有点凶」）
  - 月巴堵住威胁 1 句（如「挡住！」）
  - 月巴被将军/被做活四 1 句（如「糟了…」）
  - 胜利 / 失败 / 和局各 1 句
- 台词仅中文先行，四语言同步补齐；文案总量控制在 20 条以内，避免翻译膨胀。

### 3.6 结算

| 结果 | 展示 |
|---|---|
| 胜 | 反白横幅「你赢了」+ 连线五子依次闪烁 + 统计更新 |
| 负 | 「月巴赢了」+ 月巴一句得意台词 + 连线位置描边 |
| 和 | 「棋盘满了」+ 双方各一句 |
| 数据 | 本局步数、用时、连胜、历史胜/负/和 |

结算页按钮：**再战一局**（同对手）/ **换一只月巴** / **返回标题**。不做金币、不做掉落。

## 四、技术方案

### 4.1 单文件结构

```
gomoku.html
├─ <style>  浅色单色像素版式 + 全部 CSS 变量
├─ DOM      顶栏 / 对手条 / 棋盘舞台(#stage) / 底栏 / 弹层(标题/暂停/结算) / toast
└─ <script>
   ├─ 语言字典 TXT（zh/en/ja/ko）
   ├─ 独立存档 gmLoad/gmSave
   ├─ 名册握手（postMessage ready → roster）+ 直开兜底
   ├─ 棋盘模型（Uint8Array 225：0 空 / 1 玩家 / 2 月巴）
   ├─ 胜负判定 / 候选生成 / 评分 / alpha-beta
   ├─ Canvas 像素渲染（棋盘、棋子、悬停、连线、落子动画）
   ├─ 状态机 menu → playing → thinking → paused → over
   ├─ 音效（Web Audio 合成，无音频文件）
   └─ 页面生命周期（visibilitychange / pagehide / resize）
```

### 4.2 棋盘渲染（低分辨率像素）

- 逻辑尺寸固定 `BOARD = 480`（含边距），15 格；格子 `CELL = 29`、左右边距 `MARGIN = 17`，全部整数，保证像素对齐。
- Canvas 实际像素 = `BOARD × min(devicePixelRatio, 2)`，CSS 尺寸自适应；`ctx.imageSmoothingEnabled = false`，CSS `image-rendering: pixelated`。
- 棋子不使用平滑圆：在离屏 9×9 画布画「像素圆」，再按整数倍放大贴回，得到方块感强的棋子。
  - 玩家黑子：实心墨色 + 右下 1px 纸色高光。
  - 月巴白子：纸色实心 + 1px 墨色描边 + 中心 1 格墨点。
- 棋盘线 1px 墨色（`--line2`），外框 2px；四个星位用小方块而非圆点。
- 悬停预览：鼠标移动显示 40% 抖动（2px 棋盘格）半透明棋子；触屏不显示悬停，直接落子。
- **只在以下时机重绘**：落子、撤销、悬停格变化、窗口 resize、动画帧（仅落子 90ms 与胜利闪烁 600ms）。不做常驻 RAF。

### 4.3 交互

| 输入 | 行为 |
|---|---|
| 鼠标点击 / 触屏点按 | 最近交叉点落子；点击半径向外扩 3px，提升小屏命中率 |
| 鼠标悬停 | 显示抖动预览子（不改变棋盘数据） |
| 键盘 `Esc` | 暂停 / 关闭弹层 |
| 键盘 `R` | 结算页再来一局 |
| 悔棋按钮 | 撤回一轮（月巴 + 玩家各一手）；次数用尽后置灰 |
| 认输 | 二次确认后判负 |

- `touch-action:none`、`overscroll-behavior:none`，防止棋盘区域滚动与双击缩放。
- 落子后 120ms 内锁定输入，防止连点重复落子。

### 4.4 状态机

```
menu（标题/换对手/难度）
  └─ start → playing（玩家回合）
               ├─ 落子 → thinking（AI 异步计算）
               │          └─ 落子 → playing / over
               ├─ 悔棋 → playing（若在 thinking，取消计时器）
               ├─ 暂停 → paused（冻结思考计时）
               └─ 五连/满盘 → over（结算）
over → 再战（同对手，重置棋盘） / 换一只（回 menu 重抽）
```

对外暴露 `window.__gomoState()` 返回 `menu / playing / thinking / paused / over`，供首页 `gbBusy()` 判断是否允许热更新。

### 4.5 性能与低功耗

- AI 计算放在 `setTimeout` 中执行，先让「思考中」动画渲染一帧；搜索本身同步但受节点/时间上限约束。
- 无 `backdrop-filter`、无 `filter: blur()`、无大面积 `box-shadow` 动画；弹层用纯色 + 抖动纹理。
- 低功耗模式：关闭扫描线、落子粒子、胜利闪烁；棋子直接落定，不做缩放动画。
- `visibilitychange` → 自动暂停并冻结 AI 计时；`pagehide` → 保存统计。
- 关闭 iframe 即 `about:blank` 卸载，计时器与 AudioContext 一并销毁。

## 五、月巴名册握手

### 5.1 名册范围

父页筛选（与螺旋跳同一口径）：

```js
fgAllTypes()                              // TYPES + TYPES2 + TYPES3
  .filter(t => colCount(t.id) > 0)        // 已开启/已收集
  .map(t => ({
    id: t.id,
    name: t.name,                         // 已是当前语言名
    color: t.color || '#8fd0de',
    scale: picScale(t),
    art: artURL(t) || '',                 // 有立绘才下发
    svg: fatSVG(t)                        // 无立绘时的 SVG 兜底
  }))
```

- 不下发未解锁月巴，避免剧透。
- 152 只全量 SVG 字符串约几十 KB，`postMessage` 足够。

### 5.2 握手协议

| 方向 | 消息 | 说明 |
|---|---|---|
| 子 → 父 | `{type:'yueba-gomoku-ready'}` | iframe `DOMContentLoaded` 后发送 |
| 父 → 子 | `{type:'yueba-gomoku-roster', list, muted, lowPower}` | 父页收到 ready 后回包 |

- 子页 800ms 内未收到名册 → 使用内置兜底名册（约 20 只常见月巴的 id / 四语言名 / 颜色 / `shape`，头像用程序化像素兔兜底），并提示「从百巴箱进入可对战全部已开启月巴」；保证直接双击也能玩。

## 八、UI / 动效 / 音效

### 8.1 视觉基调（浅色单色像素）

沿用蛇月巴 / 幸存者的版式骨架，但整体换成「1-bit 墨色纸面」：

| Token | 默认值 | 用途 |
|---|---|---|
| `--paper` | `#f6f3ea` | 页面底色（米白纸） |
| `--paper2` | `#ece8dc` | 次层纸 / 卡片 |
| `--ink` | `#23231f` | 主墨色 / 玩家黑子 |
| `--ink2` | `#4a4a42` | 次文字 / 描边 |
| `--ink3` | `#7a7a6f` | 弱文字 |
| `--line` | `rgba(35,35,31,.22)` | 细描边 |
| `--line2` | `rgba(35,35,31,.55)` | 棋盘线 / 高亮描边 |
| `--dither` | `rgba(35,35,31,.10)` | 棋盘格抖动纹理 |
| `--ai` | `#fdfbf3` | 月巴白子底 |

规则：

- **全页只有墨色 + 纸色**，不出现彩色 emoji、彩色渐变、彩色高亮；胜负提示靠**反白**（墨底纸字）而不是红/绿。
- 若需层次，只用 2×2 棋盘格抖动（`repeating-conic-gradient`），不用透明度渐变。
- 像素感来自：整数坐标、2px 硬描边、4px 硬投影（`box-shadow:4px 4px 0 var(--dither)`，无模糊）、切角按钮。
- 月巴头像可选灰度化：`filter:grayscale(1) contrast(1.15)`，让彩色立绘融入单色画面（默认开；见「待拍板」）。

|---|---|

- 点击任何按钮不触发屏幕整体闪烁（沿用项目既有约束）。

### 8.4 音效

- 复用 Web Audio 合成，无外部音频文件；只用 sine / triangle，避免刺耳方波。
- 共享一个 `AudioContext` + 总输出限幅（≤0.7）+ 单音音量钳制 + 并发 ≤6 + `onended` 释放。
- 键位：`placeMe`（玩家落子）、`placeAi`（月巴落子）、`invalid`（无效）、`undo`（悔棋）、`taunt`（台词气泡）、`win`、`lose`、`draw`、`ui`、`pause`。
- 静音跟随主存档 `muted`，页内可切换但不写回。
- 连点/连续落子做 80ms 节流，避免并发撑满。
